Base de Datos
Especifica el Google Sheet compartido que actúa como base de datos de la plataforma.
ℹ️
En arquitectura Single-DB Multi-Tenant, todos los tenants apuntan al mismo Sheet. Si eres Tenant B, usa el mismo Sheet ID que el Tenant A te haya compartido con acceso Editor.
Encuéntralo en la URL del Sheet: docs.google.com/spreadsheets/d/[ID]/edit
El ID del Google Sheet es requerido.
Mantén "Google Sheets" a menos que estés migrando a una BD externa.
⚠️
Asegúrate de que la cuenta de servicio de Apps Script tiene acceso Editor al Sheet antes de continuar. Sin este permiso, el sistema no podrá leer ni escribir datos.
