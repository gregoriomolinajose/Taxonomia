# S46.4: Refactor Org Chart Hierarchy to use `lider_directo`

## User Story
**As a** system user,
**I want** the organizational chart to be structured strictly according to the reporting lines (`lider_directo`),
**So that** the diagram visually represents the true chain of command rather than arbitrary group-by configurations.

## Acceptance Criteria
- Given a dataset of Personas with assigned `lider_directo` values, when the tree is built, the nodes must be nested correctly following the `PERSONA_LIDER_DIRECTO` graph edges.
- Given multiple root Personas (no leader), when the tree renders, they must all be attached to a synthetic "Empresa" root to avoid disjoint graphs.
- Given the node visual card, when it renders, the department accent color must still be preserved for visual identification.
