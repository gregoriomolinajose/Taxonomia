# Retrospective S46.1: Toolbar View Toggle & Data Transformer

## 1. What went well
- We cleanly injected the tree toggle button into the `DataView` toolbar.
- The `DataView_UI` router extension for the `tree` view was straightforward and proportional to the task.
- We implemented `buildHierarchyTree` without over-engineering, sticking to simple IDs and avoiding speculative generality.

## 2. What could be improved
- `DataView_UI.client.js` is growing (God Object). We should track this as technical debt for a future epic and potentially extract views (List, Grid, Map, Tree) into their own factory modules.
- The `buildHierarchyTree` heuristic uses a virtual node (`root-company`) for multiple independent roots. We must ensure this doesn't conflict with backend interactions, though since it's a presentation-only view, it is generally safe.

## 3. Learnings
- The `UI_DataView_Toolbar` uses a conditional pattern (`if (entityName === 'Dominio')`) which we successfully replicated for `Persona`, proving the extensibility of the UI shell for custom views per entity.

## 4. Framework / Process Updates
- None required.
