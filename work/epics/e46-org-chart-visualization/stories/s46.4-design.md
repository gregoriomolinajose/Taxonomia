# S46.4 Design Specification

## Overview
Change the hierarchical backbone of the org chart from grouping to strictly graph-edge-based parent mapping using `lider_directo`.

## Implementation Tasks

### 1. Update Hierarchy Engine
- **File:** `src/DataEngine_UI.client.js`
- **Target:** `buildHierarchyTree`
- **Changes:** 
  - Change `const parentCol = 'Líder';` to `const parentCol = 'lider_directo';`
  - Ensure the fallback parsing correctly handles when `lider_directo` is an array of objects `[{id: '...'}]` or a raw string UUID.

### 2. Validation
- Verify the topological tree doesn't break if `lider_directo` is empty.
- Fallback unassigned individuals to an "Empresa" root.
