# User Story S46.3: Node Template & Theme Styling

As a user,
I want the organizational chart nodes to be visually appealing, showing avatars, full names, roles, and department color-coding,
So that I can easily scan and understand the organizational structure at a glance.

## Acceptance Criteria
- Given the Tree View is active, when a node renders, it must display the employee's Avatar, Name, Role, and Department.
- Given the node renders, its top border or background accent should be color-coded based on the Department (Área).
- Given the node renders, it must not be susceptible to XSS (ensure all data is escaped).
- Given the layout of the chart, it must be responsive or scrollable for large hierarchies.
