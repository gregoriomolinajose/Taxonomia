# User Story S46.2: ApexTree Local Integration

As a user,
I want the ApexTree library to be loaded locally and initialized when I switch to the Tree View,
So that the application can render the hierarchical employee data offline and securely without relying on external CDNs.

## Acceptance Criteria
- Given I am a developer, the `ApexTree` source code is embedded within the project files (`Vendor_ApexTree.html` or similar).
- Given I am on the `DataView` screen, when I toggle the "Tree View" for the `Persona` entity, the system initializes an `ApexTree` instance inside the `#org-chart-container`.
- Given the tree initializes, it uses the transformed data from `buildHierarchyTree` to render the basic structure of the organization.
