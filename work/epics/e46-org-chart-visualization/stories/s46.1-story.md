# User Story S46.1: Toolbar View Toggle & Data Transformer

As a user,
I want to toggle to a "Tree View" in the DataView toolbar,
So that I can eventually view my data in a hierarchical format.

## Acceptance Criteria
- Given I am viewing the `UI_DataView`, when I look at the top right toolbar, I should see a third toggle button with a tree/diagram icon next to the list and grid buttons.
- Given I click the "Tree View" button, the view state changes, hiding the list/grid cards and showing an empty container `#org-chart-container`.
- Given the system loads employee data, the new `buildHierarchyTree()` transformer successfully maps linear relationships via the `Líder` property into a nested object format suitable for ApexTree.
