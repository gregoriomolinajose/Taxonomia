# Story: S46.5

## User Story

Como usuario del Sistema de Taxonomía,
Quiero poder abrir un diagrama de tipo "ECharts Option Query" para la entidad "Capacidades" mediante un botón en el DataView Toolbar,
Para poder visualizar y analizar la topología de la información usando configuraciones avanzadas de ECharts.

## Acceptance Criteria

- [ ] Un nuevo botón se añade en el DataView Toolbar específicamente para la vista de "Capacidades".
- [ ] Al hacer clic en el botón, se despliega una interfaz o modal conteniendo un contenedor de ECharts.
- [ ] El diagrama renderizado emplea la tecnología ECharts utilizando opciones parametrizadas (Option Query).
- [ ] El diagrama se alimenta del modelo o sub-grafo de "Capacidades".
