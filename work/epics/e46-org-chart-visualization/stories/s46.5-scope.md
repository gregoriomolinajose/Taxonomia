# Scope: S46.5 - ECharts Option Query Diagram for Capacidades

## In Scope
- Añadir un botón en `UI_DataView_Toolbar` (o equivalente) exclusivo para la entidad "Capacidades".
- Implementar la lógica para instanciar un contenedor y renderizar un gráfico usando Apache ECharts.
- Consultar y transformar los datos de "Capacidades" al formato requerido por ECharts Options.

## Out of Scope
- Migrar visualizaciones existentes (como ApexTree) a ECharts.
- Implementar ECharts para entidades distintas a "Capacidades".
- Funcionalidad de edición de datos desde dentro del nuevo diagrama.

## Done When
- El botón es visible al estar en la sección "Capacidades".
- El click del botón invoca exitosamente la vista ECharts.
- Los datos de Capacidades se reflejan en la gráfica mediante la configuración pasiva "Option Query" de ECharts.
- Se puede cerrar la visualización para regresar al modo tabla/vista original.
