# Retrospective S46.2: ApexTree.js Local Integration

## 1. What went well
- We successfully downloaded and wrapped the minified `ApexTree.js` source code into a local `Vendor_ApexTree.html` module.
- We bypassed Google Apps Script's Content Security Policy limitations by avoiding CDN reliance (Zero-Trust).
- The integration within `DataView_UI` is fully functional and safely contained within a `try/catch` block.

## 2. What could be improved
- The layout dimensions (`offsetWidth`) can suffer from a race condition if queried before the browser paints. We should ensure reactive rendering or apply CSS explicit widths.
- We caught a DOM XSS vulnerability in the node template during the Quality Review; it's a good reminder to always escape user data when injecting via template literals in Vanilla JS.

## 3. Learnings
- The `<?!= include(...) ?>` pattern works perfectly for integrating large vendor JS files without cluttering `Index.html` or creating deployment complications with `clasp`.

## 4. Framework / Process Updates
- None required.
