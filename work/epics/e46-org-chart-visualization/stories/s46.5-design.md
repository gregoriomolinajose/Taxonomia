# Story Design: S46.5 - ECharts Option Query Diagram

## 1. Arquitectura a Modificar

Para implementar el diagrama avanzado utilizando Apache ECharts exclusivamente para la entidad `Capacidad`, la integración abarcará cuatro puntos principales:

1. **`UI_DataView_Toolbar.client.js`**
   - **Cambio:** Inyectar un nuevo botón condicional (`entityName === 'Capacidad'`) en el lado izquierdo del toolbar (`dv-toolbar-left`).
   - **Estado:** Se activará enviando el string `'echarts'` al manejador `onViewToggle`.

2. **`DataView_UI.client.js`**
   - **Cambio:** Ampliar el dispatcher de vistas en `_rerenderData`. Si `_state.view === 'echarts'`, se invocará el método delegado de renderizado `window.UI_View_ECharts.render(dataZone, _state)`.

3. **`UI_View_ECharts.client.js` (Nuevo Módulo / Módulo Dedicado)**
   - **Responsabilidad:** Construir el contenedor del lienzo (`echarts-container`), inicializar la instancia `echarts.init()` usando la librería ya existente y suministrarle el objeto de configuración (Options).
   - **Escalabilidad:** Mantenerlo agnóstico, aislando la lógica de construcción del objeto de configuración.

4. **`Math_Engine` o Transformador Interno**
   - **Cambio:** Añadir una función `buildEChartsCapacidadesOption(data)` que procese los registros filtrados de `Capacidad` y construya un diagrama (por ejemplo, tipo `tree` o `graph` con Option Query) listo para pasarse a `chart.setOption()`.

## 2. Decisiones Técnicas (ADR / Context)

- **Reuso de Librería:** Se utilizará la versión de ECharts v5+ actualmente inyectada en `Index.html` (CDN).
- **Separación de Responsabilidades:** `DataView_UI` no sabrá de ECharts, simplemente delega el DOM al módulo `UI_View_ECharts`.
- **Rendimiento:** El contenedor de ECharts se ajustará a la resolución usando `window.addEventListener('resize')`, pero solo estará activo mientras esa vista sea seleccionada (evitando memory leaks cuando el usuario cambia de vista a tabla).
- **Esquema Option Query:** Permite al sistema reaccionar y ajustar las opciones puramente mediante la actualización de los diccionarios JSON (Options) en lugar de alterar código imperativo complejo.

## 3. Plan de Implementación (Task Breakdown)
*Esto alimentará el paso de planning (`/rai-story-plan`)*

1. Crear/Inyectar el nuevo componente `UI_View_ECharts.client.js` con el cascarón de renderizado.
2. Actualizar `DataView_UI.client.js` para reconocer `view: 'echarts'`.
3. Actualizar `UI_DataView_Toolbar.client.js` para agregar el botón `pie-chart-outline` o `analytics-outline`.
4. Extender `Math_Engine` o crear un utilitario para construir el `Option Query` con los datos de Capacidades.
5. Desplegar a DEV y probar visualización interactiva.
