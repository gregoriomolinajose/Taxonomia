# Scope S46.2: ApexTree Local Integration

## In Scope
- Download the minified source code of `ApexTree.js` (or copy it) into a local file (e.g., `src/Vendor_ApexTree.html`).
- Include the vendor file in `Index.html` so it's loaded by the browser.
- Update `DataView_UI.client.js` `_rerenderData` to instantiate `new ApexTree()` and pass the `buildHierarchyTree(records)` output when the Tree view is active.

## Out of Scope
- Detailed CSS styling, node templates, and department color-coding (that's S46.3).

## Done Criteria
- [ ] Vendor file is added and injected into the GAS output.
- [ ] Toggling the tree view actually renders the default ApexTree shapes using the local library.
