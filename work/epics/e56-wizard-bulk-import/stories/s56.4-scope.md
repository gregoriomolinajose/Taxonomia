# Scope: S56.4 - Integración de Ejecución ETL

## Boundaries

### In Scope
- Habilitar el botón "Cargar Registros" (`#btn-sync-drive` y `#btn-sync-csv`) en el `UI_Component_BulkImporter.client.js`.
- Modificar o asegurar que `_defaultDriveSync` utilice correctamente `options.contextId` si se provee, pasándolo al backend.
- Conectar con el backend (`etl_extract_sheet_data`) para extraer los registros (payload).
- Mandar el payload a `bulkInsert` en caso de que sea necesario, o usar directamente el pipeline de inserción masiva.
- Emitir el evento `ETL::FINISHED` a través del `AppEventBus` al completar la carga masiva.
- Validar que el paso en el Wizard registre la finalización para permitir avanzar (habilitar botón "Siguiente").

### Out of Scope
- Nuevas estrategias de resolución de grafo (eso fue cubierto en S47 y S48).
- Importación de otras entidades ajenas a Equipos o Personas en este flujo específico.

## Done Criteria
1. Se puede ejecutar la extracción de Google Sheets haciendo clic en "Cargar Registros".
2. Los datos extraídos se inyectan correctamente como "Borrador" usando el contexto de la Taxonomía (si se configuró para arrastrar entidades al contexto).
3. Tras la carga, la UI del Stepper avanza lógicamente.
