# S56.1 Scope: Reestructuración del Wizard

## Boundaries

### In Scope
- Actualizar el array `steps` (y su mapeo lógico) en la instanciación de `UI_FormStepper` para la entidad Taxonomía, introduciendo "Importar Equipos" y "Importar Personas".
- Ajustar la lógica dentro de `UI_FormStepper` o donde corresponda para que las vistas Inmersivas/Full-Screen se activen exclusivamente en el Canvas (ahora índice 3, no índice 1).
- Reservar los contenedores vacíos del DOM en los nuevos pasos para la posterior inyección de componentes en S56.2.

### Out of Scope
- Implementar la interfaz de usuario de carga masiva (selector de sheets, botones de validación). Solo se requiere crear el "cascarón" (paso del stepper).
- Modificar el backend de ETL o conectar API externas.
- Alterar la lógica del autoguardado universal (ya manejada por E55).

## Done Criteria
- [ ] El Stepper de Taxonomía tiene 4 pasos renderizados.
- [ ] Se puede avanzar y retroceder entre los 4 pasos usando los botones Siguiente/Anterior.
- [ ] El Canvas de Taxonomía solo se carga y se expande a pantalla completa cuando el usuario alcanza el cuarto paso (índice 3).
- [ ] Si se retrocede desde el Canvas al paso 3, el panel izquierdo de navegación reaparece.
