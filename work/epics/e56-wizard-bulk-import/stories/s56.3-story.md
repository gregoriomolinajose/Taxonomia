# User Story: S56.3 - Inspección de Archivos Google Sheets

## User Story (Connextra)
Como usuario configurando una Taxonomía
Quiero inspeccionar un archivo de Google Sheets pegando su URL
Para asegurarme de que el archivo es válido, tiene el formato correcto y contiene datos útiles antes de iniciar la importación.

## Acceptance Criteria (Gherkin)

### Scenario 1: Validación de URL exitosa
**Given** que estoy en el paso "Importar Equipos" o "Importar Personas"
**When** pego un enlace válido de Google Sheets en el input
**And** hago click en el botón de búsqueda/inspección (lupa)
**Then** el sistema debe hacer una llamada al servidor para extraer los metadatos del archivo
**And** debe mostrar un indicador de carga durante el proceso
**And** debe reflejar información básica o estado de validez al terminar.

### Scenario 2: Error en formato de archivo
**Given** que he pegado un enlace válido de Google Sheets
**When** hago click en inspeccionar
**And** el archivo no tiene datos útiles, carece de permisos o es un formato xlsx antiguo
**Then** el sistema debe capturar el error
**And** debe mostrar un mensaje de error explicativo en el UI del componente.

## Specification by Example
- Input: `https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit` -> Inspecciona el ID `1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms` y devuelve OK.
- Input: `https://google.com/` -> El botón de sync sigue deshabilitado, formato inválido.
