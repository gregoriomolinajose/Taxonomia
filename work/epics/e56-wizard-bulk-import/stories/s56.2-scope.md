# S56.2 Scope: UI de Importación Embebida (Inline)

## In Scope
- Refactorización de la UI de importación masiva (`UI_ETL_Modal` u homólogo actual) hacia un componente independiente `UI_BulkImporter.client.js`.
- Ajuste de estilos para que el componente funcione tanto en un Drawer, un Modal, o directamente dentro de una fila (`ion-row`/`ion-col`) del wizard de FormEngine.
- Inyección del componente en `FormRenderer_UI.client.js` al encontrar un `divider` o un campo virtual definido para carga masiva.

## Out of Scope
- Integración real con Google Apps Script para descargar o procesar la hoja de Google Sheets (eso será en S56.3).
- Lógica de backend para el guardado real en la base de datos de las filas importadas (eso es S56.4).

## Done Criteria
- [ ] La clase `UI_BulkImporter` es un componente instanciable sin acoplamiento a Modales globales.
- [ ] Al visualizar el Paso 2 (Equipos) del Taxonomía Wizard, el componente de importación masiva se renderiza perfectamente sin romper el contenedor de scroll del stepper.
- [ ] La UI incluye el input de URL, la zona de "Drop File", y las instrucciones dinámicas (qué entidad se está importando).
