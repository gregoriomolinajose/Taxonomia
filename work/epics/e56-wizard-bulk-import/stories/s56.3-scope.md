# Scope: S56.3 - Inspección de Archivos Google Sheets

## Boundaries

### In Scope
- Habilitar la funcionalidad del botón de "lupa" en `UI_Component_BulkImporter.client.js`.
- Implementar la extracción del ID de Google Sheets a partir de una URL usando una expresión regular.
- Realizar una llamada a `API_Universal_Router` con una nueva acción o reutilizando la de extracción para obtener una "vista previa" o comprobación de los metadatos del archivo.
- Mostrar una notificación (`_showToast`) o información de pre-validación al usuario en caso de éxito.
- Manejar adecuadamente errores (archivo sin permisos, URL no válida, formato incorrecto) y presentarlos en la interfaz.

### Out of Scope
- Implementar la importación o escritura final de datos en la base de datos de la Taxonomía (es parte de S56.4).
- Extracción de vista previa completa (ej. tablas enteras). Solo nos interesa comprobar que el archivo es legible y tiene la estructura básica correcta antes del *Commit*.

## Done Criteria
1. El botón de inspección ejecuta una llamada simulada o real de validación contra el backend de Apps Script.
2. Si el archivo es inválido, el UI muestra el error sin bloquear el resto del Wizard.
3. El usuario recibe feedback claro (loaders) durante la inspección.
