# Retrospective: S56.4 - Integración de Ejecución ETL

## Context
**Epic:** E56 Wizard Bulk Import
**Story:** S56.4
**Objective:** Habilitar el flujo de ejecución ("Cargar Registros") directamente desde el Google Sheet especificado dentro del UI del Bulk Importer, asegurando que los registros extraídos reciban el contexto de Borrador (`_contexto_arista` y `estado = 'Borrador'`) antes de ingresar a la base de datos a través del `DataEngine_ETL`.

## Learnings
1. **Inyección en el Edge de Salida:** Inicialmente se consideró modificar `DataEngine_ETL.processPayload` para aceptar opciones de `contextId`. Sin embargo, aprovechar el interceptor de la promesa `window.DataAPI.call` dentro del UI (`UI_Component_BulkImporter.client.js`) proporcionó un puente elegante que no afecta la abstracción core del ETL.
2. **Propagación del Evento Global:** Utilizar `AppEventBus.publish('ETL::FINISHED')` para anunciar la finalización de los "chuncks" promueve un diseño reactivo y muy poco acoplado, facilitando futuras lógicas como analíticas u orquestaciones visuales.
3. **Manejo Correcto de Arrays mutados:** Resuelta la inyección con un bloque directo `res.data.forEach` garantizando la mutación en memoria rápida antes del despacho al chunker asincrónico V8.
