# S56.1 Story: Reestructuración del Wizard

## User Story
**Como** administrador responsable de definir la topología,
**Quiero** que el wizard de Taxonomía contenga pasos intermedios explícitos para importar Equipos y Personas,
**Para** poder ejecutar la carga masiva dentro del mismo flujo antes de visualizar el Canvas final.

## Gherkin Acceptance Criteria

**Scenario**: Rendering de los nuevos pasos
  **Given** que el usuario abre el modal/drawer de nueva Taxonomía
  **When** el Stepper inicializa
  **Then** la barra lateral debe mostrar 4 pasos: "Configuración General", "Importar Equipos", "Importar Personas" y "Taxonomía Canvas" en ese orden.

**Scenario**: Reglas Full-Screen del Canvas actualizadas
  **Given** que el usuario navega a través de los pasos
  **When** llega al paso 4 (Taxonomía Canvas, índice 3)
  **Then** la pantalla debe pasar a modo inmersivo ocultando el panel izquierdo,
  **And** si retrocede al paso 3 (Importar Personas), debe restaurar el panel izquierdo.
