# S56.2 Design: UI de Importación Embebida (Inline)

## 1. Problem & Value
**Problem**: La vista de importación masiva (`UI_ETL_Modal.client.js`) está acoplada rígidamente a un Modal global y no puede ser inyectada en contenedores estáticos (como el Wizard).
**Value**: Al abstraer este componente, no solo permitiremos que los pasos del Wizard fluyan de forma inmersiva sin popups que rompan la experiencia, sino que tendremos un componente reutilizable para futuros flujos.

## 2. Approach

1. **Creación de `UI_Component_BulkImporter.client.js`**:
   - Se creará una nueva clase `window.UI_BulkImporter` que reciba una configuración (`targetEntity`, `options`, `contextId`) y cuyo método `.render()` devuelva un `HTMLElement` (un div `.etl-body` o similar).
   - Este componente contendrá toda la lógica visual actual de `UI_ETL_Modal` (pestañas Google Sheets vs CSV, inputs de URL, dropzone de archivos, barra de progreso y vista de resultados).
   - No forzará un `ion-modal` interno. Se expandirá al 100% del contenedor padre.

2. **Adaptar `UI_ETL_Modal.client.js` (Backward Compatibility)**:
   - Para no romper las pantallas de Listados Genéricos (`DataView_UI`), la función `UI_ETL_Modal.present()` se re-escribirá para que internamente genere el `ion-modal`, instancie `new UI_BulkImporter()`, lo monte dentro de `ion-content`, y haga un puente ("bridge") hacia sus métodos `updateProgress()` y `showResults()`.

3. **Modificación de Esquema (`Schema_Engine.js`)**:
   - En el esquema de Taxonomía, cambiaremos el tipo de campo de "Importar Equipos" e "Importar Personas" de `type: "divider"` a `type: "uiComponent", uiComponent: "bulk_importer"`. Agregaremos `targetEntity: "Equipo"` y `targetEntity: "Persona"`.

4. **Fábrica de Componentes (`FormBuilder_Inputs.client.js`)**:
   - En la función `global.UI_Factory.buildFieldNode`, agregaremos una condición para atrapar `field.uiComponent === 'bulk_importer'`.
   - Cuando se detecte, instanciará `new window.UI_BulkImporter({ targetEntity: field.targetEntity, contextId: currentEditId })` y devolverá el nodo renderizado para que el Wizard lo incruste de forma natural.

## 3. Acceptance Criteria
- **MUST**: `UI_BulkImporter` expone los métodos `.render()`, `.updateProgress()` y `.showResults()`.
- **MUST**: `UI_ETL_Modal.client.js` utiliza internamente a `UI_BulkImporter` sin duplicar la lógica de creación del DOM o listeners de botones.
- **MUST**: El Wizard de Taxonomía muestra en los pasos 2 y 3 la interfaz inmersiva (Inputs de Google Sheets / CSV) sin botones flotantes o comportamientos de modal.

## 4. Next Steps
- Implementar la migración de la lógica desde `UI_ETL_Modal` hacia la nueva clase base.
- Actualizar el index.html y Schema.
