# S56.2: UI de Importación Embebida (Inline)

## 1. User Story

Como usuario con permisos de edición de taxonomía
Quiero disponer de la interfaz de carga masiva integrada directamente en los pasos del wizard (Equipos y Personas)
Para no tener que abrir popups flotantes que rompan el flujo de configuración paso a paso.

## 2. Acceptance Criteria (Gherkin)

```gherkin
Feature: Inline Bulk Importer
  Background:
    Given que estoy creando o editando una Taxonomía
    And el wizard tiene configurado el paso de "Importar Equipos" y "Importar Personas"

  Scenario: Renderizado de la UI de Importación
    When llego al paso 2 o 3 del wizard
    Then debo visualizar el componente de carga masiva sin modales
    And la vista debe tener un input para URL, otro para arrastrar archivo, y mostrar instrucciones claras
    And el estilo debe respetar los tokens de diseño de sistema (SaaS)

  Scenario: Aislamiento del Componente
    When interactúo con la interfaz de carga (escribir URL)
    Then no deben dispararse eventos de navegación o submit del wizard prematuramente
```

## 3. Specification by Example

- **Dado** que llego al "Paso 2: Importar Equipos"
- **Cuando** la vista se renderiza
- **Entonces** el sistema inyecta un `UI_BulkImporter` puro y autocontenido que ocupa la pantalla completa disponible (fuera de un ModalStack).
