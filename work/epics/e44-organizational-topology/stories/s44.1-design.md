# S44.1: Design

### Architecture & Data Model
- **Entity**: Create a new `Rol` schema definition in `APP_SCHEMAS`.
- **Topological rules**: Assign prefix `ROLE` to ensure IDs generate as `ROLE-XXXX`. Use `construct-outline` for the icon property.
- **Attributes**: Base fields include `nombre` (required, string) and `descripcion` (optional, text).

### Business Logic & Flow
- Remove static enums from `Persona` entity that previously handled agile roles.
- The Engine must handle the migration of old static strings to their corresponding new topological `ROLE-...` references.
- Implement an `abac_lock` rule if Roles should be restricted from basic user manipulation.

### UI & UX Integration
- Introduce the new Rol entity inside the UI architecture (Menu/Sidebar elements).
- Use a standard DataGrid layout to manage the creation/deletion of Roles.
