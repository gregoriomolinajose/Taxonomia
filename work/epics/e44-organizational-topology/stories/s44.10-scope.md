# S44.10: Migración Masiva de Roles Legacy - Scope

## In scope:
- Mapear el catálogo antiguo de cadenas de texto de `rol_agil` (ej. "Scrum Master", "RTE", "Developer") hacia sus respectivos registros nativos dentro del esquema de la Entidad `Rol`.
- Generar masivamente aristas (`Sys_Graph_Edges`) de las cardinalidades correctas para todas las personas activas registradas en `DB_Persona`.
- Crear un entorno de ejecución mediante Script de Admin o Consola Dev de Apps Script (Job de una Sola Ejecución).
- Respaldo pasivo (loggeo) de las operaciones.

## Out of scope:
- Refactorización de componentes Web UI (Ya implementado previamente).
- Creación de interfaz dedicada de visualización para Administradores de Carga Masiva.
- Migraciones de otros componentes secundarios no vinculados a Roles.

## Done when:
- El script es probado exitosamente en `DEV`.
- Todas las filas huérfanas de `rol_agil` quedan enlazadas permanentemente a sus respectivos UUIDs topológicos.
- La pantalla visual de Dashboard "Capacity Map" refleja de inmediato los resultados correctamente en lugar de fallar o visualizar arreglos en blanco.
- El script de migración se despliega y es ejecutado manualmente en el entorno `PROD`.
