# S44.8: Design

### Architecture & Data Model
- **Dictionary Context**: Extrapolate `Cargo` as an independent dictionary node, mapping Workspace's text IDs to internal UUIDs.
- **Topological constraint**: Link `Cargo` as a Catálogo node, enforcing `isTemporalGraph` rules for 1:N relations.

### Business Logic & Flow
- Cache dictionary resolutions internally so ID searches don't consume repeated I/O queries.
- Build interceptor to automatically construct a `CARG-[...] ` UUID natively assigned by the DataStore.

### UI & UX Integration
- Embed standard CRUD interfaces to map strings from "ID Externo Workspace" seamlessly for HR administrators without complex technical configuration screens.
