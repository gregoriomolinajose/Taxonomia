# Design Specification: S44.3 Mutación DataStore

## Architectural Decisions
1. **Computed Fields (Virtuales)**:
   - Se requiere un diseño abstracto donde NO se inyecten reglas de negocio estáticas (ej. `if entityName === 'Persona'`) a nivel motor.
   - En su lugar, el motor emplea una definición declarativa en el Diccionario `APP_SCHEMAS`: la matriz `computedFields`.
   - `JS_Core.client.js` iterará este arreglo universal (Configuration Over Convention), ensamblando recursivamente los atributos `concat` vía un `separator` tolerante a Fallbacks Falsy.
2. **Visual Configuration over Convention**:
   - `UI_DataGrid.client.js` invocará de manera genérica a la propiedad `schema.uiConfig.dashboardCard`.
   - Se emplearán `subtitleFields` para proyectar atributos meta (como Email y Departamento) iterativamente, permitilendo que el Grid permanezca 100% puro para cualquier Entidad.
