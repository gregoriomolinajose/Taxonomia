# S44.13: Interceptor Universal de Grafos para ETL Masivo\n\n## User Story\n**As a** System Architect\n**I want** to implement a Universal Graph Interceptor within the Engine_ETL.hydrateAndDeduplicate boundary\n**so that** massive CSV imports (>500 records) can calculate and provision SCD2 graph edges (M:N relations like PERSONA_CARGO) purely in memory (O(1)) without hitting Google Apps Script timeout limits, effectively decoupling graph logic from the iterative DB nested save.\n\n## Specification By Example\n- Cuando un administrador importa 1000 Personas.\n- El diccionario pre-carga Relaciones en memoria.\n- En lugar de forzar orchestrateNestedSave iterativo que gasta I/O, el Interceptor extrae TODAS las aristas y las deposita de forma transaccional mediante Engine_DB.upsertBatch a Sys_Graph_Edges.\n
