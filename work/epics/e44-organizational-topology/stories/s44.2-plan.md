## Design

### Architecture & Data Model
- **Graph Metadata**: Mutate `Sys_Graph_Edges` payload schema to optionally include `peso_capacidad` (Integer, 0-100%).
- **SCD-2 Protection**: Ensure that augmenting the edge metadata does not override or invalidate the temporal boundaries (`fecha_inicio`, `fecha_fin`).

### Business Logic & Flow
- Expose the metadata payload parameter in `Engine_Graph.patchSCD2Edges` and `Engine_Graph.addEdge`.
- Adjust the internal diffing logic so a change in `peso_capacidad` alone can trigger a new temporal edge row without changing the actual destination node.
- Modify the reverse lookup so components can sum `peso_capacidad` dynamically.

### UI & UX Integration
- **Capacity Slider**: The `RelationBuilder` or Form modal needs to inject a slider or numeric input when assigning a Rol.
- Visually mark in the UI if an individual allocation exceeds 100%.
