# User Story: Mutación DataStore (_nombre_completo)

**As a** system user,
**I want** to see the full name, avatar, and core attributes (email, department) of individuals globally across the entire UI
**So that** I don't have to read decoupled columns or parse IDs manually when identifying assigned members.

## Acceptance Criteria
- [x] La variable `_nombre_completo` se genera de forma virtual uniendo dinámicamente `nombre` y `apellidos` sin afectar el Schema Físico de Base de Datos.
- [x] El `UI_DataGrid` renderiza correctamente el avatar personal si cuenta con una URL válida (HTTP/S).
- [x] Se exponen subtítulos indicando el `email` y `departamento` bajo la estructura de UI Card Moderna del Grid de manera agnóstica (`uiConfig`).
- [x] El motor tolera atributos Nulos o Indefinidos fallando hacia un `fallback` dinámico (`email` o `id_persona`).
