# Scope S44.1: Infraestructura Entidad Rol

## In Scope
- Definición de la entidad `Rol` en `APP_SCHEMAS` (`src/Schema_Engine.js`).
- Atributos base: `id_rol` (PK), Sistema, Auditorio, Versión, Nombre, y Descripción (Textarea).
- Configuración visual de Entidad: Prefijo `ROLE`, label "Roles", color de tema base (`primary` o derivado).
- Preparación del M:N (declarar en Schema de Rol y Persona cómo se relacionan mediante `Sys_Graph_Edges`).

## Out of Scope
- Migración de datos SQL / Carga del catálogo de Roles existentes.
- Cálculos de capacidad o lógicas visuales del mapa de equipos (se abordará en S44.5).
- Frontend o visualización del merge de Apellidos (corresponde a S44.3).

## Done Criteria
- [ ] La interfaz expone "Roles" en el menú (si se configura `showInMenu: true`) y permite CRUD.
- [ ] `Schema_Engine.js` contiene `APP_SCHEMAS.Rol` validado.
- [ ] Los tests de esquema suben sin error o validaciones superadas según gate de calidad.
