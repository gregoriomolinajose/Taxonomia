# S44.7: Design

### Architecture & Data Model
- Modify `APP_SCHEMAS.Persona.fields` array topology.
- Add logical boundaries (virtual fields) with `type: 'separator'` such as `separator_1`, `separator_2`.
- Remove `showIf` conditions from business-critical fields like "Cargo" to prevent validation failures on load.

### Business Logic & Flow
- Ensure FormBuilder correctly intercepts `type: 'separator'` and does not attempt to bind the value to a model payload.
- Separate ABAC security validations to ensure that even with UI splits, secure fields still drop if the token doesn't map successfully.

### UI & UX Integration
- Enhance the `FormBuilder` recursively to map separators into HTML `<hr>` or `<h3>` container boundaries with icon tags.
- Apply Flex/Grid padding adjustments to reset flow after each block section so inputs align cleanly.
