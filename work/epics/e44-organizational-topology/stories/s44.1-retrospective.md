# Retrospective: S44.1 Infraestructura Entidad Rol

## Learnings
- El patrón `APP_SCHEMAS` de RaiSE funciona a la perfección para habilitar M:N inyectando únicamente la configuración visual y las variables topológicas estables (`PERSONA_ROL`). 
- Fue crucial desacoplar el viejo campo de `Persona` para abrir la puerta al historial SCD-2 usando `Sys_Graph_Edges`.
- En revisiones de Calidad posteriores descubrimos el poder preventivo de `FIELD_TEMPLATES.NAME_FIELD()` que auto-protege propiedades críticas (como la obligatoriedad `required: true`) a nivel central sin rediseño manual.
- La analogía visual (Ionicons `shirt-outline`) ayuda profundamente al mapeo mental de los Líderes sobre qué implica tener un Rol Ágil.

## Action Items
- Para historias siguientes (S44.2), extender `Sys_Graph_Edges` con el peso porcentual para concretar el cálculo de capacidad.
