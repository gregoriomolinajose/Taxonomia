## Design

### Architecture & Data Model
- Implement a non-destructive interceptor matrix mapping raw "Workspace Number Fields (e.g., 411)" directly to the active Schema UUID for Job Titles.
- No direct database writes, parsing strictly occurs in the `hidratate` flow.

### Business Logic & Flow
- Create a runtime lookup map during `ETL` hydration.
- If an automated Bulk flow encounters `cargo: "411"`, swap the value natively into `id_cargo: "CARG-..."` inside the dictionary translation layer. 
- Drop invalid payloads with unmapped IDs strictly or attach placeholder metadata.

### UI & UX Integration
- Transparent to the end user. If any manual mapping UI is needed later, establish an "On Load" hook listener in Modal templates.
