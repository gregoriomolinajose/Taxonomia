# S44.8: Entidad Cargo (Diccionario Topológico Vivo)

## User Story

**As a** Human Resources Administrator
**I want** to manage a progressive dictionary mapping Workspace IDs to internal descriptive Job Titles (Cargos)
**so that** incoming employee payloads automatically register the correct human-readable role, and I can maintain an audited timeline (SCD-2) of an employee's promotion history across time.

## Acceptance Criteria

```gherkin
Feature: Cargo Organizational Schema

  Scenario: Administrative Management of Cargos
    Given I log in as Administrator
    When I navigate to the Schema Editor for "Cargos"
    Then I should be able to create a new Cargo specifying "Nombre" and "ID Externo Workspace"
    And the system will assign an internal CARG-* prefix UUID

  Scenario: Associating a Cargo to a Persona
    Given a Persona record is open in Edit mode
    When I search the "Cargo" dropdown
    Then I should see a dynamic searchable list of Cargo names
    And selecting "Gerente de Producto" links the Cargo topologically with an `isTemporalGraph` constraint of 1:N
```

## Specification By Example

- Cuando el Administrador ingresa `411` como ID de Workspace y `Gerente de Producto` como Nombre, se genera el registro `CARG-XYZ`.
- Si el Administrador abre el perfil de Juan Pérez y le asigna `Gerente de Producto`, la capa `Engine_DB` orquesta un parche universal al nodo de Juan apuntando al nodo padre de Cargo mediante la relación `CARGO_PERSONA` con la propiedad SCD-2 activa (`es_version_actual: true`).
