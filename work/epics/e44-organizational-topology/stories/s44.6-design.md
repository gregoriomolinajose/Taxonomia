# S44.6: Design

### Architecture & Data Model
- No database changes required. The component deals exclusively with HTML/CSS DOM structuring.

### Business Logic & Flow
- The state management variable `isMultiple` inside `UI_Component_TXSearchable.html` will act as a routing switch.
- For Single Select (`!isMultiple`), executing a focus or click on the placeholder will unmount the placeholder block and render the search input explicitly in the DOM layer without absolute positioning overlaps.
- Listen for `onSelect` and tear down the search layer, swapping back to the selected item card.

### UI & UX Integration
- **Style Reset**: Eliminate the old `.floating-popover` classes and unify styling to use grid-flow row rendering.
- Maintain identical transition and border radiuses to the Multi-Select variation to prevent visual dissonance.
