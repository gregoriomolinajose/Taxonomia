# User Story: S44.2 - Extensión del Grafo de Capacidad

**Como** Arquitecto del Sistema
**Quiero** que el modelo del grafo universal acepte metadata numérica
**Para que** las células de trabajo puedan guardar explícitamente el porcentaje (%) de dedicación que una persona invierte en un rol específico para calcular sobrecargas.

## Acceptance Criteria

**Scenario 1: Conservación Semántica**
*Given* el esquema `Sys_Graph_Edges` de arquitectura
*When* se visualicen las entidades M:N
*Then* la arista debe contener opcionalmente los atributos `peso_capacidad` (número) y `resolucion_dinamica` permitiendo a una tabla satélite calcular el sumatorio de pesos.

**Scenario 2: Ontología correcta M:N (Hotfix)**
*Given* el modelo de Catálogos (Padre) e Instancias (Hijos)
*When* unamos a una persona y un rol
*Then* el `Rol` debe reportarse apuntando como Catálogo Central, resolviendo el antipatrón estructural previo.
