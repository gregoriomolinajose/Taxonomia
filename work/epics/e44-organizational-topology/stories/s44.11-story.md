# S44.11: Sincronización Programada y On-Demand (Workspace Sync)

## User Story

**As a** System Administrator
**I want** a background process that runs every 24 hours (with an on-demand trigger option)
**so that** any Persona record in the database missing Workspace information (e.g. `nombre`, `id_cargo`, `departamento`) is automatically queried and updated based on its `email`, ensuring the organizational topology stays up to date without manual intervention.

## Acceptance Criteria

```gherkin
Feature: Workspace Scheduled Synchronization

  Scenario: Execution of Daily Cron Job
    Given there are Persona records where the `nombre` or `id_cargo` is empty but the `email` is present
    When the 24-hour Google Apps Script Time-Driven Trigger fires
    Then the engine iterates through the missing records
    And invokes `resolverDirectorioWorkspace` for each `email`
    And natively patches the Persona using the `Engine_DB.update` layer
    And routes the `cargo` field through the Auto-Discovery mapping interceptor.
```

## Specification By Example

- Cuando el administrador lanza el proceso desde una hipotética Consola de QA (o se corre por defecto a las 2 AM):
- El script lee solo las Personas que están incompletas.
- Pasa la Data por el mismo flujo `Engine_ETL.hydrateAndDeduplicate()` o inyecta la solución directamente en un Batch Update.
