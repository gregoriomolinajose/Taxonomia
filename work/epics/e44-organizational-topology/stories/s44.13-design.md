# S44.13: Design

### Architecture & Data Model
- **Data Model**: Extend `hydrateAndDeduplicate` to explicitly act as the Graph Memory Array builder.
- Bypassing the nested object model instantiation, caching directly constructed arrays representing `Sys_Graph_Edges` relations.

### Business Logic & Flow
- **Memory Caching**: Array storage of `PERSONA_CARGO` nodes built structurally in O(1) runtime.
- Use atomic Bulk arrays instead of individual recursive iteration locks (`Engine_DB.orchestrateNestedSave`).
- Inject directly to the destination via a single nuclear `_Adapter_Sheets.upsertBatch` dump per mapping instance, shielding the Google App Script 6 minute limitation.

### UI & UX Integration
- Allow infinite scale capacity inside the Bulk ETL importer. No front-end logic changes require except loading bar optimization polling.
