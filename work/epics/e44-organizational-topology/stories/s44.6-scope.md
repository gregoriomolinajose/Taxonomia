# S44.6 Scope

## Boundaries

**In scope:**
- Modificar el Render HTML dentro del Web Component `<tx-searchable>` en Vanilla Javascript para inyectar su estado "Inline List" tanto en `multiple` como en `!multiple`.
- Ajustar la lógica del Desktop Flow `executeSearchAndOpen` para no exigir `this._isMultiple` como requisito al modo Inline.
- Actualizar el click-handler individual en Single Mode para que respete el cierre del `this._inlineMode` y su renderizado local, sin recurrir a llamadas de `.dismiss()` a Nodos de Popover inexistentes.

**Out of scope:**
- Modificación visual de las Opciones Mobile. Las vistas en teléfonos mantendrán el comportamiento de Modal/BottomSheet actual ya que es idóneo para móviles pequeños.
- Modificación del componente Legacy Grid `UI_SubgridBuilder.client.js`. Sólo afecta a `TXSearchable`.
