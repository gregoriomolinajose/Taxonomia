# Architecture Review: S44.9 Mapeo Automático de Ingesta (Cargo Workspace Interceptor)

**Target:** Epic E44 / Story S44.9
**Type:** System Architecture Review (SAR)

## 1. Contexto Teórico

La S44.9 exige interceptar el flujo natural de Ingesta (ya sea vía webhooks iterativos, descargas masivas ETL, o sincronizaciones `Job_WorkspaceSync.js`) para capturar la propiedad huérfana de `cargo` (un string raw, ej. "411" o "Gerente"), cruzarla contra el diccionario maestro estructurado en S44.8, y permutar el payload inyectándole el UUID orgánico (`CARG-[...]`) antes de que este alcance la capa final de persistencia O(1).

## 2. Evaluación Heurística (Beck's Four Rules)

### ✅ Rule 1: Pasa las pruebas de exactitud y control (Correctness)
El motor intermedio de traducción anulará por completo los errores de inconsistencia relacional (Constraint Violations) en `Sys_Graph_Edges`. Al transmutar transparentemente el string en un Arista válido `id_cargo`, garantizamos que la topología histórica SCD-2 funcione sin generar Nodos fantasmas.

### ✅ Rule 2: Revela la Intención (Semantic Accuracy)
Colocar la resolución explícitamente en el canal de Hidratación (Middlewares de ETL y Background Jobs) preserva a la Capa de Interfaz y Formularios pura (Dumb UI). La UI confía en que los datos que le llegan ya son referencias viables o vacíos limpios. La manipulación de datos pertenece a la plomería del backend.

### ✅ Rule 3: Eliminación de Duplicación (DRY)
Construir un mapa temporal en memoria `{ "411": "CARG-..." }` al inicio del `Bulk Upload` o del Sincronizador previene cientos de consultas cíclicas (Select WHERE id=411) a la base de datos de Sheets, reduciendo el I/O exponencialmente. 

### ✅ Rule 4: Minimiza los Elementos (Lean Rules)
El diseño evita la creación de tablas transversales adicionales o módulos mastodónticos de Parsing. El uso programático de las utilidades de `Cache_Utils` apoyando a `Job_WorkspaceSync.js` o el `ETL_Runner` es económicamente elegante y de altísima mantenibilidad.

## 3. Dictamen Final

**[APPROVED]**
El interceptor cumple a rajatabla todas las pautas de alto desempeño y acoplamiento defensivo, salvaguardando la fragilidad de I/O dentro de Google Workspace y Google Apps Script (Cuotas/Quotas).
