# S44.10: Migración Masiva de Roles Legacy a Topología de Grafos

## User Story

**As a** System Administrator / Data Engineer
**I want** to execute a bulk migration on the legacy `DB_Persona` data structure
**so that** the flat, deprecated `rol_agil` string fields are correctly transformed into properly linked topological Nodes (`Rol`) natively integrated into the `Sys_Graph_Edges` structure, enabling the Capacity Map to display accurate cross-team leadership assignments.

## Acceptance Criteria

```gherkin
Feature: Bulk Topology Migration

  Scenario: Extracting Legacy Roles
    Given the legacy database state where `Persona` records harbor plain strings in `rol_agil`
    When the ETL/Migration Script is executed
    Then it must identify and map standard text strings (e.g., "Scrum Master", "Product Owner")
    
  Scenario: Edge Forging
    Given the successful extraction of a role match
    When the processor reaches the structural stage
    Then it must provision or resolve the UUID pointer of that `Rol`
    And natively write an Edge into `Sys_Graph_Edges` connecting the Persona to the Rol using `PERSONA_ROL`
    And safely nullify or flag the old `rol_agil` origin trace to prevent double-processing.
```
