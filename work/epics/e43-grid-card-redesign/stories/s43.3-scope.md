# S43.3 Scope

## Boundaries

### In Scope
- Aplicación de propiedades CSS de truncamiento (`text-overflow: ellipsis`, `overflow: hidden`, `white-space: nowrap`) para el subtítulo/descripción y etiquetas de jerarquía.
- Limitación estricta de las líneas del título a 2 (`-webkit-line-clamp: 2` o equivalente).
- Control de flex-shrink/flex-grow en los elementos hijos del botón de jerarquía para evitar desbordamiento del ancho principal.

### Out of Scope
- Cambio estructural del Layout (mantenemos CSS Grid / Flexbox actual de la tarjeta base).
- Funcionalidad JavaScript del componente (solo atacamos diseño visual).

## Done Criteria
1. El título (Nombre) no sobrepasa las 2 líneas y, si es muy largo, muestra elipsis.
2. El departamento/barril (icono de documento + área) está truncado a 1 sola línea de manera estética sin empujar los elementos inferiores.
3. Los badges contenedores de grafos padre/hijos (Líder / Cargo) no se salen del límite horizontal de la tarjeta principal, elipsis interna aplicada exitosamente a sus textos internos.
