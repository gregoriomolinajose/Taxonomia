# Scope: S61.1 - IDataProvider Interface

## In scope
- Definir la interfaz `IDataProvider` con métodos genéricos para leer y escribir.
- Implementar un adaptador para Google Sheets que cumpla con `IDataProvider`.
- Refactorizar las referencias directas a `SpreadsheetApp` en la capa central del motor ETL para que consuman `IDataProvider`.
- Crear un `MockDataProvider` para permitir testing en memoria.

## Out of scope
- Mover la lógica dura de entidades a `APP_SCHEMAS` (pertenece a S61.2).
- Motor de validación centralizado (pertenece a S61.3).
- Implementación de colas de tareas asíncronas (pertenece a S61.4).
- Soporte para otros orígenes físicos (ej. Excel, S3, FTP).

## Done when
- [ ] La interfaz `IDataProvider` está completamente definida.
- [ ] La clase `GoogleSheetsProvider` encapsula todas las llamadas a `SpreadsheetApp`.
- [ ] El núcleo del ETL no tiene dependencias directas de Google Apps Script.
- [ ] Se puede instanciar el ETL con un proveedor mock en memoria y ejecutar pruebas unitarias.
- [ ] El código cuenta con anotaciones de tipos.
- [ ] Los tests pasan y los quality checks son exitosos.
