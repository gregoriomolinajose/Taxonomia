# Story S61.17: Fail-fast Validation UI Integration

## Implementation Plan

### Task 1: Update `updateProgress` to preserve DOM
- Open `src/UI_Component_BulkImporter.client.js`.
- Modify `updateProgress` to not use `this.containerNode.innerHTML = ...`.
- Instead, use a wrapper `.etl-progress-wrapper` and hide the original children.

### Task 2: Defer progress and handle button state
- In `_defaultDriveSync`, capture the original button text.
- Disable the button and change text to `<ion-spinner> Validando...`.
- Call `etl_extract_sheet_data`.
- If successful, restore button and call `updateProgress(0, ...)`.

### Task 3: Error Handling
- In the `catch` block of `_defaultDriveSync`, restore the button state.
- Remove the `.etl-progress-wrapper` and unhide the original form elements.
- Look for `Formato Estricto Incompatible` in the error message.
- If present, set the `error-text` on the `#etl-drive-url` input and add `ion-invalid`.

### Task 4: Deployment
- Run `npm run deploy:staging:auto` to push changes.
