# Story: Centralized Validation

## User Story
As a developer,
I want a centralized ValidationEngine based on schema definitions,
so that I can consistently validate data during both ingestion and UI interactions.

## Acceptance Criteria

### Scenario: Validating ingestion data
```gherkin
Given a set of data rows for ingestion
When the data is passed to the ValidationEngine
Then it validates the data against the corresponding schema
And returns valid rows and a list of validation errors for invalid rows
```

### Scenario: Validating UI interactions
```gherkin
Given a user editing data in the UI
When the data is passed to the ValidationEngine
Then it validates the data against the corresponding schema
And returns instant feedback for validation errors
```

## Examples (Specification by Example)

| Input | Action | Expected Output |
|-------|--------|-----------------|
| Row missing required field | ValidationEngine.validate(row) | Validation error for missing field |
| Row with correct fields | ValidationEngine.validate(row) | No errors |
