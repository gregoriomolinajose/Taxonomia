# S61.8: Pre-flight check de Workspace en ETL

**As a** System Administrator
**I want** to see a clear warning and have the ability to test the Google Workspace connection before importing "Persona" data
**so that** I don't accidentally ingest records that cannot be hydrated with critical business data (like Manager, Title, or Department) due to connection failures.

## Acceptance Criteria
- Given I select "Persona" in the ETL UI, if `WORKSPACE_ENABLED` is false, I should see a warning block.
- Given the warning block is visible, the "Cargar Registros" button must be disabled (Hard-Block).
- Given the warning block is visible, there should be a "Probar Conexión" button.
- When I click "Probar Conexión", it should invoke `testWorkspaceConnection` on the backend.
- If the test succeeds, the warning should disappear and the upload buttons should be enabled.
- If the test fails, an error toast should be shown and the block remains.
