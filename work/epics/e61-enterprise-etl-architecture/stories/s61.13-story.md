# Story S61.13: CacheSignal Limits & ETL Logs

## User Story
As a developer,
I want to ensure that CacheSignals respect the 100KB CacheService size limit by pruning old signals and logging `null` appropriately during ETL.

## Acceptance Criteria
- In `Engine_DB.js`, `_checkCacheSignals` reduces the `signals` array to only the single most recent signal (largest `invalidated_at`) for each unique `entity_name` + `by_tenant` combination before caching.
- In `Engine_ETL.js`, if the db search does not find a match, `matchedRow` explicitly assigns `null` instead of `undefined` for evaluation keys logging.
