# Scope: S61.6 Enhanced ETL Progress UX

## Boundaries

**In scope:**
- Modify `Job_Worker.js` to emit detailed status messages (e.g., "Validating 30 records", "Writing to database").
- Enhance `UI_Component_BulkImporter.client.js` to render these sub-status messages clearly in the progress modal.
- Ensure the progress modal handles transitions (start -> extracting -> queued -> polling -> finished) without sudden visual drops.
- Implement a final success/summary view that stays on screen until the user acknowledges it.

**Out of scope:**
- Sending email notifications or push notifications.
- Changing the underlying chunking logic or data structures.

## Done Criteria
- [ ] Users see a clear message indicating data extraction has started immediately after clicking "Cargar".
- [ ] Polling displays human-readable micro-statuses (e.g., "Procesando lote 1...").
- [ ] Upon 100% completion, a summary screen replaces the progress bar showing total inserted/failed, requiring a "Cerrar" button to dismiss.
- [ ] Code has type annotations, tests pass, and quality checks pass.
