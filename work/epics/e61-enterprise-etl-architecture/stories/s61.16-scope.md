# Story S61.16: Fail-fast Schema Format Validation — Scope

## Boundaries

**In scope:**
- Add format validation to `Engine_ETL.extractDataFromDrive`
- Throw an explicit error when `maxOverlap <= 0`

**Out of scope:**
- Modifying the core mapping logic or schema definitions
- Implementing a mapping UI for users

## Done Criteria

**Done when:**
- An Error is thrown for completely incompatible files.
- The validation is fast and prevents unnecessary processing.
