# Scope: S61.4 Async Job Processing

## Boundaries

**In scope:**
- Implementar cola de tareas / jobs asíncronos en el backend (Google Apps Script).
- Lógica de chunking para respetar el límite de 6 minutos de ejecución de GAS.
- Endpoint de encolamiento y endpoint de polling de estado.
- Mecanismo de polling en el frontend (UI).
- Estructura de datos para enviar errores a la Dead Letter Queue (DLQ).

**Out of scope:**
- UI de visualización y resolución de conflictos de la DLQ (Eso corresponde a la historia S61.5).

## Done Criteria

- [ ] Se puede encolar un trabajo de importación masiva y el frontend recibe un ID inmediatamente.
- [ ] El backend procesa los registros asíncronamente en chunks (para evitar límite de 6 min).
- [ ] El frontend muestra el progreso consultando periódicamente el estado.
- [ ] Los registros erróneos son guardados en una estructura de DLQ.
- [ ] Carga de prueba de 10,000 registros exitosa sin timeout.
- [ ] Code with type annotations, Tests passing, Quality checks pass (ruff, pyright/eslint/tsc).
