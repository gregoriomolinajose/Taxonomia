# Story S61.16: Fail-fast Schema Format Validation

## User Story

**As a** system user uploading Google Sheets data
**I want** the system to immediately reject files with completely incorrect headers
**So that** I don't waste time processing or debugging a completely invalid file upload

## Acceptance Criteria

**Scenario:** Uploading a file with completely unmatching headers
**Given** the user selects a Google Sheet to upload
**And** the headers in the sheet do not match the expected schema at all (maxOverlap <= 0)
**When** the extraction process begins in `Engine_ETL.extractDataFromDrive`
**Then** the system should immediately throw an Error "Formato Incompatible: Los encabezados del archivo no coinciden con la entidad..."
**And** the upload process should stop early
