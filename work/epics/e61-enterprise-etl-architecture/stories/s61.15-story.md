# Story S61.15: Intra-batch Deduplication Bugfix

## User Story

As a system using the Engine_ETL,
I want intra-batch duplicates to be correctly deduplicated even when they lack a UUID,
So that identical records uploaded in the same batch do not result in duplicated entries in the database.

## Acceptance Criteria

1. Given two identical new records in the same batch, the identity resolution correctly matches them.
2. Given a matched row that lacks a UUID (`pkField`), the engine merges information and drops the duplicate.
3. The database receives only one instance of the new record instead of multiples.
