# Design: S61.8 - Pre-flight check de Workspace en ETL

## Architecture
- **Frontend (`UI_Component_BulkImporter.client.js`)**: Injects a hidden `div` container for the alert. During `render()`, it evaluates the `window.AppEnv.WORKSPACE_ENABLED` flag. If it's falsy, the `div` is shown, and the execute buttons are disabled.
- **Backend (`Engine_Workspace.js`)**: Exposes `testWorkspaceConnection()`. This function reads `_getWorkspaceConfig()`, checks if `syncEnabled` is true, and performs a test call. For the Webhook mode, it pings the endpoint. For Native mode, it executes `AdminDirectory.Users.list({maxResults: 1})`.

## Interactions
1. User selects "Persona" in ETL UI.
2. System evaluates environment flag.
3. System blocks UI if disconnected.
4. User clicks "Probar Conexión".
5. Backend attempts live API call.
6. Frontend receives `{status: 'success'}` and unlocks UI, or `{status: 'error'}` and shows Toast.
