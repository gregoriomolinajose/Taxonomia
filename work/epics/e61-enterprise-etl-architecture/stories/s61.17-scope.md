# Story S61.17: Fail-fast Validation UI Integration

## Boundaries

**In Scope:**
- Deferring the progress UI transition until the `etl_extract_sheet_data` API returns success.
- Adding a loading state to the `#btn-sync-drive` button.
- Restoring the button state if validation fails.
- Catching the "Formato Estricto Incompatible" error and injecting a user-friendly message into the `<ion-input id="etl-drive-url">` `error-text` attribute.
- Ensuring the original form UI is not destroyed by the progress container so that it can be reverted to safely.

**Out of Scope:**
- Modifying the server-side validation logic (already completed in S61.16).
- Adding new UI components to the importer.

## Done Criteria
- [x] When clicking "Cargar Registros", the UI stays on the form and the button shows "Validando...".
- [x] If validation fails with "Formato Estricto Incompatible", the button resets and the URL input shows the error message in red.
- [x] If validation passes, the progress wizard is displayed.
- [x] The form UI is safely preserved and not destroyed when showing the progress UI.
