# S61.6: Enhanced ETL Progress UX

## User Story

**As a** business user importing bulk data
**I want** to see detailed, human-readable status messages and exact progress metrics during the load process
**So that** I understand exactly what the system is doing, don't feel anxious about a frozen screen, and can trust the asynchronous job execution.

## Acceptance Criteria

**Scenario 1: Detailed initialization feedback**
- **Given** I initiate a bulk import
- **When** the system starts extracting data from the spreadsheet
- **Then** I should see a clear message indicating "Leyendo archivo y preparando datos..." instead of a generic loading spinner.

**Scenario 2: Real-time asynchronous processing feedback**
- **Given** the job has been queued and the frontend is polling
- **When** the backend updates the job status
- **Then** the progress UI should display specific sub-status messages (e.g., "Procesando lote 1 de 3 (33%)", "Validando registros...", "Guardando en base de datos...").

**Scenario 3: Final state resolution**
- **Given** the job finishes
- **When** the progress reaches 100%
- **Then** the UI should transition smoothly to a success summary (or error summary) without abrupt disappearing modals.
