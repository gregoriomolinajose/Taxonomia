# Story S61.2: Metadata Hooks Engine

## User Story
Como desarrollador de la plataforma Taxonomía,
Quiero que las reglas de transformación y pre-procesamiento (hooks) se definan dinámicamente en el esquema de cada entidad,
Para que el motor ETL central (`Engine_ETL.js`) sea agnóstico a las reglas de negocio específicas de entidades como "Dominio" o "Persona".

## Acceptance Criteria
- El motor ETL no debe contener bloques `if (entityName === 'Dominio')` u otros condicionales *hardcodeados* para limpieza o mapeo de datos.
- `APP_SCHEMAS` debe soportar la declaración de un objeto `etlHooks` con callbacks como `onRowTransform` o `onBeforeImport`.
- Durante la ingestión masiva, el `ETLEngine` debe invocar estos hooks si están definidos para la entidad que se está importando.
- La lógica *hardcodeada* heredada en `Engine_ETL.js` para dominios o diccionarios debe eliminarse y trasladarse al esquema correspondiente.
