# Story S61.17: Fail-fast Validation UI Integration

## User Story

**As a** system user uploading Google Sheets data
**I want** the system to validate the file format before showing the progress wizard
**So that** if there is a schema error, I am notified immediately on the input field without losing the context of my form.

## Acceptance Criteria

**Scenario:** Uploading an invalid schema file
**Given** the user selects a Google Sheet to upload with an invalid format
**When** the user clicks "Cargar Registros"
**Then** the button should show a "Validando..." spinner
**And** the UI must not transition to the progress wizard
**And** upon receiving the "Formato Estricto Incompatible" error from the server
**Then** the URL input field should turn red and display the error message "El archivo ingresado no coincide con el formato de la plantilla para '[Entidad]'"
**And** the "Cargar Registros" button should be restored to its original state.

**Scenario:** Uploading a valid schema file
**Given** the user selects a valid Google Sheet
**When** the user clicks "Cargar Registros"
**Then** the button shows a "Validando..." spinner
**And** upon successful validation, the UI transitions to the progress wizard to queue the jobs.
