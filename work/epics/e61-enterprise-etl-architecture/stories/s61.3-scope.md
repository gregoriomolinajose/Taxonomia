# Scope: S61.3 Centralized Validation

## Boundaries

**In scope:**
- Crear ValidationEngine basado en esquema para ingesta y UI.
- Validar reglas usando las propiedades del esquema (`APP_SCHEMAS`).
- Retornar formato estandarizado de errores de validación.

**Out of scope:**
- UI components para mostrar los errores (se difiere a S61.5 DLQ UI).
- Jobs asíncronos (se difiere a S61.4).
