# Story S61.13 Scope

## In scope:
- Updating `_checkCacheSignals` in `Engine_DB.js` to prune CacheSignals before saving to cache.
- Ensure only the single most recent signal per `entity_name` and `by_tenant` combination is kept.
- Updating `Engine_ETL.js` to assign `null` to `matchedRow` if no DB match is found.

## Out of scope:
- Other caching mechanisms.
- Other ETL logs outside of `matchedRow` null assignment.

## Done when:
- The `signals` array is properly filtered before `cache.put`.
- `matchedRow` is strictly `null` in case of an empty DB search match.
- Code is pushed and validated via the `rai-story-run` process.
