# Story S61.2: Metadata Hooks Engine - Scope

## Boundaries

**In scope:**
- Definición de la estructura de `etlHooks` en la especificación de `APP_SCHEMAS`.
- Migración de la lógica dura de `Dominio` (y cualquier otra entidad detectada en `Engine_ETL.js`) hacia sus respectivos esquemas.
- Integración del ejecutor de hooks dentro del `ETLEngine` para que invoque `onRowTransform` en la fase de mapeo/hidratación.

**Out of scope:**
- Implementación de hooks que realicen llamadas externas a otras bases de datos (se mantienen como hooks puros sincrónos).
- El motor de validación estricta de tipos de datos (esto pertenece a S61.3).

## Done Criteria
- [ ] No existen bloques condicionales ligados a los nombres de entidades en el código base de `Engine_ETL.js` para transformaciones de columnas.
- [ ] El esquema de `Dominio` incluye su `onRowTransform` mapeando nombres históricos de columnas en el Excel.
- [ ] Tests actualizados pasando verde.
