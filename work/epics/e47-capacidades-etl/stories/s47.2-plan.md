# S47.2 Implementation Plan

## Overview
Transform the flat `record` payload arrays generated in S47.1 into a deduplicated, hierarchical array of individual nodes using an O(1) Hash Map approach, and assign their topology using `Math_Engine`.

## Tasks

### T1: Augment Math_Engine for O(1) Arrays
1. Open `src/Math_Engine.html`.
2. Modify `buildOrdenPath` to check if `cache` is an object with `nodesById` and `childrenCount` properties.
3. If it is, use `cache.nodesById.get(idPadre)` instead of `safeCache.find(...)` and `cache.childrenCount.get(idPadre)` instead of `safeCache.filter(...)`.
4. Ensure backward compatibility if `cache` is a standard Array.

### T2: Build Deduplication Hash Map Algorithm
1. Open `src/DataEngine_ETL_Capacidades.client.js`.
2. Create `nodesMap`, and `fastCache = { nodesById: new Map(), childrenCount: new Map() }`.
3. Construct unique keys for each level (e.g., `M:Nombre`, `C:Macro|||Capacidad`, etc.).
4. Extract unique entities. As they are created, assign them a virtual `_id` (`Crypto.randomUUID()` or simple counter string).

### T3: Integrate Math_Engine Topology Calculation
1. As each node is added to the `nodesMap`:
    - Assign `id_dominio_padre` using the parent's virtual `_id`.
    - Compute `_order_path` calling `window.Math_Engine.buildOrdenPath(nodo, params, fastCache)`.
    - Compute `_path_completo_es` calling `window.Math_Engine.buildPathName(nodo, params, fastCache)`.
    - Register the node in `fastCache.nodesById`.
    - Increment the parent's counter in `fastCache.childrenCount`.
2. Build the final flat array of nodes `Array.from(nodesMap.values())`.

### T4: Return Valid Array & Logging
1. Ensure the generated array is logged to console and resolved by the promise.
