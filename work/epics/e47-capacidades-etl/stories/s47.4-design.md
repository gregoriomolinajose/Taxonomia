# Design S47.4: Integración Drive-Capacidades

## Concept
En vez de reconstruir la lógica de importación jerárquica O(1) de Capacidades dentro de la extracción remota (Google Sheets), extendemos la extracción del backend `Engine_ETL.extractDataFromDrive` para que acepte un modo "matriz cruda" (`rawMatrix`). Esto elude la suposición de que la primera fila es un encabezado y simplemente devuelve la grilla de datos intacta.

En el cliente, extraemos la lógica de parsing de `DataEngine_ETL_Capacidades` a un nuevo método agnóstico de I/O llamado `_processMatrix`. Este método asume que recibe un array 2D y realiza el mapeo de nodos en memoria sin importar el origen. Finalmente, el UI intercepta la carga si la entidad es `Capacidades` y llama a `_processMatrix`.

## Module Changes
1. **Engine_ETL.gs**: Modificar la firma de `extractDataFromDrive(entityName, url, options)` para que si `options.rawMatrix === true`, retorne los valores 2D crudos sin parsearlos a un array de diccionarios.
2. **API_Universal.js**: Modificar `etl_extract_sheet_data` para extraer las opciones enviadas en el payload.
3. **DataEngine_ETL_Capacidades.client.js**: 
   - Extraer contenido de la lectura de archivos hacia `_processMatrix(entityName, jsonRaw, options)`.
   - Modificar `processFile` para que llame a `_processMatrix` tras utilizar el FileReader con la librería SheetJS.
4. **DataView_UI.client.js**: En `onDriveSync`, evaluar si la entidad es Capacidades. En tal caso, pasar `{ rawMatrix: true }` y delegar en `window.DataEngine_ETL_Capacidades.processMatrix` en lugar del genérico.

## Traceability
* Resuelve: Restricción de Ingestión Masiva por Sincronización en Entidad Jerárquica.
* Alineación: Minimiza el duplicado de código aislando en `_processMatrix` la única regla de negocio.
