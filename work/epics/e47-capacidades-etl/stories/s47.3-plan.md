# S47.3 Implementation Plan

## Overview
Connect the deduplicated and topologized array (`finalPayloads`) from `DataEngine_ETL_Capacidades` to the native `DataEngine_ETL._dispatchChunks` function, providing real-time feedback to the UI.

## Tasks

### T1: Wire `_dispatchChunks` Integration
1. Open `src/DataEngine_ETL_Capacidades.client.js`.
2. Delete the temporary "S47.2 se considera terminada" code block at the end of `processFile`.
3. Check if `window.DataEngine_ETL` and `_dispatchChunks` exist.
4. If available, construct a wrapper callback for progress:
   ```javascript
   const progressCallback = (chunk, total, isDone, metrics, text) => {
       if (window.UI_ETL_Modal && window.UI_ETL_Modal.updateProgress) {
           window.UI_ETL_Modal.updateProgress(chunk, total, isDone, metrics, text);
       }
       if (isDone && window.UI_ETL_Modal && window.UI_ETL_Modal.showResults) {
           window.UI_ETL_Modal.showResults(metrics || { success: finalPayloads.length, duplicate: 0, error: 0 });
       }
   };
   ```
5. Invoke `await window.DataEngine_ETL._dispatchChunks(finalPayloads, entityName, progressCallback)`.
6. Return/Resolve the final payloads.

### T2: Handle Edge Cases
1. In the `.catch` or error blocks of `_dispatchChunks`, call `showResults({ success: 0, duplicate: 0, error: finalPayloads.length })` to visually indicate total failure if the GAS endpoint times out or crashes.
2. Ensure the fallback behavior remains if `_dispatchChunks` is somehow missing (for decoupled testing).
