# S47.3: Database Batch Dispatch

## User Story
**Como** usuario final
**Quiero** que los datos jerárquicos extraídos del Modelo de Capacidades se guarden en la base de datos de Taxonomía
**Para** que la vista de Árbol y el Datagrid reflejen inmediatamente la información sin bloquear la interfaz.

## Acceptance Criteria
1. El arreglo topológicamente procesado en `DataEngine_ETL_Capacidades.client.js` debe utilizar el mecanismo nativo `_dispatchChunks` de `DataEngine_ETL.client.js`.
2. Los registros deben insertarse respetando la lógica de inserción actual (chunks asíncronos), delegando el payload al backend (GAS).
3. La interfaz visual (`UI_ETL_Modal`) debe reflejar el progreso de la subida a medida que los baches responden.
