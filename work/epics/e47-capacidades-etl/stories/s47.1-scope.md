# S47.1 Scope: UI File Interception & Offset Parser

## In Scope
- Lógica de detección (sniffing) en `UI_ETL_Modal.client.js` u homólogo para detectar la estructura "Modelo de Capacidades 2.0".
- Adaptación/incorporación de librería `SheetJS (XLSX)` o lógica equivalente si se requiere nativo en `.xlsx`, o en su defecto, procesamiento correcto de CSV generado a partir del Excel.
- Parser `DataEngine_ETL_Capacidades` (o nueva función dentro de `DataEngine_ETL`) con offset desde la Fila 6.
- Algoritmo de Fill-Down para heredar celdas vacías (agrupadas verticalmente).

## Out of Scope
- Lógica matemática de `order_path` y `path_completo_es` (Pertenece a S47.2).
- Construcción de índice O(1) para cálculo de herencia topológica (S47.2).
- Inyección masiva hacia Google Workspace/Drive (S47.3).

## Done Criteria
- [ ] El sistema intercepta el archivo, loguea "Modo Capacidades Activado".
- [ ] El sistema ignora las primeras 5 filas (Logos y Títulos).
- [ ] El arreglo resultante muestra Componentes (hojas) con sus propiedades Macro, Capacidad y Subcapacidad correctamente rellenadas (sin `null` o espacios vacíos incorrectos).
