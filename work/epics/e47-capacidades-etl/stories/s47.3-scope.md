# S47.3 Scope: Database Batch Dispatch

## In Scope
- Integrar la salida `finalPayloads` de `DataEngine_ETL_Capacidades` con la función `window.DataEngine_ETL._dispatchChunks`.
- Asegurar que la modal se actualice con la cantidad de filas a procesar y los eventos de "éxito" (`showResults`).
- Tratar los `_id` como temporales (para relaciones entre los nodos en la tabla) si es posible que el backend los inserte masivamente, o dejar que `_dispatchChunks` llame al endpoint tradicional de GAS.

## Out of Scope
- Reescritura del algoritmo de persistencia backend (`Engine_DB`). El script asume que la función de API remota `ETL_IngestBulk` o el pipeline estándar se encargará de guardarlo.

## Done Criteria
- [ ] La barra de carga del ETL reacciona al envío masivo.
- [ ] Los registros aplanados llegan al backend y son persistidos de manera segura.
