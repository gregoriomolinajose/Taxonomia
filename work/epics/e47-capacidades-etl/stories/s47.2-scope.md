# S47.2 Scope: Graph Flattening & Math_Engine Consumption

## In Scope
- Lógica de aplanamiento de matriz a objetos individuales en `DataEngine_ETL_Capacidades`.
- Invocación de `window.Math_Engine.buildOrdenPath` y `window.Math_Engine.buildPathName`.
- Implementación de un Hash Map (`cacheNiveles` o similar) como caché O(1) de hermanos/padres previos durante el parseo iterativo.
- Transformación final a un arreglo de objetos compatible con el backend de Taxonomía.

## Out of Scope
- Lógica de lectura nativa de XLSX o interceptación de eventos UI (Ya cubierto en S47.1).
- Inyección asíncrona hacia Google Workspace mediante `_dispatchChunks` (S47.3).
- Modificación estructural profunda a `Math_Engine.html` (Solo se consume).

## Done Criteria
- [ ] El array resultante (`jsonPayloads`) imprime en consola registros correctos de Capacidades.
- [ ] Cada registro posee propiedades topológicas (`_nivel`, `_order_path`, `_path_completo_es`).
- [ ] El rendimiento es sub-segundo incluso para miles de filas gracias al caché Hash Map, evitando degradación de CPU.
