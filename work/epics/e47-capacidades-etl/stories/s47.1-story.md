# S47.1: UI File Interception & Offset Parser

## User Story
**Como** arquitecto de datos empresariales
**Quiero** subir el catálogo corporativo de Capacidades (Modelo de Grupo 2.0) al portal sin tener que reformatear el Excel a un formato plano complejo
**Para** poder actualizar la topología del negocio de forma masiva y autónoma manteniendo su legibilidad jerárquica original.

## Acceptance Criteria
1. **Detección Automática:** Al soltar el archivo en el modal de importación actual, el sistema debe detectar (por nombre de columnas o título en las primeras filas) que se trata del formato especial de capacidades.
2. **Ignorar "Paja":** El parser debe saltarse los logos y títulos iniciales y comenzar a parsear datos desde la Fila 6.
3. **Memoria Vertical (Fill-Down):** Cuando el parser lee celdas vacías debajo de una "Macrocapacidad" o "Capacidad", debe auto-completarlas heredando el valor del último padre válido, de tal forma que no se rompan las ramas hijas.
4. **Validación Temprana:** La historia se considerará terminada si el parser es capaz de imprimir en consola el arreglo plano de objetos correctos (walking skeleton), aún sin auto-generar las llaves matemáticas (que pertenecen a S47.2).
