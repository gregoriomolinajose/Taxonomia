# S47.1 Design: UI File Interception & Offset Parser

## 1. What & Why
**Problem:** The current generic ETL modal expects CSVs with a 1:1 schema mapping and a single header row. The new Capacidades file is an XLSX with a 5-row header offset and merged cells representing hierarchy.
**Value:** By sniffing the file and using a specialized parser, the user experience remains "drag-and-drop" without needing manual Excel formatting or a secondary button. 

## 2. Approach
- **UI File Interception (`UI_ETL_Modal.client.js`):** Modify the drag-and-drop listener to read the file name or use a lightweight FileReader slice to detect if it's the "Modelo de Capacidades". If so, route it to `DataEngine_ETL_Capacidades.processFile`.
- **Parser (`DataEngine_ETL_Capacidades.client.js`):** We will create a new class/object matching the interface of `DataEngine_ETL.client.js`. It will use `SheetJS` (available via CDN `xlsx.full.min.js` which needs to be added to `Index.html` if not present) to read the `.xlsx` natively.
- **Offset & Fill-Down Logic:** The parser will skip rows 0-4. Row 5 contains the headers. Rows 6 onwards contain data. We maintain memory variables `lastMacro`, `lastCapacidad`, `lastSubcapacidad`. If a cell in those columns is falsy/empty, it inherits the memory.

## 3. Examples
**Scenario 1: Uploading standard file**
- User drops `empleados.csv`.
- System routes to standard `DataEngine_ETL.processFile`.

**Scenario 2: Uploading Capacidades XLSX**
- User drops `Modelo de Capacidades de Grupo 2.0 VF.xlsx`.
- System routes to `DataEngine_ETL_Capacidades.processFile(file, 'Capacidades', callback)`.
- Parser uses SheetJS to convert to JSON starting from row 6.
- Fill-Down logic ensures that if row 7's 'Capacidad' cell is empty, it inherits row 6's 'Capacidad'.
- `console.log` shows the flattened array with inherited values.

## 4. Acceptance Criteria
- **MUST:** Detect the Capacidades file automatically.
- **MUST:** Read the XLSX file natively without forcing the user to convert to CSV.
- **MUST:** Read headers starting at row 6.
- **MUST:** Properly fill down missing values from parent nodes.
- **MUST NOT:** Call `Math_Engine` logic (that belongs to S47.2).
