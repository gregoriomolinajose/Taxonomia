# Story Plan: S51.8 Visual Taxonomy Builder Canvas

## T1: Schema Simplification (Schema_Engine.js)
- Remove `id_portafolio` and `grupos_productos` from `Taxonomia` schema.
- Retain `id_unidad_negocio` in `Taxonomia` to link the root.

## T2: UI Canvas Component (UI_View_TaxonomyCanvas.client.js)
- Create `UI_View_TaxonomyCanvas.html` and `.client.js`.
- Implement ECharts Tree generation based on `Sys_Graph_Edges`.
- Implement dynamic node rendering (fetching Taxonomia, Portfolios, and Product Groups).

## T3: UI Routing & DataGrid Actions
- Update `UI_Router.client.js` to handle `#taxonomia/canvas/:id`.
- Update `SelfService_Home_UI.client.js` or `UI_DataGrid.client.js` to add a new Row Action: "Diseñar Jerarquía" (icon: `git-merge-outline` or `git-network-outline`) that triggers the canvas route.

## T4: Interaction Popover & Mutations (API_Universal.js + View)
- Implement `chart.on('click')` logic in the Canvas to open a Popover.
- Inside the popover, render `UI_Factory.buildSearchableMulti()` pointing to the correct child entity (Portafolio if clicking UN, Grupo si clicking Portafolio).
- Expose a new GAS RPC `RPC_ContextualGraphBuilder.upsertNodes(contextId, parentId, relationType, targetNodeIds)`.
- Re-render the Canvas upon successful mutation.

## T5: Testing & E2E Validation
- Validate root UN injection.
- Validate adding 2 Portfolios to 1 UN.
- Validate adding 3 distinct Groups to Portfolio A, and 2 distinct Groups to Portfolio B.
- Validate visually that the Tree separates them perfectly.
