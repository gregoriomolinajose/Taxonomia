# Story S59.1: Schema OAuth Delegation

## User Story
Como arquitecto del sistema
Quiero que la entidad `Config_Workspace` almacene tokens de delegación OAuth y switches de activación
Para preparar la base de datos para la autenticación transversal de dominios.

## Acceptance Criteria
1. Se añade el campo booleano `activar_consulta_directorio`.
2. Se añade `OAUTH_DELEGATION (Google Consent)` a las opciones de `auth_mode`.
3. Se añade el campo encriptado/seguro `refresh_token_autorizado`.
