# Story S59.0: Limpieza y Fix Dominios

## User Story
Como administrador de Taxonomía
Quiero que el sistema valide correctamente los dominios ignorando espacios en blanco y lea de una sola fuente de verdad
Para que los dominios válidos no reboten y el código sea mantenible.

## Acceptance Criteria
1. El login aplica `.trim()` a todos los dominios evaluados.
2. `Global_Config.gs` ya no define `ALLOWED_DOMAINS` estáticos.
