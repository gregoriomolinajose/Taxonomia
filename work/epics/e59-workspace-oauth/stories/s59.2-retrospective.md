# S59.2 Retrospective

## What went well
- La arquitectura de plugins para UI Components permitió inyectar `UI_Component_OAuthDelegation` sin modificar el `FormRenderer` profundamente, aislando la lógica de Google Identity Services.
- El evento local `FIELD_CHANGED` del `eventBus` hizo muy sencilla la interacción reactiva (mostrar/ocultar botón).

## Learnings
- **Inyección Transversal:** La variable `__OAUTH_CLIENT_ID__` inyectada desde `Code.js` hacia `Index.html` resolvió el problema de pasar variables de entorno de Backend a Frontend de manera segura, pero sin usar un request adicional asíncrono.
