# S45.5 - Optimización de Feedback Visual en Carga Masiva (ETL) E2E

## Descripción
Mejorar la experiencia de usuario (UX) durante el proceso de ingesta masiva y sincronización con Google Workspace (ETL). Actualmente, la interfaz modal muestra contadores estáticos de lotes y fases fraccionadas (ej. "1 de x" y luego "Workspace 1 de x"), lo cual puede generar la sensación de que el proceso se ha congelado debido a la falta de avance visual fluido.

## Objetivo
Unificar el progreso de la carga masiva en un único flujo de porcentaje continuo (0% a 100%) que describa verbalmente el progreso paso a paso de toda la cadena de valor (Parseo -> Hidratación -> Persistencia DB -> Interceptores -> Sincronización Workspace -> Refresco Topológico).

## Tareas
- [x] Modificar la función de progreso en `DataEngine_ETL.client.js` para unificar el cálculo de progreso total a nivel de porcentaje `(paso actual / total de pasos) * 100`.
- [x] Integrar el número de lote y fase dentro de mensajes descriptivos que informen qué está haciendo el sistema (ej. "Analizando y deduplicando lote 2 de 5...", "Sincronizando cuentas con Google Workspace...", "Guardando grafo relacional...").
- [x] Actualizar `UI_ETL_Modal.client.js` para que el spinner consuma el porcentaje de progreso de forma gráfica (o un texto de "0% completado"), manteniendo el UI responsivo.
