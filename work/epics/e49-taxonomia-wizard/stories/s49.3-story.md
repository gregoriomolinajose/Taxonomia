# Story: Creación de cascarón y rutas para el Portal Home de Negocio

## User Story
As un Cliente de Negocio / Owner,
I want to tener una pantalla de bienvenida (Home) independiente del área de administración,
so that pueda visualizar un resumen de mis Taxonomías y acceder a la opción de crear una nueva a través del Wizard interactivo.

## Acceptance Criteria

### Scenario: Acceso al Portal de Autoservicio
```gherkin
Given que el usuario inicia sesión en la plataforma
When la ruta de navegación apunta a la vista de cliente de negocio
Then se debe inicializar el componente `SelfService_Home_UI`
And el UI debe mostrar un diseño *premium* diferenciado (hero banner, tipografía, etc.)
And debe existir un botón de Call to Action principal (ej. "Diseñar Nueva Taxonomía").
```

### Scenario: Interfaz desacoplada
```gherkin
Given que el usuario está en el `SelfService_Home_UI`
When carga la vista
Then no se deben cargar las barras laterales administrativas (sidebar tradicional) ni componentes que requieran permisos ABAC completos.
```

## Notes
Esta historia se centra exclusivamente en el **cascarón visual** y la configuración de rutas en `UI_Router` o donde aplique. La integración del modal Fullscreen con el `FormRenderer` se ejecutará en la S49.4. El diseño debe cumplir con los lineamientos premium (vibrant colors, micro-animations, glassmorphism) según el Developer Profile.
