# Design: S49.5 Schema Completo y Testing End-to-End

## What & Why
- **Problem**: El contenedor UI Fullscreen (S49.4) invoca un esquema (`Wizard_Taxonomia`) que no existe en el registro central `Schema_Engine.js`, lo que produce una pantalla en blanco.
- **Value**: Proveer la capa de datos estructural. Esto habilita que los líderes funcionales puedan declarar el modelo de datos transversal.

## Approach
- **Declaración del Esquema Transaccional**:
  Se agregará la llave `Wizard_Taxonomia` al diccionario `APP_SCHEMAS`. Esta será una entidad "Dummy" a nivel transaccional (sus registros no viven como Nodos fuertes de taxonomía, sino como Entidades de orquestación, similares a un *Ticket* o *Formulario* que genera grafos).
- **Arquitectura de Stepper UI en Schema**:
  Usaremos el tag `form_stepper_stateful: true` en la configuración UI del schema.
  Se estructurará en `sections` múltiples:
  - Paso 1: Configuración Inicial (Nombre y Objetivo)
  - Paso 2: Dominio y Capacidades
  - Paso 3: Portafolio y Negocio
- **Relaciones Multiselección (Subgrids / Relations)**:
  Los campos de las etapas de selección de componentes usarán `type: "relation"` con `relationType: "M:N"` para usar el `UI_SubgridBuilder.client.js` nativo que permite búsqueda y selección masiva sin salir de la vista.

## Ejemplos
```javascript
"Wizard_Taxonomia": {
    label: "Diseño Organizacional",
    plural: "Diseños Organizacionales",
    icon: "business-outline",
    formMode: "stepper",
    form_stepper_stateful: true,
    sections: [
        {
            title: "Concepto Base",
            fields: [
                ...FIELD_TEMPLATES.NAME_FIELD("Nombre del Modelo"),
                { name: "descripcion", type: "textarea", label: "Justificación Estratégica", width: 12 }
            ]
        },
        {
            title: "Mapeo de Capacidades",
            fields: [
                { name: "rel_dominios", type: "relation", label: "Dominios Impactados", relationTarget: "Dominio", relationType: "M:N", width: 12 },
                { name: "rel_capacidades", type: "relation", label: "Capacidades Asociadas", relationTarget: "Capacidad", relationType: "M:N", width: 12 }
            ]
        }
    ],
    fields: [
        ...FIELD_TEMPLATES.SYSTEM_FIELDS(),
        { name: "id_registro", type: "hidden", primaryKey: true }
    ]
}
```
