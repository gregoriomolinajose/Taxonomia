# Design: S49.4 Vista Fullscreen / Inserción Wizard

## What & Why
- **Problem**: En S49.3 creamos la UI del portal, pero el botón principal no hace nada. Para que funcione como "Self Service", necesitamos que al darle click se despliegue el motor de `Wizard_Taxonomia` de manera aislada y enfocada. Inicialmente se consideró un modal, pero por temas de usabilidad y amplitud de trabajo se decidió usar una **Vista a Pantalla Completa**.
- **Value**: Completar la integración end-to-end (E2E) de la Epic M2, logrando que el portal sea funcional y ofrezca una experiencia inmersiva al usuario sin las limitaciones espaciales de un modal. Adicionalmente, el portal de bienvenida adopta una estética moderna de "Landing Page" estilo iOS (minimalista, tonos claros, desenfoque radial sutil).

## Approach
- **Enrutamiento Dedicado (`nav:wizard`)**:
  Dentro de `SelfService_Home_UI.client.js`, el listener de `#btn-start-wizard` delega la transición al `AppEventBus` llamando a `NAV::CHANGE` con `viewType: 'wizard'`.
  Se rediseñó el componente principal eliminando el Glassmorphism a favor de un fondo `Off-White` con orbes de gradiente difuso (blur 80px) al estilo Apple iOS, con tipografía robusta y un Call To Action sólido en contraste alto.
- **Renderizado Nativo en `UI_Router.client.js`**:
  Al detectar la ruta `wizard`, el enrutador limpia el DOM, desactiva la barra lateral (`when='false'`), inyecta un contenedor central optimizado y una cabecera nativa con un botón de retroceso (Cerrar).
- **Inyección de Dependencia (IoC)**:
  El enrutador llama a `window.FormRenderer_UI.renderForm('Wizard_Taxonomia', null, wrapper)` pasándole el contenedor en pantalla completa, aprovechando la capacidad *stateless* del motor para anidarse donde se le pida.
- **Escucha del Ciclo de Vida**:
  Se utiliza el bus de eventos global. `UI_FormSubmitter` publica `FORM::SUBMIT_SUCCESS` al guardar la data con éxito. El enrutador intercepta este evento y emite una redirección (`NAV::CHANGE` hacia `selfservice`) disparando a su vez una alerta Premium visualizando el éxito.

## Ejemplos
```javascript
// Transición en el Portal
btnStart.addEventListener('click', () => {
    window.AppEventBus.publish('NAV::CHANGE', {viewType: 'wizard'});
});

// Enrutador Nativo (UI_Router)
else if (viewType === 'wizard') {
    window.DOM.clear(container);
    const wrapper = document.createElement('div');
    container.appendChild(wrapper);

    let unsubscribe = window.AppEventBus.subscribe('FORM::SUBMIT_SUCCESS', (payload) => {
        if (payload.entityName === 'Wizard_Taxonomia') {
            window.AppEventBus.publish('NAV::CHANGE', {viewType: 'selfservice'});
        }
    });

    window.FormRenderer_UI.renderForm('Wizard_Taxonomia', null, wrapper);
}
```
