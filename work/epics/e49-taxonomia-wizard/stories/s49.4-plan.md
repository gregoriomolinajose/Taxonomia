# Implementation Plan: S49.4 Modal Fullscreen / Inserción Wizard

## Tasks

1. **Modificar `UI_FormSubmitter.client.js` para eventos de éxito (Pub/Sub)**
   - En la función de callback de guardado exitoso (`saveForm` -> `.withSuccessHandler`), emitir un evento `window.AppEventBus.publish('FORM::SUBMIT_SUCCESS', { entityName: currentEntityName, response: response })`.
   - Esto permitirá al cascarón saber cuándo cerrar el modal.

2. **Implementar el Modal en `SelfService_Home_UI.client.js`**
   - En el `btnStart.addEventListener('click', ...)`:
     - Crear dinámicamente un `<ion-modal>`.
     - Definir su HTML interno con un `<ion-header>` (botón cerrar) y un `<ion-content>` con un `div#wizard-render-zone`.
     - Añadir el modal al `document.body` y presentarlo vía `window.PresentSafe(modal)`.
   - Llamar a `window.FormRenderer_UI.renderForm('Wizard_Taxonomia', null, document.getElementById('wizard-render-zone'))`.

3. **Escucha de Cierre del Modal**
   - Suscribirse a `FORM::SUBMIT_SUCCESS` desde `SelfService_Home_UI.client.js`.
   - Cuando se dispare, verificar si `entityName === 'Wizard_Taxonomia'`.
   - Si coincide, lanzar un mensaje Toast o SweetAlert Premium indicando éxito.
   - Ejecutar `modal.dismiss()` y remover la subscripción de AppEventBus.

4. **Estilos Premium en el Contenedor**
   - Asegurarnos que `wizard-render-zone` tenga `max-width: 800px`, `margin: 2rem auto`, `background: var(--ion-background-color)`, padding y sombra flotante, simulando un "Documento" flotando sobre la pantalla, lo cual resalta la experiencia UI.
