# Implementation Plan: S49.4 Vista Fullscreen / Inserción Wizard

## Tasks

1. **Modificar `UI_FormSubmitter.client.js` para eventos de éxito (Pub/Sub)**
   - En la función de callback de guardado exitoso (`saveForm` -> `.withSuccessHandler`), emitir un evento `window.AppEventBus.publish('FORM::SUBMIT_SUCCESS', { entityName: currentEntityName, response: response })`.
   - Esto permitirá a componentes externos (como el Router) saber cuándo reaccionar tras enviar datos.

2. **Rediseñar el SelfService Home (`SelfService_Home_UI.client.js`)**
   - Reemplazar el tema de Glassmorphism por un diseño tipo *Landing Page iOS*.
   - Usar un fondo `Off-White` con gradientes radiales absolutos difuminados (`filter: blur(80px)`).
   - Aplicar tipografía ultra pesada y oscura para los títulos, y un botón de Call-To-Action sólido.
   - El botón, al hacer clic, dispara la navegación: `window.AppEventBus.publish('NAV::CHANGE', {viewType: 'wizard'});`.

3. **Implementar Ruta en `UI_Router.client.js`**
   - Añadir una nueva condición `else if (viewType === 'wizard')`.
   - Limpiar el contenedor actual (`window.DOM.clear(container)`).
   - Desactivar la barra lateral izquierda (`splitPane.setAttribute('when', 'false')`).
   - Crear un `wrapper` limpio de ancho de 1000px y pasarlo como `customContainer` a `window.FormRenderer_UI.renderForm('Wizard_Taxonomia', null, wrapper)`.

4. **Escucha de Cierre del Wizard**
   - Dentro del caso de ruteo `wizard`, suscribirse a `FORM::SUBMIT_SUCCESS`.
   - Al capturar el evento para `Wizard_Taxonomia`, cancelar la subscripción y retornar al home automáticamente: `window.AppEventBus.publish('NAV::CHANGE', {viewType: 'selfservice'})`.
   - Levantar un `ion-toast` confirmando "¡Taxonomía orquestada con éxito!".
