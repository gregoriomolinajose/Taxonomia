# Scope: S49.3 Cascarón Home de Negocio

## Boundaries

**In Scope:**
- Creación del archivo `src/SelfService_Home_UI.client.js` (o en HTML si la arquitectura lo dicta) como un Custom Web Component o clase de renderizado.
- Diseño visual Premium de la pantalla (HTML/CSS): Hero Banner, Tarjeta de presentación, Call to Action primario ("Nueva Taxonomía").
- Inyección de una ruta/trigger temporal o permanente desde la navegación base para acceder al modo cliente.

**Out of Scope:**
- Lógica de instanciación del Wizard modal (eso pertenece a S49.4).
- Obtención y listado real de la base de datos de las Taxonomías del usuario (esto puede requerir un DataView especial o llamadas API en iteraciones futuras; por ahora el foco es la interfaz de acceso).

## Done Criteria
- [ ] Existe un archivo dedicado para la vista `SelfService_Home_UI`.
- [ ] La vista puede ser accedida desde el entorno de desarrollo y se renderiza de forma aislada.
- [ ] El diseño cumple con expectativas "Premium" (Modern Typography, Hover effects, Micro-animations).
