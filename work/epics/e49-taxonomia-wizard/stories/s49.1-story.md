# Story: Data Layer - Entidad Taxonomía

## User Story
As an Arquitecto de Datos,
I want to tener la entidad "Taxonomia" debidamente registrada en el Schema_Engine,
so that el motor UI pueda orquestar el asistente (Wizard) mapeando correctamente todos sus directorios, portafolios y dominios asociados.

## Acceptance Criteria

### Scenario: Inicialización de la entidad en Schema_Engine
```gherkin
Given el sistema de base de datos en estado de inicialización
When el motor invoca la configuración para `Taxonomia`
Then el esquema debe definir las relaciones N:M (subgrids) para:
  - Directorio de TI, Negocio y Producto (M:N Personas)
  - Portafolios Asociados (M:N Portafolio)
  - Productos Asociados (M:N Producto)
  - Equipos Participantes (M:N Equipos)
  - Colaboradores (M:N Personas)
  - Alta de Dominios (M:N Dominio)
  - Alta de Capacidades (M:N Capacidad)
```

## Notes
Esta historia es el "Walking Skeleton" de datos para la Épica E49. No contiene lógica UI compleja ni modificaciones al Blueprint CRUD, solo el mapeo semántico en `APP_SCHEMAS`.
