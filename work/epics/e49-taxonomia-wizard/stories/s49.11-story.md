# Story S49.11: Refinamiento Visual del Wizard (Look & Feel)

## User Story (Connextra)
**Como** diseñador de taxonomías organizacionales,
**Quiero** que el Wizard de Taxonomía E2E tenga una interfaz visual premium y pulida,
**Para** que la experiencia de creación se sienta profesional, guiada y acorde al nivel de la plataforma de gobernanza.

## Contexto
El Wizard de Taxonomía funciona correctamente tras la consolidación de S49.1-S49.7, pero su presentación visual necesita refinamiento para alcanzar paridad con diseños modernos de SaaS. Se utiliza una imagen de referencia como inspiración de diseño.

## Criterios de Aceptación (Gherkin)

### AC-1: Header alineado con jerarquía tipográfica invertida
```gherkin
Given el Wizard está abierto en modo fullscreen
When se renderiza el header superior
Then el subtítulo "ORQUESTADOR DE TAXONOMÍA E2E" aparece en formato mini caps con indicador de punto azul
And el título principal "Diseñando la arquitectura organizacional" aparece debajo en formato H2 bold
And ambos están alineados a la izquierda
```

### AC-2: Sidebar con subtítulos descriptivos y barra de progreso
```gherkin
Given el Wizard muestra la navegación lateral
When se visualiza cada paso en el sidebar
Then cada paso muestra su número/checkmark, nombre y un subtítulo descriptivo debajo
And al pie del sidebar existe una barra de progreso lineal con texto "Progreso X de Y"
```

### AC-3: Badge de paso y dot indicators en el footer
```gherkin
Given el usuario navega a cualquier paso del Wizard
When se renderiza el área de contenido
Then aparece un badge pill "☆ PASO X DE Y" encima del título de la sección
And el footer muestra dot indicators (●/○) representando el progreso visual
```

## Restricciones
- **Solo tokens existentes** del design system (`text-mini`, `text-h2`, `--rounded-full`, colores Ionic)
- **Cero componentes nuevos** — refinamiento de los existentes
- **Cero regresiones funcionales** — cambios puramente cosméticos
- **Compatible con Dark Mode** mediante uso exclusivo de CSS custom properties
