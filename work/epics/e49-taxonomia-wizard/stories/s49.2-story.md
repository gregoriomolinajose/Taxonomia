# Story: Extensión Stateful del UI_FormStepper y Configuración IoC en FormRenderer

## User Story
As an Arquitecto Frontend,
I want to extender el componente `UI_FormStepper.client.js` para soportar `stateful: true` e inyectar Inversión de Control en `FormRenderer_UI.client.js`,
so that el Wizard de Taxonomía pueda mostrar indicadores visuales de progreso por paso, y pueda ser renderizado dentro de un modal custom (sin acoplarse al Drawer lateral).

## Acceptance Criteria

### Scenario: Modo Stateful activo
```gherkin
Given que un formulario se renderiza usando UI_FormStepper
When el Stepper se inicializa con `config.stateful = true`
Then debe evaluar si los inputs de cada paso tienen valor
And debe actualizar los íconos del menú lateral mostrando "Pendiente", "En Proceso" o "Finalizado".
```

### Scenario: FormRenderer en contenedor custom
```gherkin
Given que invoco global.renderForm() con `config.customContainer` definido
When se construye el formulario
Then los campos deben insertarse dentro del `customContainer`
And la capa DrawerStackController.push() debe ser ignorada.
```
