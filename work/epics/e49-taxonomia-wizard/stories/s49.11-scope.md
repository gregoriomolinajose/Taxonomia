# Scope: S49.11 — Wizard Look & Feel

## In Scope
- Rediseño del header del Wizard (jerarquía tipográfica, alineación, indicador visual)
- Subtítulos descriptivos en cada paso del sidebar lateral
- Barra de progreso lineal al pie del sidebar
- Badge pill "☆ PASO X DE Y" en el área de contenido
- Dot indicators en el footer de navegación
- Compatibilidad con Dark Mode

## Out of Scope
- Cambios en lógica de negocio o validación del stepper
- Nuevos tokens CSS o componentes del design system
- Refactorización arquitectónica (eso pertenece a S49.8/S49.9)
- Cambios en el flujo de guardado o persistencia

## Done When
- El header muestra el subtítulo mini caps + título H2 alineados a la izquierda
- Cada paso del sidebar tiene su subtítulo descriptivo visible
- El sidebar muestra barra de progreso + texto "Progreso X de Y" al pie
- Un badge pill indica el paso actual en el content area
- El footer incluye dot indicators visuales
- Los cambios se ven correctamente en Dark Mode
- Despliegue exitoso a DEV
