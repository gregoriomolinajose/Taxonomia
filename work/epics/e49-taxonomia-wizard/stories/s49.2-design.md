# Design: S49.2 Extensión UI Engine

## What & Why
- **Problem**: El `FormRenderer_UI` está fuertemente acoplado al `DrawerStackController`, impidiendo que un formulario nativo sea renderizado en pantalla completa (un wizard aislado). A su vez, `UI_FormStepper` no tiene indicadores visuales de progreso (completitud).
- **Value**: Desacoplar el Drawer nos permitirá reaprovechar cientos de líneas de código generador de Inputs y M:N Subgrids en el portal de clientes (fullscreen), y hacer el stepper stateful ofrecerá una excelente UX para el Wizard.

## Approach
- **Modificación en FormRenderer_UI.client.js**: En `global.renderForm(entityName, data, callback, config)`, evaluar si `config.customContainer` existe. Si existe, usar ese contenedor como base del modal. Si no existe, invocar `global.DrawerStackController.push()`. 
- **Modificación en UI_FormStepper.client.js**: Añadir soporte al constructor para `stateful`. Añadir un método `_recalculateStatus()` que se suscriba al evento `ionChange` o `input` del contenedor principal. Dependiendo de los inputs rellenados por sección, pintará un check (verde) si está lleno, un círculo (azul) si está a medias, o un círculo (gris) si está vacío.

## Examples
### Renderizar en un modal (SelfService Home):
```javascript
const modalWizard = document.createElement('ion-modal');
modalWizard.classList.add('fullscreen-wizard');
document.body.appendChild(modalWizard);

// El renderizado inyecta todo el wizard dentro de `modalWizard` en lugar de abrir el Drawer administrativo.
await global.renderForm('Taxonomia', null, null, { customContainer: modalWizard });
```

### Indicador visual (UI_FormStepper):
```javascript
// Internamente, el Stepper evaluará:
const inputs = this.stepContainers[stepName].querySelectorAll('ion-input, ion-textarea, .subgrid-container');
const hasData = Array.from(inputs).some(i => i.value && i.value !== '' && i.value !== '[]');
if (hasData) {
    this.menuItems[stepName].icon.setAttribute('name', 'checkmark-circle');
    this.menuItems[stepName].icon.setAttribute('color', 'success');
}
```
