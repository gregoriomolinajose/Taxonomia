# S54.5: Plan de Implementación (Lienzo en Asistente)

## Overview
- **Story:** S54.5 (Integrar Lienzo al Asistente de Nueva Taxonomía)
- **Size:** S (Small)
- **Date:** 2026-05-13

## Tareas (Execution Order)

### Tarea 1: Estilos CSS para Pantalla Completa y Split-View
- **Description:** Agregar reglas CSS para la clase `.drawer-fullscreen` que modifique el comportamiento del `drawer-panel` a 100vw. Configurar flexbox para dividir el contenedor del wizard en dos columnas (formulario y lienzo) cuando esta clase esté activa.
- **Files:** `src/Index.html` (sección `<style>`)
- **AC Reference:** Scenario 1 (Expansión de Drawer)
- **Verification:** Abrir la consola, inyectar manualmente la clase `.drawer-fullscreen` al drawer actual y verificar que ocupa toda la pantalla de forma responsiva.
- **Size:** XS
- **Dependencies:** Ninguna

### Tarea 2: Orquestación del Stepper y Montaje del Canvas
- **Description:** Modificar la lógica de cambio de pasos en `UI_FormStepper.client.js`. Cuando el índice del paso sea `>= 1` (Paso 2 o superior), añadir dinámicamente la clase al drawer. Luego, instanciar `window.UI_View_SwimlaneGrid` dentro de un contenedor derecho inyectado en el DOM. Asegurar que recibe el `contexto_id` optimista de la taxonomía.
- **Files:** `src/UI_FormStepper.client.js`
- **AC Reference:** Scenarios 2 & 3 (Carga en tiempo real de componentes)
- **Verification:** Al avanzar del Paso 1 al Paso 2 en la UI de Taxonomía, la pantalla debe dividirse y el lienzo vacío debe inicializarse en la derecha.
- **Size:** S
- **Dependencies:** Tarea 1

### Tarea 3: Prueba de Integración End-to-End
- **Description:** Validar el comportamiento manual y real. Crear una taxonomía, avanzar al paso de Unidad de Negocio, guardar, y agregar un portafolio.
- **Verification:** Confirmar que al guardar un portafolio en el panel izquierdo (Formulario), el componente `UI_View_SwimlaneGrid` de la derecha escucha el evento `CACHE::GRAPH_HYDRATED` y dibuja la tarjeta inmediatamente sin recargar.
- **Size:** XS
- **Dependencies:** Tarea 2

## Riesgos y Mitigaciones
- **Riesgo:** El Canvas intenta escribir eventos al global scope que puedan chocar con el Wizard.
- **Mitigación:** Asegurar que los botones "internos" del Canvas (ej. "Añadir Portafolio") se deshabiliten o se oculten con CSS (`pointer-events: none` o un modo explícito de `read-only`) para forzar al usuario a usar el panel lateral del asistente.
