# S54.3: Alcance del List Engine Wrapper

## In Scope
- Implementación de un patrón *Wrapper* o Función Decoradora (`withUniversalFilter(viewComponent)` o similar) para inyectar lógica en vistas existentes sin tocar la implementación interna de cada una.
- Algoritmo de filtrado `in-memory` aplicando lógica combinada: `OR` para múltiples selecciones de un mismo campo (ej. Depto = TI o Legal), y `AND` entre campos distintos (Depto = TI AND Estado = Activo).
- Modificación de la inicialización de grillas existentes en el *Entry Point* (main router) para utilizar el Wrapper.
- Inyección del DOM para el botón disparador del Drawer.

## Out of Scope
- Traducción de IDs relacionales a etiquetas de texto amigables (ej. si el dato es un UUID, el wrapper filtrará por UUID. La S54.4 solucionará esto hidratando los UUIDs en la capa ETL antes de que lleguen al filtro).
- URL State / Deep Linking para guardar filtros en marcadores del navegador.

## Done Criteria
- [ ] La vista principal de "Personas" o entidad homóloga muestra el botón "Filtrar".
- [ ] Al seleccionar opciones, la cantidad de filas en la tabla disminuye correctamente en tiempo real.
