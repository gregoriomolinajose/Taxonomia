# S54.5: Diseño de Integración de Lienzo en Asistente

## Problem & Value
**Problema:** El asistente de creación de Taxonomía actual carece de contexto espacial; el usuario llena un formulario sin ver cómo se construye la jerarquía que está diseñando.
**Valor:** Proveer un lienzo interactivo en modo de pantalla dividida ("Split-View") mejora drásticamente la usabilidad en laptops y da seguridad al usuario de que las ramificaciones se están generando correctamente, elevando la experiencia a un producto SaaS premium.

## Approach
1. **Drawer a Pantalla Completa:** Interceptar el cambio de pasos en `UI_FormStepper.client.js`. Si el paso es >= 2, agregar una clase `drawer-fullscreen` al contenedor padre `.drawer-panel`. 
2. **CSS Split-View:** Agregar estilos en `Index.html` (o `UI_Components.html`) para que cuando el contenedor del stepper tenga un estado de "split", el formulario ocupe ~35% de ancho y un nuevo contenedor `div#wizard-canvas-container` ocupe el ~65% restante.
3. **Instanciación del Canvas:** Durante el montaje del paso 3 y 4 en el Stepper, instanciar dinámicamente `window.UI_View_SwimlaneGrid` pasándole el ID optimista de la Taxonomía recién creada (que ya debe vivir en `DataStore` gracias al paso 1).
4. **Modo Read-Only:** El canvas renderizado dentro del Wizard funcionará como un espectador reactivo, leyendo eventos `CACHE::GRAPH_HYDRATED` y auto-actualizándose, pero las llamadas a la acción deben mantenerse centralizadas en el panel del Wizard.

## Components Affected
- `src/UI_FormStepper.client.js` (Modificación: lógica de transición y renderizado condicional de Split-View).
- `src/Index.html` (Modificación: adición de reglas CSS para `.drawer-fullscreen` y animaciones fluidas de `width`).

## Examples
**Ejemplo de Transición en UI_FormStepper:**
```javascript
// Dentro de UI_FormStepper._renderStep()
const drawerNode = this.container.closest('.drawer-panel');
if (drawerNode) {
    if (this.currentStepIndex >= 1) { // Paso 2 (0-indexed)
        drawerNode.classList.add('drawer-fullscreen');
        this._mountCanvasViewer();
    } else {
        drawerNode.classList.remove('drawer-fullscreen');
        this._unmountCanvasViewer();
    }
}
```

## Acceptance Criteria
- [ ] **MUST:** El Drawer debe transicionar fluidamente a `100vw` cuando se avanza del Paso 1 al Paso 2.
- [ ] **MUST:** Un renderizado en tiempo real de `UI_View_SwimlaneGrid` debe mostrarse en la mitad derecha del cajón expandido.
- [ ] **MUST:** Al agregar un nuevo nodo (ej. Portafolio) desde el panel izquierdo, el lienzo derecho debe reflejarlo automáticamente.
