# S54.2: Alcance de Lógica de Motor de Filtros

## In Scope
- Lectura de `APP_SCHEMAS[entityName]` para poblar el select principal.
- Algoritmo extractivo `Set(records.map(...))` para crear listas de checkboxes basadas en los datos reales en memoria.
- Interacción y renderizado reactivo del UI (S54.1) usando JavaScript nativo.
- Generación de State (`activeFilters`).
- Asegurar A11y (IDs únicos generados programáticamente para asociaciones `<label for>`).

## Out of Scope
- Conexión del `onFilterChange` a los `DataViews` o grillas de la aplicación (eso es S54.3).
- Resolución de nombres legibles para campos estrictamente relacionales (eso es S54.4).

## Done Criteria
- [ ] La UI reacciona y renderiza opciones reales basadas en `APP_SCHEMAS` y el array de registros pasado al inicializar.
- [ ] Al seleccionar opciones, se construye un objeto estructurado con las opciones activas.
- [ ] Los identificadores de checkboxes no sufren colisiones (A11y action item mitigado).
