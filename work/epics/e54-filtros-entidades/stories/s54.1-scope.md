# S54.1: Alcance de Diseño UI/UX del Filtro Universal

## In Scope
- Maquetación HTML/CSS del contenedor Drawer lateral (Jira-like).
- Maquetación del dropdown de selección de campos ("Selecciona un campo para filtrar").
- Maquetación de la tarjeta individual de campo (Buscador interno + Checkboxes).
- Estilos responsivos y uso de sistema de diseño (colores, tipografía).
- Botón "Filtro" (Trigger) en la barra de herramientas base (visualmente).

## Out of Scope
- Lógica de estado (state management) de filtros (S54.2).
- Filtrado real in-memory de las grillas (S54.3).
- Obtención dinámica de opciones desde `APP_SCHEMAS`. La maqueta usará datos de prueba (mocks).

## Done Criteria
- [ ] Existe un componente visual aislado y renderizable.
- [ ] La UI concuerda estructuralmente con el prototipo visual acordado (Drawer lateral, cards expandibles, scrollbars).
- [ ] El estilo CSS está encapsulado y respeta el tema global (fuentes, bordes, colores).
