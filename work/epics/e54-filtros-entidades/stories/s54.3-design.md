# S54.3 Design

## Arquitectura de Inyección (Wrapper Pattern)
Para evitar la modificación individual de cada pantalla, utilizaremos `DataViewEngine` (en `src/DataView_UI.client.js`) como nuestro *Wrapper*. 
Este componente ya actúa como el controlador central para todas las vistas tabulares y gráficas del sistema.

### Modificaciones Clave
1. **`UI_DataView_Toolbar.client.js`**:
   - En `buildToolbarHTML()`, el botón de "Filtros" que actualmente tiene un `console.log('Panel de Filtros...')` será actualizado para recibir y ejecutar un callback `onFilterToggle`.

2. **`DataView_UI.client.js`**:
   - **Contenedor**: En `render()`, inyectar un `<div id="dv-filter-container"></div>` junto a las otras zonas del layout.
   - **Instanciación**: Crear `_initUniversalFilter()` que instancie `window.UI_UniversalFilter` utilizando el `_state.entityName`, `window.APP_SCHEMAS`, y `_state.data`.
   - **Estado Logico**: Añadir `_state.advancedFilters = {}`.
   - **Interceptación**: Modificar o ampliar la función `_applyFilter()` para que, después de buscar por texto libre, itere sobre `_state.advancedFilters` y descarte registros que no cumplan la lógica AND/OR.
   - **Callback `onFilterChange`**: Al recibir el evento del drawer, guardar `_state.advancedFilters = newState` y ejecutar `_applyFilter(_lastSearchQuery)` + `_rerenderData()`.

## Lógica de Combinación (AND/OR)
Por requerimiento, la lógica debe ser:
- Entre campos distintos (Ej: `Departamento` y `Rol`): **AND**.
- Entre valores de un mismo campo (Ej: `Rol = Admin` o `Rol = Editor`): **OR**.

```javascript
const filterKeys = Object.keys(advancedFilters);
if (filterKeys.length > 0) {
    baseData = baseData.filter(row => {
        return filterKeys.every(field => { // AND entre campos
            const validValues = advancedFilters[field]; // ['Admin', 'Editor']
            let rowVal = row[field];
            
            // Resolución para relacionales (array de diccionarios)
            if (Array.isArray(rowVal)) {
                return validValues.some(val => rowVal.includes(val));
            } else {
                return validValues.includes(String(rowVal)); // OR entre valores del mismo campo
            }
        });
    });
}
```
