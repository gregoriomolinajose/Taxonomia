# S54.2 Retrospective

## What went well
- La transición de un objeto mock estático a una **Clase Vanilla JS** instanciable permitió acoplar limpiamente el `APP_SCHEMAS` sin perder la modularidad de la vista original.
- El algoritmo extractivo nativo mediante `Set()` probó ser altamente eficiente para deduplicar incluso valores dentro de arrays relacionales (M:N).
- Logramos generar la lógica sin usar un Virtual DOM, manteniendo la compatibilidad con G. Apps Script al 100%.

## What to improve
- El método `render()` destruye y re-crea todo el contenido con `innerHTML`. Si se tipea muy rápido en un *search* interno que dispare `render()`, se perderá el foco del usuario.

## Action Items
- Para **S54.3**, al conectar este Drawer a la grilla global de registros, deberemos monitorizar si la recarga agresiva del DOM produce *glitches* visuales inaceptables. De ser así, deberemos migrar el repintado a mutaciones puntuales (`element.appendChild` o asignaciones a nodos específicos).
