# S54.1: Diseño UI/UX del Componente de Filtros Universales

## User Story (Connextra)
**Como** usuario del sistema (Líder Estratégico, PM, etc.)
**Quiero** disponer de un panel lateral (Drawer) de filtros universal
**Para** poder visualizar las opciones de filtrado disponibles y preparar la interfaz para la selección de criterios (estilo Jira).

## Acceptance Criteria (Gherkin)

**Scenario 1: Apertura del panel de filtros**
- **Given** que estoy en una vista principal (ej. Personas o Portafolios)
- **When** hago clic en el botón "Filtrar"
- **Then** se despliega un panel lateral (Drawer) desde la derecha con el título "Filtros".

**Scenario 2: Visualización de campos seleccionados**
- **Given** que el panel de filtros está abierto
- **When** observo el contenido
- **Then** veo un dropdown para "Seleccionar un campo para filtrar" y bloques expandibles para los campos ya seleccionados.

**Scenario 3: Bloque de campo individual**
- **Given** que tengo un campo visible (ej. Área de producto)
- **When** el bloque está expandido
- **Then** muestra un buscador interno, una lista de checkboxes (Seleccionar todo, Sin valor, opciones estáticas de prueba) y un enlace para limpiar la selección.
