# Story: S47.1, S47.2, S47.3 - Dominios Full Integration

## Implementation Details
- **S47.1 Schema Standardization**: Refactored `APP_SCHEMAS.Dominio` to align perfectly with `Capacidad`. Replaced `id_registro` with `id_externo`, and added `orden_path`, `contexto_completo_analisis`, and `path_completo_es`.
- **S47.2 ETL Bulk Upload Resiliency**: Enhanced `DataEngine_ETL.client.js` with an intelligent Alias Mapper. It seamlessly converts visual headers from the Google Sheet (`Nivel subdominio`, `Orden. Subdominio`, `Abreviación (Path Servicio)`, etc.) directly into their corresponding DB columns. This allows the user to upload the CSV or Google Sheet without renaming the headers manually!
- **S47.3 ECharts Treemap Integration**: Made `Math_Engine.html`'s `buildEChartsCapacidadesOption` completely entity-agnostic. Added `'Dominio'` to the `UI_DataView_Toolbar.client.js` button condition and connected it to `UI_View_ECharts.client.js`.

- **S47.4 Topological Auto-Inference**: Implemented a robust fallback in `DataEngine_UI.client.js`. When a relational edge is missing from `Sys_Graph_Edges`, the system mathematically infers the parent-child relationship by parsing the `orden_path` field (e.g., mapping `02.01.01` to `2.1`).
- **S47.5 Graph Edge Resilience**: Hardened the topological join mechanism by enforcing string `.trim()` on `id_nodo_hijo`, `id_nodo_padre`, and the UUID primary keys, neutralizing hidden whitespace artifacts injected during flat CSV uploads.
- **S47.6 Strict Root Enforcement**: Implemented a defensive mechanism in the hierarchy builder that strictly isolates root-level rendering. Nodes with `nivel_tipo > 0` are forcibly rejected from the `trueRoots` array. This completely prevents orphaned sub-level nodes from mixing with the Level 0 view.
- **S47.7 Treemap Depth Expansion**: Reconfigured `UI_View_ECharts.client.js` and `Math_Engine.html` to allow the full topological hierarchy to render. Adjusted `leafDepth` to `2` to expose Nivel 0, Nivel 1, and Nivel 2 simultaneously on the main screen without requiring deep-clicks.

## Outcome
The Dominios entity now natively supports mass ETL ingestion and topological rendering using the same powerful engine developed for Capacidades. Data ingestion anomalies (such as missing edges or whitespace trailing) are now elegantly handled by the Auto-Inference and Strict Root filtering, guaranteeing a pristine visual hierarchy.
