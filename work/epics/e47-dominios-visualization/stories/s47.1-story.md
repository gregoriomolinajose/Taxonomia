# Story: S47.1, S47.2, S47.3 - Dominios Full Integration

## Implementation Details
- **S47.1 Schema Standardization**: Refactored `APP_SCHEMAS.Dominio` to align perfectly with `Capacidad`. Replaced `id_registro` with `id_externo`, and added `orden_path`, `contexto_completo_analisis`, and `path_completo_es`.
- **S47.2 ETL Bulk Upload Resiliency**: Enhanced `DataEngine_ETL.client.js` with an intelligent Alias Mapper. It seamlessly converts visual headers from the Google Sheet (`Nivel subdominio`, `Orden. Subdominio`, `Abreviación (Path Servicio)`, etc.) directly into their corresponding DB columns. This allows the user to upload the CSV or Google Sheet without renaming the headers manually!
- **S47.3 ECharts Treemap Integration**: Made `Math_Engine.html`'s `buildEChartsCapacidadesOption` completely entity-agnostic. Added `'Dominio'` to the `UI_DataView_Toolbar.client.js` button condition and connected it to `UI_View_ECharts.client.js`.

## Outcome
The Dominios entity now natively supports mass ETL ingestion and topological rendering using the same powerful engine developed for Capacidades.
