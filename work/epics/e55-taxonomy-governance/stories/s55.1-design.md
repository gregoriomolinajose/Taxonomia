# S55.1 - Design: Centralización y Bloqueo Relacional

## 1. What & Why
**Problem:** Users can currently modify taxonomy relations (like Portafolio -> Unidad de Negocio) from standard entity drawers outside the Taxonomia Canvas, bypassing governance and risking SCD-2 consistency.
**Value:** By enforcing read-only topological fields outside the Canvas, we establish the Canvas as the single source of truth for structural modifications.

## 2. Approach
Modify `getAppSchema` in `src/Schema_Engine.js` to dynamically apply `readonly: true` to topological relation fields when the application is not operating within a Taxonomia context.

- **Component Affected:** `src/Schema_Engine.js` (`getAppSchema` function).
- **Logic:**
  1. Check if `window.taxonomiaContext` is defined and truthy.
  2. If falsy (not in Wizard), deep clone the requested schema fields.
  3. Find fields where `type === 'relation'` and `graphEntity === 'Sys_Graph_Edges'`.
  4. Override them to set `readonly = true` and append a warning to `helpText`.
  5. Return the cloned schema so we don't mutate `APP_SCHEMAS` globally.

## 3. Concrete Examples

```javascript
// Example 1: Inside Taxonomia Canvas
window.taxonomiaContext = 'TAX-123';
const schemaInCanvas = getAppSchema('Portafolio');
// Result: schemaInCanvas.fields.find(f => f.name === 'unidad_negocio_padre').readonly is loosely undefined or false.

// Example 2: In standard UI Dashboard
window.taxonomiaContext = undefined;
const schemaInDashboard = getAppSchema('Portafolio');
const field = schemaInDashboard.fields.find(f => f.name === 'unidad_negocio_padre');
// Result: field.readonly === true
// Result: field.helpText === '(Solo lectura: Gestionado vía Canvas de Taxonomía)'
```

## 4. Acceptance Criteria
- **MUST**: Campos topológicos se renderizan en solo lectura si `window.taxonomiaContext` es nulo/falso.
- **MUST**: Se añade una indicación visual (`helpText`) al campo bloqueado.
- **MUST**: `getAppSchema` clona la matriz de campos (deep clone) para evitar mutar la configuración estática de `APP_SCHEMAS`.
