# S55.4 Scope: UI de Resumen de Impacto

## In Scope
- Creación de un Componente UI (Modal o Cajón Lateral) para mostrar el *Deployment Preview*.
- Integración en el cliente con el motor de diffing lógico (S55.3) consumiendo el estado del Canvas (draftEdges) y el estado global inicial (activeEdges).
- Resolución de IDs a nombres legibles: El UI debe mostrar el nombre del nodo ("Portafolio Fintech") en lugar de UUIDs ("PORT-49A...").
- Controles de usuario: Botones para "Cancelar" y "Confirmar Despliegue".

## Out of Scope
- Funciones de "deshacer" a nivel individual (si el diff no le gusta, el usuario cancela todo el despliegue y vuelve al lienzo).
- Visualización de diferencias en propiedades de los nodos (solo se visualizan cambios topológicos/aristas).
- El backend del despliegue (la transacción de base de datos) corresponde a S55.5.

## Done Criteria
- Cuando el usuario finaliza el wizard o pulsa "Desplegar", aparece el modal de resumen.
- El modal interpreta la salida de `GraphTopologyDiffer.computeDelta` de forma gráfica (listas de adiciones y remociones).
- Los IDs de nodos son resueltos a etiquetas legibles.
- El botón de confirmación dispara una intención de evento al sistema (`ACTION::PUBLISH_TAXONOMY` o similar).
