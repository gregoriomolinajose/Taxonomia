# S55.6 Autoguardado Universal en el Wizard

## User Story
**Como** Usuario del Sistema
**Quiero** que mis datos se guarden automáticamente al avanzar de un paso a otro en cualquier formulario tipo "Wizard"
**Para** no perder mi progreso si ocurre un error, cierro la ventana por accidente, o el proceso requiere de un ID real para renderizar relaciones en pasos posteriores.

## Acceptance Criteria

### Scenario 1: Interceptor Universal en Transición Siguiente
**Given** que el usuario está llenando cualquier entidad que utiliza un diseño de Wizard (múltiples pasos)
**When** completa los campos requeridos del paso actual y hace clic en "Siguiente"
**Then** el sistema debe emitir un autoguardado silencioso a la base de datos
**And** solo debe permitir la transición visual al siguiente paso si el guardado responde con éxito.

### Scenario 2: Navegación por Barra Lateral (Sidebar)
**Given** que el usuario utiliza la barra lateral izquierda para saltar a un paso posterior
**When** hace clic en el nombre de otra sección
**Then** el sistema debe interceptar la acción y realizar el autoguardado de los datos actuales
**And** al confirmar el guardado, debe moverse a la sección seleccionada.

### Scenario 3: Experiencia de Usuario sin Interrupciones
**Given** que el autoguardado es disparado
**When** el formulario envía los datos al `FormEngine`
**Then** la solicitud debe utilizar el flag `isFormModal = false` para que el panel lateral (Drawer) no se cierre automáticamente.
**And** los botones "Siguiente" y de guardar deben bloquearse momentáneamente para prevenir doble envío.

## Technical Implementation Details
- Modificar la arquitectura del método `goToSection()` y el EventListener de `btnNext` en `UI_FormStepper.client.js`.
- Generalizar el bloque S55.2 (que actualmente solo aplica a `Taxonomia` y `currentStepIndex === 0`) para abarcar cualquier entidad (`entityName !== null`).
- Gestionar correctamente los callbacks de `FormEngine.saveForm` manteniendo la inyección de dependencias `FormEngine` global o manejando correctamente las promesas para la transición asincrónica.
