# S55.4 Design: UI de Resumen de Impacto

## Problem
Los usuarios necesitan saber qué va a suceder exactamente en la topología global de la arquitectura antes de "Desplegar" sus borradores locales del Canvas. Desplegar a ciegas viola los principios de Gobernanza SCD-2.

## Value
El Deployment Preview actúa como la "pantalla de confirmación" definitiva (Gatekeeper). Al resolver los IDs a nombres legibles, permite que arquitectos y analistas no técnicos entiendan el impacto de sus decisiones de diseño en el lienzo.

## Approach
1. **Lógica Cliente:** Añadir `computeDelta` a `window.Graph_Utils` en `JS_GraphUtils.client.js` para que el cliente pueda calcular el Diff de forma instantánea y síncrona sin latencia de red.
2. **Componente Visual:** Crear o inyectar un Modal nativo de Ionic (`<ion-modal>`) que se levanta cuando el usuario presiona "Desplegar" en el paso final del Wizard.
3. **Resolución de Nombres:** El componente UI tomará el Delta (Additions, Removals) e iterará sobre los nodos usando `window.DataStore.get(Entity)` para reemplazar los UUIDs por el campo `nombre` de cada nodo (`Unidad_Negocio` o `Portafolio`).
4. **Despacho:** Al confirmar en el Modal, se invoca `window.AppEventBus.dispatch('ACTION::DEPLOY_DRAFT')`.

### Components Affected
- `JS_GraphUtils.client.js` (Modificar: Añadir `computeDelta`).
- `UI_FormStepper.client.js` (Modificar: Reemplazar el handler del botón final "Finish" o "Desplegar" para abrir el Modal en lugar de simplemente cerrar).
- `CSS_ETL_Modal.html` o un nuevo componente `UI_DeploymentModal.html` (Crear o reusar diseño para listar Adds/Removes).

## Examples
**Cálculo y Resolución:**
```javascript
const activeEdges = DataStore.get('Sys_Graph_Edges').filter(e => e.es_version_actual === true && e.estado !== 'Borrador');
const draftEdges = DataStore.get('Sys_Graph_Edges').filter(e => String(e.contexto_id) === String(taxonomiaId));

const delta = window.Graph_Utils.computeDelta(activeEdges, draftEdges);
// delta = { additions: [{id_nodo_hijo: 'UNDN-123'}], removals: [] }

// Resolución (ejemplo):
const undns = DataStore.get('Unidad_Negocio');
const nodeName = undns.find(u => u.id_unidad_negocio === 'UNDN-123')?.nombre || 'Desconocido';
// Renderizar "Desconocido" o "Nueva Unidad" en color verde.
```

## Acceptance Criteria
- **MUST**: Calcular el delta usando `window.Graph_Utils.computeDelta`.
- **MUST**: Renderizar las adiciones en una lista con un indicador visual positivo (verde, icono de '+').
- **MUST**: Renderizar las eliminaciones en una lista con un indicador visual negativo (rojo, icono de '-').
- **MUST**: Resolver los IDs a los nombres de las entidades correspondientes (usando el DataStore cacheado).
- **MUST**: Proveer botones "Cancelar" y "Confirmar".
