# S55.1 - Scope: Centralización y Bloqueo Relacional

## Boundaries
### In Scope
- Inyectar lógica condicional en la función `getAppSchema` dentro de `Schema_Engine.js`.
- Detectar si la UI actual se encuentra en el contexto del "Taxonomia Wizard" (`window.taxonomiaContext` o similar).
- Forzar la propiedad `readonly = true` a los campos relacionales cuando se accede desde fuera de dicho contexto.
- Agregar un texto de ayuda indicando que la modificación está reservada al Canvas de Taxonomía.

### Out of Scope
- Modificar el comportamiento de `Sys_Graph_Edges` a nivel de backend.
- Cambiar la renderización visual nativa de los componentes `SearchableMulti` o `SelectSingle`, asumiendo que ya soportan la propiedad `readonly`.

## Done Criteria
- [ ] Formularios de entidades topológicas bloquean edición de relaciones fuera del Taxonomia Canvas.
- [ ] La UI indica visualmente por qué el campo no es editable a través de un `helpText`.
- [ ] Dentro del Taxonomia Wizard, la edición sigue fluyendo normalmente.
