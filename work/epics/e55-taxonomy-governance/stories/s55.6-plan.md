# S55.6 Plan: Autoguardado Universal en el Wizard

## Implementation Plan

### T1: Refactorizar Transición en `UI_FormStepper.client.js`
- **Goal:** Hacer que el interceptor de transición de pasos sirva para cualquier entidad, no solo "Taxonomia" ni solo en el "Paso 0".
- **File:** `src/UI_FormStepper.client.js`
- **Action:** 
  1. Localizar el método `goToSection`.
  2. Remover la validación restrictiva: `if (this.entityName === 'Taxonomia' && this.currentStepIndex === 0 && newIdx > 0 ...)`
  3. Cambiarla por: `if (window.FormEngine && newIdx !== this.currentStepIndex)` (para toda entidad y cambio de paso).
  4. Realizar el autoguardado usando `FormEngine.saveForm(null, this.cardContent, this.entityName, callback, this.btnSubmit, false)`.
  5. Asegurar re-habilitación de los botones ante fallos o éxitos, y proceder con `_executeSectionTransition`.
- **Validation:** Verificar que se puede pasar de un paso a otro y se llama a la persistencia optimista en segundo plano.
