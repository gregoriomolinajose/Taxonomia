# S55.3 Scope: Motor de Diffing de Grafos

## In Scope
- Implementación del algoritmo de "Diffing" de topología matemática (comparación de nodos padres/hijos).
- Funcionalidad para identificar eltas de adición (`ADD`), eliminación (`REMOVE`) y conservación (`KEEP`).
- Integración temporal de datos (Drafts `Sys_Graph_Edges` filtrados vs. Active `Sys_Graph_Edges`).
- Pruebas unitarias/integradas de la lógica de diffing asegurando la correcta identificación de los cambios.

## Out of Scope
- Interfaz gráfica para visualizar los cambios (S55.4).
- Despliegue de los cambios a la base de datos de producción (S55.5).
- Análisis profundo de atributos individuales de los nodos; la comparación es estrictamente topológica (por aristas).

## Done Criteria
- La función o clase `GraphDiffer` toma dos listas de aristas (producción vs borrador) y retorna un objeto de resumen `{ additions: [], removals: [], kept: [] }`.
- Las aristas de borrador se normalizan para asegurar la comparación 1:1 con producción (sin falsos positivos por discrepancias de metadatos irrelevantes).
- La lógica no ejecuta mutaciones a nivel de base de datos; opera en memoria pura y retorna el resultado computado.
