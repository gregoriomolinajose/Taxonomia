# Design: S55.2 Inmersión UX

## What & Why
**Problem:** Actualmente, entrar al diseñador de Taxonomía requiere navegar por menús estándar, y el área de trabajo está confinada a un viewport fijo, restringiendo el layout visual de diagramas grandes.
**Value:** Una tarjeta de acceso rápido en el Dashboard reduce la fricción de entrada. Un botón para alternar a pantalla completa maximiza el espacio horizontal y vertical, ofreciendo una experiencia inmersiva tipo Miro.

## Approach
1. **SelfService_Home_UI.client.js**: Modificaremos el renderizado del dashboard para incluir un nuevo card premium apuntando al router `Taxonomia`.
2. **UI_FormStepper.client.js**: En el header del Wizard (paso 2), agregaremos un botón de icono (`expand-outline` / `contract-outline`) que añada una clase CSS `fullscreen-wizard` al contenedor padre.
3. **Index.html**: Agregar los estilos CSS para la clase `fullscreen-wizard` que posicionará el elemento en top:0, left:0, width:100vw, height:100vh, z-index superior, etc.

## Examples
**Dashboard Card:**
```html
<ion-card class="dashboard-card" onclick="window.history.pushState(null, '', '#view=Taxonomia'); window.dispatchEvent(new Event('popstate'));">
   <!-- Card content -->
</ion-card>
```

**Fullscreen Toggle logic:**
```javascript
btnFullscreen.onclick = () => {
   const container = document.getElementById('wizard-container');
   container.classList.toggle('fullscreen-wizard');
   // Actualizar icono expand/contract
}
```

## Acceptance Criteria
- [MUST] Tarjeta visible en el Dashboard (SelfService_Home) apuntando a la creación/edición de Taxonomía.
- [MUST] Botón de expandir visible en la esquina superior derecha del Wizard (Paso 2).
- [MUST] El botón alterna una clase CSS que posiciona el Wizard ocupando el 100% de la ventana in-app.
- [MUST] El Canvas (pan y zoom) sigue funcionando correctamente dentro del nuevo tamaño de contenedor.
