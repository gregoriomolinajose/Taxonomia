# Plan: S55.2 Inmersión UX

## Implementation Steps

### 1. Dashboard Access (SelfService_Home_UI.client.js)
- [ ] Localizar la función `_buildDashboardUI` en `SelfService_Home_UI.client.js`.
- [ ] Insertar un nuevo `<ion-card>` con diseño premium (similar a los demás pero con estilo distintivo para "Diseñar Nueva Taxonomía").
- [ ] El onClick de este card debe invocar la navegación al formulario de Taxonomía. (Ej. `window.history.pushState({viewType: 'dataview', payload: 'Taxonomia'}, '', '#view=Taxonomia'); window.dispatchEvent(new Event('popstate'));` o abrir el modal de `Taxonomia` si se utiliza el stepper).

### 2. Estilos Fullscreen (Index.html / CSS)
- [ ] Añadir en `<style>` (por ejemplo, en `Index.html` o donde apliquen estilos del stepper):
```css
.fullscreen-wizard {
    position: fixed !important;
    top: 0 !important;
    left: 0 !important;
    width: 100vw !important;
    height: 100vh !important;
    z-index: 99999 !important;
    margin: 0 !important;
    border-radius: 0 !important;
}
```

### 3. Fullscreen Toggle en el Wizard (UI_FormStepper.client.js)
- [ ] Localizar `_buildRightColumn` o donde se genera el header del canvas (Paso 2) en `UI_FormStepper.client.js`.
- [ ] Añadir un botón (icon-only button) en la esquina superior derecha del canvas.
- [ ] El onClick del botón hace `toggle` de la clase `fullscreen-wizard` sobre el contenedor principal del wizard (ej. `modal-content` o el contenedor del componente).
- [ ] Alternar el ícono entre `expand-outline` y `contract-outline`.

### 4. Verificación de Reflow del Canvas
- [ ] Asegurar que al cambiar de tamaño el contenedor, `UI_View_SwimlaneGrid.client.js` no se rompa (normalmente Flexbox y Miro-pan/zoom basado en transformaciones CSS se adaptan automáticamente al contenedor, pero conviene asegurar que no hay hardcoded dimensions).

## Test Cases
