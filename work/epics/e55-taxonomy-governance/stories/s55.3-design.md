# S55.3 Design: Motor de Diffing de Grafos

## Problem
Para gobernar los cambios de Taxonomía, necesitamos saber exactamente qué relaciones (aristas) se crearon o eliminaron en el borrador (Draft) en comparación con Producción (Active), para no sobrescribir toda la base de datos a ciegas y aplicar un correcto SCD-2.

## Value
Garantizar despliegues atómicos y auditables (idempotencia) mostrando a los usuarios exactamente qué van a cambiar antes de confirmarlo.

## Approach
Implementar una clase abstracta pura de matemática de conjuntos (`GraphTopologyDiffer`) en `Engine_Graph.js` (o accesible globalmente).
- **Entrada:** `activeEdges` (Array de aristas en producción, `es_version_actual: true`, filtradas por tipo) y `draftEdges` (Array de aristas en el borrador actual).
- **Proceso:** 
  1. Generar un `hash` único por cada arista: `id_nodo_padre + "::" + id_nodo_hijo + "::" + tipo_relacion`.
  2. Indexar `activeEdges` y `draftEdges` usando ese hash.
  3. Iterar para clasificar en `ADD` (en draft, no en active), `REMOVE` (en active, no en draft), y `KEEP` (en ambos).
- **Salida:** `{ additions: [], removals: [], kept: [] }`.

### Components Affected
- `Engine_Graph.js` (CREATE: añadir método de utilería matemática `GraphTopologyDiffer.computeDelta`).

## Examples

```javascript
// Input
const activeEdges = [
  { id_nodo_padre: 'A', id_nodo_hijo: 'B', tipo_relacion: 'TAXONOMIA_UNIDAD' },
  { id_nodo_padre: 'A', id_nodo_hijo: 'C', tipo_relacion: 'TAXONOMIA_UNIDAD' }
];

const draftEdges = [
  { id_nodo_padre: 'A', id_nodo_hijo: 'B', tipo_relacion: 'TAXONOMIA_UNIDAD' }, // kept
  { id_nodo_padre: 'A', id_nodo_hijo: 'D', tipo_relacion: 'TAXONOMIA_UNIDAD' }  // added
  // C is missing, so it's removed
];

// Execution
const delta = GraphTopologyDiffer.computeDelta(activeEdges, draftEdges);

// Output
// delta.additions -> [{... D}]
// delta.removals  -> [{... C}]
// delta.kept      -> [{... B}]
```

## Acceptance Criteria
- **MUST**: `computeDelta` identifica correctamente las aristas nuevas (ADD).
- **MUST**: `computeDelta` identifica correctamente las aristas eliminadas (REMOVE).
- **MUST**: `computeDelta` identifica correctamente las aristas que se mantienen (KEEP).
- **MUST**: La función no tiene efectos secundarios (pure function).
- **MUST**: Ignora campos de metadatos (como `id_arista` o `id_workspace`) para la comparación, basándose exclusivamente en la firma topológica.
