# Story S48.1: Admin Configuration Tab for Custom Branding

## User Story
Como **Administrador de Sistema**
Quiero **tener una pestaña de "Configuración General" en el panel de administración**
Para **poder cambiar dinámicamente el ícono de la pestaña (favicon) y el texto del título de la aplicación sin tocar código**

## Acceptance Criteria
1. El panel de administración debe contener una nueva pestaña/sección "Configuración".
2. La sección debe tener campos para ingresar la URL de la imagen del favicon y el texto del título.
3. Los datos de configuración deben guardarse de forma persistente utilizando el backend de Apps Script (`PropertiesService`).
4. La función `doGet` debe leer estas propiedades y aplicarlas en `setTitle` y `setFaviconUrl`.
5. Si no hay propiedades configuradas, debe aplicar valores por defecto de la aplicación.

## Specification by Example
- **Scenario:** El administrador actualiza la identidad visual de la pestaña.
  - **Given** el administrador ingresa a la configuración
  - **When** introduce "https://ejemplo.com/icono.png" en URL del Favicon y "Mi Taxonomía" en Título, y presiona Guardar
  - **Then** las propiedades se actualizan en el servidor.
  - **And** al recargar la aplicación web, el navegador muestra el nuevo título e icono en la pestaña.
