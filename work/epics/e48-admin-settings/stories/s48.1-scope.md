# Scope S48.1: Admin Configuration Tab for Custom Branding

## In Scope
- Agregar una nueva pestaña/sección "Configuración" en la UI del panel de administración (`Governance_Admin_UI.html` o similar).
- Crear un formulario con dos campos: "Título de la Aplicación" y "URL del Favicon".
- Conectar el formulario al backend (`API_Admin.js` o similar) para guardar en `PropertiesService.getScriptProperties()` bajo una clave como `APP_BRANDING_CONFIG`.
- Modificar `doGet` en `Code.js` para leer `APP_BRANDING_CONFIG` dinámicamente e inyectarlo en `setTitle()` y `setFaviconUrl()`.

## Out of Scope
- Subida directa de archivos binarios al servidor (el usuario debe proveer una URL pública para la imagen del favicon).
- Modificación de otros parámetros del White Label en esta historia específica, excepto si se unifican bajo la misma interfaz.

## Done Criteria
- [ ] La nueva pestaña de configuración está disponible en la interfaz de administración.
- [ ] El formulario permite actualizar y persistir el título de la app y la URL del favicon en la base de datos de propiedades.
- [ ] Los cambios se reflejan inmediatamente al recargar la aplicación completa (re-renderizado del `doGet`).
- [ ] Se verifica en el entorno de desarrollo que los cambios en el título e icono aplican de forma global.
