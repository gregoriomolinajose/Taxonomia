# Story S48.4: Adaptador OAuth2 para Consultas Multi-Dominio de Workspace

## User Story
Como **Administrador de la Instancia**
Quiero **que el sistema pueda conectarse al Google Workspace de dominios de terceros (ej. @bancoppel.com) a través de Cuentas de Servicio (Service Accounts)**
Para **permitir el aprovisionamiento de perfiles corporativos (Personas) sin que el usuario activo necesite privilegios administrativos en todos los dominios de la empresa.**

## Acceptance Criteria
1. El sistema debe integrar un mecanismo de *Domain-Wide Delegation* (impersonación) usando OAuth2.
2. Si el dominio a consultar tiene una cuenta delegada configurada en `APP_WORKSPACE_CONFIG` (creado en S48.3), el sistema debe usar un Service Account para solicitar un token de acceso a nombre de esa cuenta.
3. Las llamadas a `AdminDirectory` en `Engine_Workspace.js` deben usar el token OAuth2 cuando el dominio no pertenezca al dominio base o cuando esté explícitamente configurado.
4. El sistema de fallback debe mantenerse intacto: si la conexión falla (Service Account inválido, sin permisos), el aprovisionamiento no debe explotar, simplemente omitirá los datos extendidos.
