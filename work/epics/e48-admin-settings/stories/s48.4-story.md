# Story S48.4: Autorización OAuth2 (3-Legged) para Workspace Multi-Dominio

## User Story
Como **Administrador de la Instancia**
Quiero **poder autorizar la conexión a dominios externos (ej. @bancoppel.com) conectándome con mi propia cuenta de administrador de ese dominio a través de Google Sign-In**
Para **permitir que el sistema tenga acceso de lectura permanente a ese directorio sin necesitar configurar infraestructuras complejas en Google Cloud.**

## Acceptance Criteria
1. El sistema debe integrar la librería oficial `OAuth2` de Apps Script y un flujo "3-Legged" (Autorización de Usuario).
2. En la pestaña de *Workspace Sync*, debe haber un botón "Conectar Nuevo Dominio" que genere una URL de autorización de Google.
3. Tras aceptar el consentimiento, el sistema debe guardar el `Refresh Token` asociándolo a ese dominio.
4. Las llamadas a `AdminDirectory` en `Engine_Workspace.js` deben interceptar dominios externos y usar `UrlFetchApp` en crudo junto con el token de acceso generado por el Refresh Token guardado.
