# S48.1: Admin Configuration Tab for Custom Branding (Design)

## 1. What & Why
- **Problem**: Actualmente, el título de la pestaña del navegador y su ícono (favicon) están hardcodeados en el código fuente. Los administradores no pueden cambiar la identidad visual sin realizar un despliegue completo de código.
- **Value**: Proveer una interfaz "White-Label" que permita modificar dinámicamente el branding general (Título y Favicon) empodera a los administradores y mejora la percepción de producto sin requerir esfuerzo de desarrollo.

## 2. Approach
La solución es moderadamente sencilla e involucra 3 capas principales:
1. **Frontend (`Governance_Admin_UI.html`)**: Agregar una pestaña/sección llamada "Configuración" o "Branding" en el panel de administrador. Tendrá un formulario sencillo con dos text inputs (`appTitle` y `faviconUrl`) y un botón para guardar.
2. **Backend API (`API_Admin.js`)**: Exponer un nuevo método (ej. `API_Admin_SaveBrandingConfig(payload)`) que valide los campos y los guarde como un string JSON en `PropertiesService.getScriptProperties().setProperty('APP_BRANDING_CONFIG', ...)`
3. **Core Entry Point (`Code.js`)**: Modificar el inicio de `doGet(e)` para leer esta propiedad de script. Si existe, parsearla y encadenarla con `.setTitle(config.appTitle)` y `.setFaviconUrl(config.faviconUrl)`. Si no existe, usar valores por defecto sensatos para evitar fallos.

**Consideraciones de fallback:** Si el valor de `PropertiesService` es nulo o está mal formado (ej. JSON inválido), se aplicará el manejo de errores (try/catch) y se utilizarán valores constantes por defecto.

## 3. Concrete Examples

### Estructura de Datos en PropertiesService
```json
// Key: APP_BRANDING_CONFIG
{
  "appTitle": "Mi Taxonomía Coppel",
  "faviconUrl": "https://www.coppel.com/favicon.ico"
}
```

### Implementación en Code.js (`doGet`)
```javascript
  let brandingConfigStr = null;
  let brandingConfig = {
    appTitle: 'Gobierno de Modelo de Producto — EPT OMR',
    faviconUrl: 'https://www.coppel.com/favicon.ico' // Default
  };

  try {
    brandingConfigStr = PropertiesService.getScriptProperties().getProperty('APP_BRANDING_CONFIG');
    if (brandingConfigStr) {
      let parsed = JSON.parse(brandingConfigStr);
      if (parsed.appTitle) brandingConfig.appTitle = parsed.appTitle;
      if (parsed.faviconUrl) brandingConfig.faviconUrl = parsed.faviconUrl;
    }
  } catch (e) {
    console.error("Error leyendo APP_BRANDING_CONFIG. Usando defaults.", e);
  }

  return template.evaluate()
    .setTitle(brandingConfig.appTitle)
    .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)
    .addMetaTag('viewport', 'width=device-width, initial-scale=1.0, viewport-fit=cover')
    .setFaviconUrl(brandingConfig.faviconUrl);
```

### Implementación en API_Admin.js
```javascript
function API_Admin_SaveBrandingConfig(payload) {
  // Validación de permisos (ABAC)
  // ...
  const configToSave = {
    appTitle: payload.appTitle || 'Gobierno de Modelo de Producto — EPT OMR',
    faviconUrl: payload.faviconUrl || 'https://www.coppel.com/favicon.ico'
  };
  
  PropertiesService.getScriptProperties().setProperty('APP_BRANDING_CONFIG', JSON.stringify(configToSave));
  return { success: true, message: "Configuración actualizada correctamente" };
}
```

## 4. Acceptance Criteria
- **MUST**: Existir una UI en la sección "Governance Admin" para editar "Título de la Aplicación" y "URL del Favicon".
- **MUST**: Los datos deben persistir de manera centralizada en `ScriptProperties`.
- **MUST**: La función `doGet` debe aplicar la configuración en cada inicio de sesión sin fallar si los datos están corruptos.
- **MUST**: Al recargar la aplicación completa (F5) el nuevo icono y texto deben visualizarse en la pestaña del navegador.
