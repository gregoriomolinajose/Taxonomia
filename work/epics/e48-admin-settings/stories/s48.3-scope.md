# Scope S48.3: Workspace Sync Configuration

## In Scope
- Promover la acción actual de "Sincronizar Workspace" a una pestaña completa en `Schema_Studio_UI.html`.
- Agregar UI para el "Master Toggle" (Activar/Desactivar sincronización de Workspace).
- Agregar UI para administrar listas de correos de consulta delegada por dominio (CRUD en memoria y guardado final).
- Crear un endpoint en `API_Admin.js` (usando el patrón `API_Admin_SaveGlobalConfig`) para guardar `APP_WORKSPACE_CONFIG`.
- Modificar `Engine_Workspace.js` para que respete el "Master Toggle" (haciendo un "early return" si está desactivado).

## Out of Scope
- Implementar la lógica OAuth2 / Service Account para la *ejecución real* de la impersonación multi-dominio. (Esto requeriría un microservicio en GCP o la instalación de librerías OAuth2 complejas en Apps Script y excede el alcance de una configuración de UI administrativa. Se preparará la base de datos para esto).
- Refactorización de toda la lógica interna de `Job_WorkspaceSync`. Solo se le insertará el mecanismo de aborto si el toggle está apagado.
