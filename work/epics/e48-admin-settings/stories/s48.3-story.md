# Story S48.3: Configuración y Toggles de Sincronización Workspace

## User Story
Como **Administrador del Sistema**
Quiero **poder activar/desactivar la sincronización con Google Workspace y configurar los correos delegados por dominio** desde el Schema Studio
Para **controlar la provisión automática de usuarios, optimizar tiempos de ejecución cuando el directorio no esté disponible, y preparar el terreno para consultas multi-dominio con delegación.**

## Acceptance Criteria
1. El Schema Studio debe tener una pestaña dedicada a "Workspace Sync" (moviendo el botón actual allí).
2. Debe existir un *toggle* o *checkbox* maestro para habilitar/deshabilitar la sincronización global.
3. Al estar desactivado, cualquier flujo de creación de `Persona` o sincronización debe saltarse la validación con `AdminDirectory`.
4. Debe existir una interfaz para añadir pares de configuración: `[Dominio] -> [Correo de Consulta / Delegado]`. Ej: `@coppel.com -> gregorio.molina@coppel.com`.
5. La configuración se debe persistir en `PropertiesService` bajo la llave `APP_WORKSPACE_CONFIG`.

## Notas Arquitectónicas (Para el Diseño)
- Google Apps Script ejecuta `AdminDirectory` con los permisos del usuario activo.
- La configuración de los "correos de consulta" preparará el terreno lógico para que un futuro adaptador OAuth2 (Service Account) sepa a qué usuario impersonar al consultar el directorio de un dominio específico. Por ahora, persistiremos la configuración para centralizar la intención operativa.
