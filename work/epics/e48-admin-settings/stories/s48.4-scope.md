# Scope S48.4: Autorización OAuth2 (3-Legged) para Workspace Multi-Dominio

## In Scope
- Integración de la librería `OAuth2` compatible con Google Apps Script.
- Construcción de flujos de autorización (`authCallback`, `getAuthorizationUrl`).
- Integración en el Frontend (`Schema_Studio_UI.html`) de la lista de dominios autorizados y el botón de "Conectar Dominio" que invoca el pop-up de login de Google.
- Modificación de `Engine_Workspace.js` para utilizar `UrlFetchApp` directo hacia la API de Directory de Google en caso de consultar un dominio externo autenticado, usando su respectivo Access Token.
- Almacenamiento seguro de credenciales (Refresh Tokens) en `PropertiesService`.

## Out of Scope
- Configuración de Service Accounts y Domain-Wide Delegation (se descartó a favor del modelo OAuth2 estándar).
- Gestión de identidades distintas a Google Workspace (Azure AD, Okta, etc.).

## Done Criteria
- [ ] El administrador puede autenticarse vía Google Sign-In y autorizar su dominio.
- [ ] El sistema guarda y refresca los tokens correctamente.
- [ ] La creación de `Persona` obtiene la foto y el puesto del dominio secundario exitosamente.
