# Scope S48.4: Adaptador OAuth2 para Workspace Multi-Dominio

## In Scope
- Integración de la librería `OAuth2` compatible con Google Apps Script (vía ID de librería o implementación directa del flow JWT).
- Creación de `Adapter_Workspace_OAuth2.js` responsable de firmar el JWT y obtener el token de acceso para el scope `https://www.googleapis.com/auth/admin.directory.user.readonly`.
- Modificación de `Engine_Workspace.js` para utilizar `UrlFetchApp` directo hacia la API de Directory de Google en caso de utilizar el adaptador OAuth2, en lugar del servicio avanzado nativo.
- Lectura de credenciales cifradas (Service Account JSON) desde `PropertiesService`.

## Out of Scope
- Configuración en la consola de Google Cloud (GCP). (La creación de la Service Account y la autorización de delegación a nivel dominio la hará el Super Administrador en la consola de Google de forma manual).
- Gestión de identidades distintas a Google Workspace (Azure AD, Okta, etc.).

## Done Criteria
- [ ] La consulta de Directorio puede impersonar a un administrador delegado según el mapeo de `APP_WORKSPACE_CONFIG`.
- [ ] La creación de `Persona` obtiene la foto y el puesto del dominio secundario exitosamente.
- [ ] Los tokens de acceso son cacheados apropiadamente usando `CacheService` para no agotar cuotas.
