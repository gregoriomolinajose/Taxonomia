# Story S41.15: Abstracción Declarativa de Renderizado PWA (Zero-Hardcode CSS)

**Como** desarrollador de la plataforma Taxonomía,
**Quiero** abstraer las mutaciones CSS en-línea (Hardcode `style.display`) que suceden dentro del Web Component `<tx-searchable>`,
**Para** cumplir integralmente con el Design System (H8 Config-over-convention), simplificando la hidratación y facilitando la interoperabilidad con PWA y ThemeManager donde las directivas CSS rigen el comportamiento visual.

## Contexto de Aceptación
1. **Regla de Cero-Estilos Inline**: El archivo fuente `UI_Component_TXSearchable.client.js` no debe contener re-asignaciones directas de la API de Estilos localizadas en atributos como `element.style.display = 'flex'`. En cambio, debe mutar clases o atributos estandarizados (`[data-popover-open="true"]` o `.show-inline`).
2. **Hidratación mediante ThemeManager / AppEventBus**: Las sub-estructuras afectadas (`#inline-list-container`) deben gobernar su visibilidad reactiva directamente a través de reglas CSS puras ya insertadas en el DOM y gestionadas en inyectores genéricos o el propio Constructor CSS del VCA.
3. **Resiliencia UI a Playwright**: Es clave que el refactor mantenga (o acelere) que los Tests E2E reconozcan rápidamente el elemento "Visible" tras invocar su apertura. Reemplazar mutaciones en-línea por tokens de Atributo ayuda a la sincronización del Layout-Tree.
