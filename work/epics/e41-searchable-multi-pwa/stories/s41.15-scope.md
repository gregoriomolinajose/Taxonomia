# Scope: S41.15 Abstracción Declarativa de Renderizado PWA

## In Scope
- Eliminar manipulaciones manuales como `el.style.display = 'flex'` y `.style.display = 'none'` en el Web Component `<tx-searchable>`.
- Orquestar la vista `Inline` y modal basándose en clases CSS puras (por ej. `tx-inline-open`, `tx-inline-closed` ó atributos HTML del estilo `data-inline-mode="open"`).
- Incluir en el `<style>` del Shadow/Light DOM las reglas nativas para interactuar con los layouts (`[data-inline-mode="open"] { display: flex !important; }`).

## Out of Scope
- Modificar las rutinas asíncronas de PWA fuera dely alcance de este refactor.
- Refactorización de Modales Externos (Popover Controller de Ionic). Solo se atacará el `inlineListContainer` dentro de `TXSearchable`.
- Re-escritura masiva de otros métodos ajenos a `executeSearchAndOpen()`, `render()` y `_cleanupOverlay()`.

## Done Criteria
- [ ] Todo uso quemado de `element.style.display` ha sido erradicado del Web Component.
- [ ] El toggle del componente en entorno Desktop (Multi-search) responde 100% igual con directivas de atributo y clases inyectadas.
- [ ] La Suite E2E local (`ui-resilience.spec.js`) sigue rindiendo a la perfección bajo el nuevo paradigma CSS.
