# Story 41.5: Integration Testing & FormRenderer Regression checks

## Contexto
El motor PWA `TXSearchable` alcanzó madurez total. Para no reescribir docenas de llamadas antiguas en el Motor de Vistas (RelationBuilder y FormRenderer) necesitamos un Middleware Factory.

## Diseño de Adaptador
Utilizar un patrón Wrapper que tome una llamada de `global.UI_Factory.buildSearchableSingle/Multi` y dinámicamente instancie `<tx-searchable>`, lo sature de propiedades y datos, y suscriba traductores de eventos antes de devolver el nodo al renderizador maestro.

```javascript
node.addEventListener('txChange', (e) => {
    bus.publish('SINGLESELECT_CHANGED', { fieldName: attr, value: e.detail.value });
});
```
