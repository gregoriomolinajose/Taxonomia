# S41.10 Scope: Rediseño de Dropdown Múltiple a Inline Checklist

## In Scope
- Refactorización del flujo de apertura en `UI_Component_TXSearchable.client.js` para `multiple="true"`.
- Desvincular el popover flotante (Desktop) y modal inferior (Mobile) para las colecciones `1:N`.
- Inyectar el `<ion-searchbar>` en línea mediante mutación DOM (`display: block/none`).
- Inyectar el `<ion-list>` con `max-height` (scrollable inline) de forma que desplace los elementos posteriores hacia abajo (expansión visual fluida).
- Transformar la representación individual de opciones de la lista para usar `<ion-checkbox slot="start">`.
- Añadir control de cierre manual ("Cerrar" / Collapse) interactivo que reemplace al "+ AGREGAR" cuando está abierto.
- La inserción visual de selecciones en la pila de "Cards" deberá ocurrir pasivamente sin cerrar el listado de checkboxes.

## Out of Scope
- Validaciones numéricas per-componente de selección (EJ: deshabilitar checkboxes si excede max_depth). Esto se reserva para futuras historias formales referidas a Schema Governance (S41.11+).
- Refactorización de Single Select `multiple="false"`. La vista single select seguirá usando los Modales o Popovers flotantes como ya está programado.

## Done When
- [ ] Hacer clic en `+ AGREGAR` de un Multi-Select abre el motor de búsqueda en línea.
- [ ] Renderiza un checkbox junto al icono para cada Item.
- [ ] Al seleccionar un `ion-checkbox`, un "Chip" o tarjeta aparece inmediatamente al fondo del contenedor.
- [ ] El menú inline se puede colapsar devolviéndolo a estado pasivo.
