# User Story: S57.3 Habilitar TXSearchable para Relaciones Jerárquicas

## Connextra
**Como** Arquitecto del Sistema
**Quiero** habilitar el componente interactivo `TXSearchable` para las vinculaciones padre-hijo desde los formularios CRUD de las entidades Dominios y Capacidades
**Para** garantizar una experiencia de usuario estandarizada, intuitiva y robusta al modificar la estructura jerárquica del mapa.

## Acceptance Criteria

```gherkin
Feature: Standardize Hierarchical Relationship Editing with TXSearchable

  Scenario: Editing the parent domain via the UI form
    Given the user is on the CRUD form for the Dominio entity
    When the user interacts with the "Dominio Padre (1:1)" field
    Then the system should render the `searchable_single` component (TXSearchable)
    And clicking the field should launch the modal search window.

  Scenario: Editing the parent capacity via the UI form
    Given the user is on the CRUD form for the Capacidad entity
    When the user interacts with the "Capacidad Padre" field
    Then the system should render the `searchable_single` component (TXSearchable)
    And clicking the field should launch the modal search window.
```
