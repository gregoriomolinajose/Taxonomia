# User Story: S57.5 Cálculo Automático de Niveles Jerárquicos

## Connextra
**Como** Usuario del Sistema
**Quiero** que el nivel jerárquico del dominio (`nivel_tipo`) se calcule automáticamente y que el campo para vincular un padre esté siempre disponible
**Para** no tener que preocuparme por definir manualmente la profundidad jerárquica y evitar fricciones en el flujo de creación de relaciones.

## Acceptance Criteria

```gherkin
Feature: Auto-calculated Hierarchy Level

  Scenario: Parent selection field is always enabled
    Given the user is on the Domain or Capacity form
    Then the "Dominio Padre" field should be immediately available and unlocked without needing to change any level manually.

  Scenario: Hierarchy level field is read-only
    Given the user is viewing the Domain or Capacity form
    Then the "Nivel Tipo" field should be strictly read-only and disabled for manual entry.

  Scenario: Auto-calculation on save
    Given the user fills the form and selects a parent domain
    When the user saves the record
    Then the system should automatically compute the correct `nivel_tipo` (e.g. parent level + 1).

  Scenario: Root node assumption
    Given the user fills the form but leaves the parent domain empty
    When the user saves the record
    Then the system should assume the level is 0/1 (Root Node) and hide the empty parent field in subsequent read-only views.
```
