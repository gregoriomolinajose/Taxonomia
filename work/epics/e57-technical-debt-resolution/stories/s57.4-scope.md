# Scope: S57.4 Refactorización Desacoplada de Web Components Relacionales

## In Scope
- Refactorizar `Schema_Engine.js` para reemplazar los hardcodings de `isExemptEntity` (basados en prefijos DOMI/CAPA) por una configuración controlada por metadatos (e.g. `schema.metadata.governancePolicy`).
- Parametrizar la emisión de eventos bidireccionales en `FormRenderer_UI.client.js` mediante un sistema de "Trigger Rules" declarado en el esquema, eliminando el listener hardcodeado para `nivel_tipo`.
- Abstraer el manejo de estado jerárquico dentro de `UI_Component_RelationBuilder.client.js` hacia un controlador puro (`RelationStateController`) para cumplir con el principio SRP.
- Refactorizar `UI_Component_TXSearchable.client.js` para basarse puramente en `observedAttributes` y su ciclo de vida natural, eliminando el uso y puente de la función inyectada `updateConfig`.
- Implementar soporte para `slots` HTML en `TXSearchable` o parametrizar limpiamente las plantillas en lugar de tener HTML gigante "hardcodeado" internamente.

## Out of Scope
- Migración de datos.
- Modificación de reglas topológicas o lógica de backend de almacenamiento de grafos.
- Funciones visuales ajenas al componente `TXSearchable`.

## Done Criteria
- `Schema_Engine.js` ya no contiene verificaciones estáticas de `prefix === 'DOMI'`.
- `FormRenderer_UI.client.js` escucha eventos genéricos derivados del `APP_SCHEMAS`.
- `TXSearchable` ya no expone el método `updateConfig` y reacciona correctamente a `node.setAttribute('placeholder', ...)` y `node.disabled = ...`.
- Pruebas E2E completadas de que la selección Padre-Hijo de Dominio funciona perfectamente tras el refactor.
