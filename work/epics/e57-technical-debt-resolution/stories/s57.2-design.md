# Story Design: S57.2 Limpieza Final de Relacion_Dominios

## Problem & Value
**Problem**: The legacy entity `Relacion_Dominios` was deprecated in S57.1, but latent string references, dead code comments, or unused scripts might still exist in the codebase.
**Value**: Performing a deep audit and cleanup ensures 100% eradication of the legacy structure, preventing future bugs where developers might accidentally use old queries or where unused code pollutes the architecture.

## Approach
1. **Global Scan**: Execute a rigorous `grep_search` across the `src/` directory for the exact string `Relacion_Dominios`.
2. **Targeted Cleanup**: Analyze the grep results. Remove the string from any comments, documentation, dead code, or configuration files that still harbor it.
3. **Validation**: The deploy command must succeed in the `dev` environment, proving no syntax errors were introduced during cleanup.

## Examples & Data Structures
**Target String**: `"Relacion_Dominios"`

**CLI Usage**:
```bash
# Developer or Agent executes:
grep -r "Relacion_Dominios" src/
# Expected Output: No results found
```

## Acceptance Criteria
- **MUST**: `grep_search` across `src/` yields 0 matches for `Relacion_Dominios`.
- **MUST**: The application builds and deploys to `dev` without errors (`npm run deploy:dev:auto`).
- **MUST NOT**: Leave any dead comments referring to the old sheet in core engine files.
