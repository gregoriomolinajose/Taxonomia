# User Story: S57.2 Limpieza Final de Relacion_Dominios

## Connextra
**Como** Arquitecto del Sistema
**Quiero** realizar una auditoría global para asegurar la total erradicación de referencias a `Relacion_Dominios` y eliminar físicamente la hoja en Google Sheets
**Para** garantizar que ninguna lógica residual falle y consolidar `Sys_Graph_Edges` como el único motor de topología.

## Acceptance Criteria

```gherkin
Feature: Decommission Legacy Domain Relationships Sheet

  Scenario: Global code audit finds zero references
    Given the source code in `src/` directory
    When a global search for "Relacion_Dominios" is executed
    Then the output should return exactly 0 matches
    And the application builds and deploys without compilation errors.

  Scenario: Physical deletion of legacy database table
    Given the system relies entirely on `Sys_Graph_Edges`
    When the administrator deletes the Google Sheet tab "Relacion_Dominios"
    Then the system must not log any "Sheet not found" exceptions during standard operations.
```
