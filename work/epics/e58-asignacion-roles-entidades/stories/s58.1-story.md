# Story S58.1: Actualización de Esquemas Estructurales (Rol + Entidades)

## User Story
**COMO** usuario del sistema
**QUIERO** poder seleccionar a una persona para un rol específico dentro de las entidades (Value Stream, Portafolio, Grupo de Producto, Equipo)
**PARA** definir quién ocupa cada posición sin ambigüedades.

## Acceptance Criteria
1. La entidad Rol incluye "Nombre en Inglés" (width 6), "Color de Ícono" (width 6), y "Área de Gestión / Especialidad" es width 12 sin valor predeterminado.
2. Value Stream permite seleccionar "Dueño del Value Stream" de tipo relacional (Persona).
3. Portafolio permite seleccionar "Gerente de Portafolio" de tipo relacional (Persona).
4. Grupo de Producto permite seleccionar "Gerente de Producto" de tipo relacional (Persona).
5. Equipo muestra el campo "Dueño de Producto" en lugar de "Product Owner".
6. Los campos están pre-configurados para el auto-aprovisionamiento (`mutationInterceptors: ['AutoProvisionEntityRoles']`).
