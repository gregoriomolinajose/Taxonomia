# Design S58.5: UI Swimlanes

## Architecture Changes
No architecture changes required. This is a pure UI projection update within the `UI_View_SwimlaneGrid.client.js` module.

## Decisions
- **D1: Resolution of Person Names.** The `DataStore` (or relation `_label` fields) will be used to resolve the UUID of the person to their actual name on the client side, avoiding N+1 queries to the backend.
- **D2: Dynamic Role Detection.** Instead of hardcoding field names like `gerente_portafolio_id`, the UI will dynamically search for relation fields where `targetEntity === 'Persona'`. This makes the UI future-proof.
- **D3: Inline CSS Flexbox.** The `.tax-node-title` wrapper will be converted to a flex column inline to support multiple vertical rows (Entity, Title, Roles) without disrupting external CSS.

## UX Design
- **Top:** 0.65rem uppercase text, slightly faded, indicating the entity type.
- **Middle:** 1rem bold text with icon, showing the record name.
- **Bottom:** 0.75rem text with a small person icon, showing the role label and the resolved person name.
