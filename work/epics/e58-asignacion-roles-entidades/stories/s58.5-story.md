## User Story
Como usuario del Lienzo de Taxonomía (Swimlane Grid),
Quiero ver el tipo de entidad y el nombre del responsable asignado directamente en el nodo (banner),
Para identificar rápidamente la estructura y a quién contactar sin tener que abrir el detalle de la entidad.

## Acceptance Criteria
1. El nodo debe mostrar en la parte superior, en letra pequeña, el tipo de entidad (ej. PORTAFOLIO).
2. Debajo debe estar el nombre del registro (comportamiento base).
3. Si la entidad tiene asignada una o más Personas en un campo de relación (ej. Gerente de Portafolio), se debe mostrar debajo del nombre del registro con el formato: `[Nombre del Rol]: [Nombre de la Persona]`.
4. El UI debe extraer y resolver automáticamente el nombre de la Persona a partir de su ID usando el DataStore local.
