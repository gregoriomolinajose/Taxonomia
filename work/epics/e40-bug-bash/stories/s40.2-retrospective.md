# Retrospective: S40.2 - Resiliencia E2E Interactiva

## What went well?
- Abordamos la latencia e inestabilidad de las pruebas de UI implementando un "Monkey Tester" robusto en Playwright.
- Las variables globales (interceptores de `pageerror` y `console`) detectaron fielmente los fallos silenciosos y nos aseguraron la integridad de los componentes nativos de Google Apps Script.
- Adoptamos excelentes prácticas de Testing mediante `expect.soft` para evitar falsos positivos y la purga transaccional (Teardown) limpia vía API en lugar de UI fragil.

## What could be better?
- La dependencia fuerte hacia el Auth state de Google (Chrome Profile local) complica temporalmente el testing dentro de sandbox cloud IA.
- Inicialmente incurrimos en "Test Muda" abusando de los silenciamientos de excepciones (catch vacíos). Afortunadamente el QA Review lo pulió.

## Action Items
- Para futuros Epics u otras historias E2E, usar desde el día 1 la arquitectura modular de Auth (`utils/setup.js`) que creamos en esta historia, para prevenir patrón de duplicidad y Magic literals.
