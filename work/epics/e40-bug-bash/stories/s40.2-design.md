# Story Design: S40.2 - Resiliencia E2E Interactiva

**Problem:** Vitest y JSDOM carecen de emulación verdadera de interacción en inputs Ionic/ShadowDOM, permitiendo que errores lógicos de scope y listeners huérfanos se filtren a la producción.
**Value:** Las pruebas "Monkey Tester" en `Playwright E2E` previenen crashes y brindan una cobertura de interacción del 100% en condiciones hiperrealistas conectadas a Google Apps Script, ahorrando debugeo posterior.

## Approach
Reemplazaremos la idea de simular el tecleo de eventos artificiales (`jsdom: e.detail`) y construiremos un Test End-to-End estricto (`ui-resilience.spec.js`), que interceptará el `page.on("pageerror")` y rellenará físicamente entradas a lo largo de las jerarquías UI, incluyendo nodos satélite de alto riesgo (Subgrids y Auto-completados).

**Módulos / Archivos Afectados:**
- `[NEW] __tests__/e2e/ui-resilience.spec.js`

## Examples / Scenarios

**Flow Principal (FormRenderer_UI):**
```javascript
// Localizar target title field "nombre" en un drawer abierto.
const input = page.locator('ion-input[name="nombre"]').locator('input');
await input.focus();
await page.keyboard.type("Reactividad Segura", { delay: 100 });
// No debe haber estallado, validando "Uncaught Exceptions" == 0
```

**Flow Satélite (SearchableSingle & Subgrids):**
```javascript
// Acceder a Búsqueda Modal (Searchable)
const searchNode = page.locator('ion-searchbar').locator('input');
await searchNode.type("Query Dinámica", { delay: 50 });
// No deben existir errores asíncronos "window is undefined" ni crashes.
```

## Acceptance Criteria

1. **MUST:** Crear `__tests__/e2e/ui-resilience.spec.js` consumiendo el `DEV_URL`.
2. **MUST:** Implementar intercepción global de `console.error` o `pageerror` para reprobar en Exception.
3. **MUST:** Demostrar mecanografiado físico (`page.keyboard.type`) en Formulario Drawer Principal.
4. **MUST:** Demostrar mecanografiado físico sobre los componentes iterativos (Satélites: Listas y Modal de Relaciones/Subgrid).
5. **SHOULD:** Configurar el test para Chromium con `headless: false` de ser necesario (en entornos Auth de Apps Script).
