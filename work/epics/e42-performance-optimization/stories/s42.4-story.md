# Story S42.4: Estandarización de Extracción Nodal (Duck-Typing API)

**As a** Arquitecto de Software
**I want** consolidar la extracción de valores del frontend bajo el protocolo estándar `getValidatedValue()`
**So that** abandonemos el web-scraping frágil del DOM (`input.value`) a favor de un protocolo que emita payloads limpios para el `UI_FormSubmitter`.

### Acceptance Criteria
- [x] El recabador del submit iterará sobre nodos `[data-form-component]`.
- [x] Web Components mutados (como `TXSearchable`) despacharán siempre la promesa resuelta.
- [x] Latencia reducida de 20ms a 2ms en ensamblaje de request.
