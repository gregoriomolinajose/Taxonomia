# Story S42.5: Temporal Graph Edge Indexing (SCD-2 Local)

**As a** Arquitecto de Software
**I want** transformar el arreglo linear de relaciones en un Mapa Hash O(1) `_topologyIndex`
**So that** los listados dependientes y los DataGrids puedan resolver herencias estructurales en tiempo real sin congelar la app durante renders masivos.

### Acceptance Criteria
- [x] El `Sys_Graph_Edges` levanta una indexación secundaria pre-compilada en memoria.
- [x] Mitigación del fenómeno "Stealing Orphans" (carreras de concurrencia al vincular n a n).
- [x] Reducción de O(N) a O(1) las iteraciones de jerarquía en SubgridBuilder.
