# Implementation Plan: S42.7 - Optimistic UI & Asynchronous UX

**Story:** S42.7
**Size:** M (5-8 SP)
**Risk Level:** Alto - Falla en reconciliación de Primary Keys mutaría el DataStore corrompiendo grillas momentáneamente.

## Orden de Ejecución de Tareas

### Tarea 1: Destrucción de Bloqueos y Routing Instantáneo
- **Descripción:** Modificar `UI_FormSubmitter` para remover el `ion-loading` global de `backdropDismiss: false`. Mover el cierre del top modal y los triggers de routing (AppEventBus) para que se disparen inmediatamente en Synchronous UI thread.
- **Ficheros:** `src/UI_FormSubmitter.client.js`
- **Verificación:** Iniciar Guardado y verificar que la ventana vuele sin pantallas negras.
- **Size:** S

### Tarea 2: Arquitectura del Proxy Optimista (Temporal PK Injection)
- **Descripción:** Implementar clonación `stateBackup` antes del fetch. Sintetizar Payload en formato `fakeResponse`. Generar identificadores en formato `TMP_LOCAL_...` para los `creates` si el payload no incluye Primary Key validada. Forzar al método `_patchFrontendCache` a inyectarlos a RAM repintando interactivamente.
- **Ficheros:** `src/UI_FormSubmitter.client.js`
- **Verificación:** La Grilla repinta 0.1s tras darle Clic, mostrando temporales.

### Tarea 3: Callback Asíncrono de Reconciliación y Reversos (Rollback)
- **Descripción:** Implementar el `.catch()` y el `.then()` background. 
  - Si Promesa explota (OCC): `window.DataStore.set(entity, stateBackup)`, repintar deshaciendo.
  - Si Promesa Cierra con Exito: Implementar nuevo helper interno `_reconcileTemporaryId` para buscar la fila en RAM que posee `TMP_LOCAL_...` y sustituirla calladamente con la PK Final/Lexical Dictaminada por Google. 
- **Ficheros:** `src/UI_FormSubmitter.client.js`
- **Verificación:** Los Toasts actúan independientemente confirmando sin robar interfaz y la Grilla absorbe los IDs finales por arte de magia.

### Tarea 4: Test de Integración E2E (Simulador Completo)
- **Descripción:** Abrir modal, crear un registro matriz con subgrid, presionar Guardar y navegar inmediatamente a portafolios mientras ocurre red en background. Validar coherencia temporal.
