# S42.7 Scope: Optimistic UI Pipeline

## In Scope
- Eliminar el `ion-loading` global (Black out screen) en el Guardado de cualquier entidad gestionada por `UI_FormSubmitter`.
- Parcheo temprano optimista mediante llamada anticipada a `_patchFrontendCache` antes del fetch.
- Retención temporal del estado local (Snapshot).
- Funcionalidad asíncrona ("Fire and Forget") y cerrado inmediato del Drawer/Modal.
- Manejo de Fallas Asíncronas (Rollback de Snapshot si catch/onError) y notificación de Toast.

## Out of Scope
- Implementación de un Offline Queue persistente (Service Worker con IndexedDB no es parte de este diseño). Si se pierde la red durante esos 6s, la acción se rechaza de inmediato temporalmente, no se reintenta mágicamente al volver el Wi-Fi.

## Done when:
- El usuario puede presionar submit y seguir moviendo el mouse libres de `backdrop` oscuros.
- El DataGrid se repintará a los escasos milisegundos de oprimir el botón.
