# Story S42.2: Desbloqueo del UI Thread durante Sincronización - Plan

## Tareas Implementadas

### Tarea 1: Extracción de Bloqueadores de Render
1. Identificados los flags semafóricos letales (`_temporaryBlurFlag`) en componentes iterativos (e.g., `UI_Component_TXSearchable`).
2. Eliminación de las barreras restrictivas mutables durante el armado asíncrono para liberar el Event Loop.

### Tarea 2: Paralelización Background (Fire & Forget)
1. Desacoplamiento del Evento `click` primigenio en el botón Guardar.
2. Cambio de `await apiService.call()` a un `Promise.race()` donde el hilo principal descarta deliberadamente la promesa para destruir el Modal mientras el motor de red transmite en las brasas.
