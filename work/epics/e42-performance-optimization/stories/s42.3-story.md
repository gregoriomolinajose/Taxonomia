# Story S42.3: Re-Arquitectura de Subgrids Stateless

**As a** Arquitecto de Software
**I want** eliminar la depuración global destructiva (`window.DataStore.clearNested()`)
**So that** los Subgrids ya no trituren la memoria de otros componentes de la SPA al recalcularse, consiguiendo componentes visuales apátridas (stateless).

### Acceptance Criteria
- [x] Los Subgrids dejan de guardar estado en `nestedData`.
- [x] Extirpación de recargas circulares asíncronas en `UI_SubgridBuilder`.
- [x] Optimización O(1) para cruces FK en arrays pre-cargados.
