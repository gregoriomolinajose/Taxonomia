# Story: S50.1 Schema Updates (Foundation)

## User Story
**Como** arquitecto del sistema,
**Quiero** expandir el esquema de datos en `Schema_Engine.js` para añadir la columna `contexto_id` en las aristas globales y el atributo `especialidad` en el catálogo de Roles,
**Para poder** soportar el versionamiento atómico de borradores (Taxonomía) y agrupar los roles por área de gestión.

## Acceptance Criteria

**Escenario 1: Sys_Roles incluye Especialidad**
- **Dado** que se define la entidad `Sys_Roles` en `Schema_Engine.js`,
- **Cuando** se visualiza la configuración de campos,
- **Entonces** debe existir un campo "especialidad" de tipo select con opciones ["TI", "Negocio", "Producto", "Agilidad"].

**Escenario 2: Sys_Graph_Edges soporta el Contexto del Borrador**
- **Dado** que se define la tabla `Sys_Graph_Edges`,
- **Cuando** se validan los campos disponibles,
- **Entonces** debe existir un nuevo campo de texto llamado `contexto_id` (que guardará el ID de la Taxonomía del borrador).
