# Technical Design: S50.4 Mass Approval ETL

## 1. Context & Complexity
- **Complexity:** Moderate.
- **Risk Gate:** Data mutations. We are performing a bulk update on `Sys_Graph_Edges`. The `upsertBatch` method is lock-protected and O(1) in I/O operations, which mitigates race conditions.

## 2. Approach
Para permitir que un Administrador apruebe un borrador:
1. **Backend (`Engine_DB.js` y `API_Universal.js`)**:
   - Agregar una acción `publish_draft_context` en `API_Universal.js` protegida por `Engine_ABAC.validatePermission(..., 'update', 'Taxonomia')`.
   - Implementar `Engine_DB.publishDraftContext(contextId)` que busque la taxonomía y todas sus aristas en borrador, les cambie el estado a `'Validado'`, y guarde vía `_Adapter_Sheets.upsertBatch()`.
2. **Frontend (`FormRenderer_UI.client.js`)**:
   - Identificar si el formulario actual es `Taxonomia` y su estado es `Borrador`.
   - Validar vía `window.ABAC.can('update', 'Taxonomia')` si el usuario tiene derecho de editarla.
   - Inyectar un botón verde "Aprobar Taxonomía" junto al botón de "Guardar".
   - Al hacer clic, invocar `api_router('publish_draft_context', { contextId })`.
   - Refrescar cachés de `Taxonomia` y `Sys_Graph_Edges` tras el éxito, y cerrar el Drawer.

*Value Preservation Gate:* Mantenemos KISS. No implementamos workflows burocráticos multi-estado, simplemente cambiamos los valores de la DB para que `GraphUtils` los descubra automáticamente.

## 3. Examples
```javascript
// Payload enviado desde el cliente
google.script.run
    .withSuccessHandler(...)
    .api_router('publish_draft_context', { contextId: 'TAX-A4F9' });

// Lógica de DB
const edgesToUpdate = edges.filter(e => e.contexto_id === contextId && e.estado === 'Borrador');
edgesToUpdate.forEach(e => { e.estado = 'Validado'; });
_Adapter_Sheets.upsertBatch('Sys_Graph_Edges', edgesToUpdate, { isVolatile: false });
```

## 4. Acceptance Criteria
- [x] Backend endpoint expuesto y protegido por ABAC.
- [x] O(1) I/O en Base de datos (usando `upsertBatch`).
- [x] Botón inyectado en el Stepper solo cuando es Taxonomia y estado es Borrador.
- [x] Se recargan las cachés automáticamente al publicarse.
