# Implementation Plan: S50.4 Mass Approval ETL

## Tasks

### [ ] Task 1: Fix Initial State in Form Submitter
- **File:** `src/UI_FormSubmitter.client.js`
- **Action:** Inside the `isDraftMode` block, add logic to force `payload.estado = 'Borrador'` if the `entityName` is 'Taxonomia' and it's a creation action. This ensures the master entity starts as a draft.

### [ ] Task 2: Implement Backend Engine
- **File:** `src/Engine_DB.js`
- **Action:** Add a new function `publishDraftContext(contextId)`.
- **Logic:**
  1. Retrieve `Taxonomia` records, find by `id_registro === contextId`, set `estado = 'Validado'`, and use `upsertBatch`.
  2. Retrieve `Sys_Graph_Edges`, filter by `contexto_id === contextId` and `estado === 'Borrador'`, update their `estado = 'Validado'` and `updated_at`, then use `upsertBatch`.
  3. Return a success object with the number of affected edges.

### [ ] Task 3: Expose Secure Endpoint
- **File:** `src/API_Universal.js`
- **Action:** Add the `publish_draft_context` action to the router.
- **Logic:** Check ABAC permissions (`Engine_ABAC.validatePermission`) for 'update' on 'Taxonomia'. If authorized, invoke `Engine_DB.publishDraftContext` and return standard success payload.

### [ ] Task 4: UI Approval Button
- **File:** `src/FormRenderer_UI.client.js`
- **Action:** Near the Stepper rendering of the 'Guardar' button, add an 'Aprobar Taxonomía' button.
- **Condition:** Render only if `entityName === 'Taxonomia'`, `data.estado === 'Borrador'`, and `ABAC.can('update', 'Taxonomia')`.
- **Event:** On click, show a loading toast, call `google.script.run...api_router('publish_draft_context')`, and on success close the drawer and publish a cache reload event.
