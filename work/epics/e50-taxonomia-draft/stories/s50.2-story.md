# Story: S50.2 GraphUtils Filter & Wizard Payload Intercept

## User Story
**Como** sistema de base (Engine),
**Quiero** ignorar por defecto todas las aristas que estén en `estado = 'Borrador'`,
**Para** garantizar que los borradores de taxonomía no afecten las consultas del resto de la empresa.

**Como** Wizard de Taxonomía,
**Quiero** enviar automáticamente `estado = 'Borrador'` y el `contexto_id` (ID de la Taxonomía) cuando el usuario guarde una relación,
**Para** asegurar que el borrador quede asilado correctamente en la base de datos hasta su aprobación final.

## Acceptance Criteria

**Escenario 1: Graph_Utils ignora los borradores globalmente**
- **Dado** que se cargan las aristas en el singleton `JS_GraphUtils`,
- **Cuando** la función recorre la lista del servidor para indexar (`resolveAllLinkedIds`),
- **Entonces** las aristas con `estado === 'Borrador'` no deben ser incluidas en los diccionarios `byOrigen` y `byDestino`.

**Escenario 2: El Wizard guarda como borrador**
- **Dado** que un usuario está en el Wizard de Taxonomía (UI_FormStepper),
- **Cuando** añade un portafolio o una persona usando `TXSearchable` o el subgrid,
- **Entonces** el payload enviado al API `Sys_Graph_Edges` debe inyectar forzosamente `estado = 'Borrador'` y `contexto_id = {id_taxonomia}`.
