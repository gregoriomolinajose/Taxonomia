# Story: S50.4 Mass Approval ETL

## Metadata
- **Epic**: E50 (Atomic Draft Taxonomies)
- **ID**: S50.4
- **Size**: S
- **Priority**: High

## User Story (Connextra)
**As a** System Administrator or Content Approver  
**I want to** approve an entire Taxonomy Draft (context) in a single action  
**So that** all draft edges immediately become active ("Validado") and are visible to the entire organization in the live system.

## Acceptance Criteria (Gherkin)

**Scenario: Approving a taxonomy draft**
- **Given** a draft taxonomy with `contexto_id` "TAX-999" containing multiple edges in 'Borrador' state
- **And** the user has administrative/approval permissions (ABAC)
- **When** the user clicks "Approve Taxonomy" and the backend ETL runs
- **Then** all edges in `Sys_Graph_Edges` with `contexto_id` "TAX-999" and `estado` = 'Borrador'
- **And** their status changes to 'Validado' (or whatever live status implies)
- **And** they instantly appear on the live system for all non-admin users without further modifications.

## Notes
- Needs an entry point in the Backend (e.g., `Universal_ETL` or `API_Universal`).
- Needs a UI trigger (button) in the Taxonomia form that is ONLY visible to Admins when `estado` is Draft.
