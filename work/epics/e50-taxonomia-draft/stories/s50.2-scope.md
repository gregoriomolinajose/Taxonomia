# Scope: S50.2 GraphUtils Filter & Wizard Payload

## Boundaries

**In Scope:**
- Modificar `JS_GraphUtils.js` (o donde resida la indexación en el servidor/cliente) para filtrar `estado === 'Borrador'`.
- Modificar la lógica de guardado de relaciones en el ecosistema del Wizard (ej. `SubgridBuilder.client.js` o `UI_Component_TXSearchable.client.js` o interceptores del `FormStepper`) para inyectar los defaults `estado='Borrador'` y `contexto_id=X`.
- Establecer la "Geometría de Roles": si se asigna un rol en un paso específico, la relación hijo será el objeto específico (Taxonomía, Dominio o Grupo Producto).

**Out of Scope:**
- La re-hidratación de estos borradores para que la UI los pinte de nuevo si el usuario vuelve a abrir el borrador (esto se cubre en S50.3).
- La lógica de Aprobación Masiva de borradores (esto se cubre en S50.4).

## Done Criteria
- `JS_GraphUtils` omite las aristas borrador.
- El guardado desde el Wizard inyecta los valores de contexto y estado borrador correctamente.
