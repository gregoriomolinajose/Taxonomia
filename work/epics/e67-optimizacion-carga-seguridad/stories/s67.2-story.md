# S67.2: Bootstrap Selectivo y Diferimiento

## User Story
**As a** system user
**I want** the initial payload and scripts to be selectively loaded and deferred
**so that** the application renders immediately without blocking on heavy libraries or unused data.

## Acceptance Criteria (Gherkin)

**Scenario:** Defer CDNs
**Given** the application is loading
**When** the index page is parsed
**Then** heavy libraries are deferred and do not block rendering.

**Scenario:** Lazy load tabs
**Given** the application has multiple tabs
**When** the initial bootstrap payload is requested
**Then** only the data for the initially visible dashboard/tab is loaded.

**Scenario:** Prune schema
**Given** the backend injects the APP_SCHEMAS
**When** the bootstrap payload is generated
**Then** unused backend metadata is pruned from the schema.
