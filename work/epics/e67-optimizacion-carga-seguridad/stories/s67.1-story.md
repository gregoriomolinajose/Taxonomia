# Story S67.1: Correcciones Críticas Inmediatas

## User Story (Connextra)
Como usuario
Quiero que la aplicación cargue de forma segura y sin redundancias en las llamadas de inicio
Para no experimentar demoras innecesarias y estar protegido ante vulnerabilidades.

## Acceptance Criteria (Gherkin)
Escenario: Inicialización del sistema sin redundancias ni vulnerabilidades
  Dado que el usuario inicia la aplicación
  Cuando el sistema inicializa y requiere la interfaz
  Entonces se debe llamar a AuthManager.init() solo una vez
  Y el caché de tuples en Engine_DB.list debe utilizarse correctamente evitando bypass
  Y se deben mitigar vulnerabilidades menores como Avatar XSS y Domain Leakage
