# S67.2 Design: Bootstrap Selectivo y Diferimiento

## 1. Complexity Assessment
- **Components**: 3 (Index.html, Bootstrap payload builder, Schema pruner)
- **Complexity**: Moderate
- **Risk Gate**: Low risk, no complex data mutation.
- **UX Gate**: Faster load times.
- **Integration Gate**: Verified. Tests should cover real payloads.

## 2. What & Why
- **Problem**: The application's initial load is slowed down by blocking CDN script downloads, loading data for invisible tabs, and transmitting heavy backend-only schema metadata.
- **Value**: Deferring scripts, lazy-loading data, and pruning schemas will drastically reduce the initial payload size and the time to first render, providing an immediate, responsive experience to the user.

## 3. Approach
- **CDNs**: Modify `Index.html` to add the `defer` attribute to heavy library `<script>` tags, preventing DOM parsing blockage while maintaining execution order.
- **Selective Tab Data**: Modify `getAppBootstrapPayload` to only fetch data for the default active tab (Dashboard). Data for other tabs will be requested asynchronously when the user clicks on them.
- **Schema Pruning**: Implement a filter function to strip out backend-specific metadata (e.g., hidden backend formulas) from `APP_SCHEMAS` before injecting it into the HTML payload.

## 4. Examples

### CDNs in Index.html
```html
<!-- Before -->
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>

<!-- After -->
<script src="https://cdn.jsdelivr.net/npm/chart.js" defer></script>
```

### Pruned Schema Payload
```javascript
// Example of pruned schema structure to be injected
const injectedPayload = {
  "schemas": {
    "users": {
      "fields": ["id", "name", "email"], // Only frontend-needed fields
      // "backendOnlyField": ... is removed
    }
  },
  "initialData": {
    "dashboard": [ ... ] // Only dashboard data, no other tabs
  }
};
```

## 5. Acceptance Criteria
- **MUST**: Heavy libraries in `Index.html` are deferred and do not block rendering.
- **MUST**: The initial bootstrap payload only contains data for the initially visible dashboard/tab.
- **MUST**: Unused backend metadata is pruned from the injected `APP_SCHEMAS`.
