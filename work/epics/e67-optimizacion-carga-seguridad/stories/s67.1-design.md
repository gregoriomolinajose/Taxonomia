# Design: S67.1 — Correcciones Críticas Inmediatas

## What & Why
**Problem**: The application initializes with redundant `AuthManager.init()` network calls causing latency. Concurrently, a cache bypass in `Engine_DB.list` degrades performance, and minor security flaws (Avatar XSS, Domain Leakage) expose the app to risks.
**Value**: Improves startup performance by ensuring efficient caching and single initialization, while securing the UI and network layer.

## Approach
1. **AuthManager Initialization**: Remove duplicate invocations of `AuthManager.init()` in the startup sequence. Ensure a singleton or initialization flag pattern is used.
2. **Tuple Cache**: Fix `Engine_DB.list` to properly check and return cached tuples before falling back to DB fetches. (Missing entity strategy: if tuple not in cache, fetch and populate).
3. **Avatar XSS**: Implement strict URL sanitization/validation before binding avatar URLs to the DOM.
4. **Domain Leakage**: Mask sensitive domain data in client-facing exceptions and network requests.

**Value preservation gate**: The caching logic preserves domain intelligence by properly scoping tuples to the request without leaking data between contexts.

## Examples

**Example 1: Initialization**
```javascript
// App Startup
bootstrapApp();
// Network tab should show exactly ONE request for AuthManager.init()
```

**Example 2: Tuple Cache**
```javascript
// First call
const tuples1 = Engine_DB.list("tuples", filter);
// Output: Fetches from DB, caches result.

// Second call (same filter)
const tuples2 = Engine_DB.list("tuples", filter);
// Output: Returns from cache immediately. No DB fetch.
```

**Example 3: Avatar XSS Prevention**
```javascript
const user = { avatarUrl: "javascript:alert('XSS')" };
const safeUrl = sanitizeAvatarUrl(user.avatarUrl);
// Expected safeUrl: "" or a default safe image URL, blocking the XSS payload.
```

## Acceptance Criteria
- **MUST**: `AuthManager.init()` is called exactly once during system initialization.
- **MUST**: `Engine_DB.list` uses the tuple cache correctly on repeated calls, avoiding DB hits.
- **MUST**: Avatar URLs are sanitized to prevent XSS payloads.
- **MUST**: Domain leakage vulnerabilities are patched.
- **MUST NOT**: Cache bypass for identical `Engine_DB.list` tuple queries.
