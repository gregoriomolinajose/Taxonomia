# Story: S101.1 - Backend y Base de Datos (Esquemas Base)

## User Story
**Como** sistema CorePlatform
**Quiero** tener los esquemas de datos de Empresas, Vacantes, Postulantes y Entrevistas definidos
**Para que** el Motor de DB y FormRenderer puedan operar el módulo GreatPeeps con integridad referencial e inmutabilidad (Auditoría).

## Acceptance Criteria
- **AC1:** Los 4 esquemas deben estar registrados en el Registry global.
- **AC2:** Todos los esquemas deben heredar obligatoriamente `lexical_id`, `created_at`, `updated_at`, `updated_by` y `version`.
- **AC3:** Las dependencias deben estar configuradas (Vacante pertenece a Empresa, Postulante a Vacante).
