# Scope: S101.2 - Integración Calendar y Hub IA

## Objective
Desarrollar los servicios backend que conectan CorePlatform con Gemini API (para el procesamiento de CVs) y Google Calendar API (para agendamiento de entrevistas).

## In Scope
- Servicio `Integration_Gemini.js` para extraer texto de PDFs en Drive y procesar el prompt de evaluación.
- Hook de negocio (Business Interceptor) que escuche la creación/actualización de un Postulante con un `cv_drive_id` y detone el servicio de IA.
- Servicio `Integration_Calendar.js` para crear eventos.
- Hook de negocio que escuche la creación de una Entrevista y detone el agendamiento.

## Out of Scope
- Interfaz gráfica (UI del portal).
- Integración nativa con LinkedIn (se hará por extracción de URL en esta fase).

## Done Criteria
- [ ] Subir un Postulante con ID de Drive actualiza su `ai_score` asíncronamente.
- [ ] Crear Entrevista genera evento en Calendar.
