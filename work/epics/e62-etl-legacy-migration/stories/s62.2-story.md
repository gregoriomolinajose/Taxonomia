# Story S62.2: Migrate Dominio Dynamic Topology

## User Story
As a developer,
I want to migrate the `relaciones_padre` calculation based on `orden_path` for Dominio to the backend,
So that we can deprecate the legacy frontend ETL logic.

## Acceptance Criteria

**Scenario: Calculate relaciones_padre from orden_path**
- **Given** a Dominio entity with an `orden_path` field during the ETL process
- **When** the business interceptor executes
- **Then** `relaciones_padre` should be mathematically deduced based on `orden_path` exactly as the frontend did
- **And** the record should be updated with this deduced value

**Scenario: Remove frontend logic**
- **Given** the frontend ETL script `DataEngine_ETL.client.js`
- **When** executing the ETL process
- **Then** it should no longer attempt to calculate `relaciones_padre` for Dominio
