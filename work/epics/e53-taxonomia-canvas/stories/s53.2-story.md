# Story: S53.2 Visual Swimlane Layout

## User Story
**As a** system architect,
**I want** to implement a "Swimlane Grid" canvas that fetches `Sys_Graph_Edges` data and renders nested entities dynamically,
**so that** users can see their Taxonomy hierarchies in a top-down, structurally robust visual matrix.

## Acceptance Criteria
- A new route `#taxonomia/canvas/:id` is registered in `UI_Router.client.js`.
- A DataGrid Row Action "Diseñar Jerarquía" is added to Taxonomía lists.
- `UI_View_SwimlaneGrid.client.js` is implemented and can fetch edges via `API_Universal`.
- `CSS_TaxonomyCanvas.html` is created to handle the native CSS Flexbox/Grid logic.
- The UI paints existing edges accurately, assigning the correct Ionic schema colors to Unidad de Negocio, Portafolio, and Grupo de Productos nodes.
