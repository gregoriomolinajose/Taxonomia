# User Story

**As a** Strategy Executive  
**I want** to click a `[+]` button within my visual hierarchy and select existing Portfolios/Product Groups via a searchable popover  
**So that** I can intuitively connect sub-components to my Taxonomy without leaving the canvas.

## Acceptance Criteria

### Gherkin AC

```gherkin
Feature: Contextual Swimlane Edges Mutation
  
  Scenario: Adding a Portfolio to a Business Unit
    Given I am viewing the Taxonomia Canvas
    And a Business Unit "Retail" is displayed
    When I click the "[+]" button inside the "Retail" swimlane node
    Then an ion-popover opens with a searchable multiselect of "Portafolio"
    When I select "Zapatos" and "Electrónica"
    And I confirm
    Then the edges are saved into Sys_Graph_Edges for the current contextual Taxonomia
    And the canvas updates automatically to reflect the new nested swimlanes.
```

## Definition of Done
- `ion-popover` implementation matches the design kit.
- Graph edge mutations are executed locally using `window.API_Universal.commitEdges(...)` or equivalent if available.
- UI state hydrates correctly after mutation without full page reload.
