# Plan: S53.3 Interactive Contextual Mutations

## Overview
- **Story Size**: Medium
- **Goal**: Allow users to click `[+]` on a taxonomy swimlane node and link an existing child entity using a searchable popover, updating the canvas instantly.

## Execution Order & Tasks

### Task 1: Popover Component UI
- **Description**: Add the `<ion-popover>` HTML template into `CSS_TaxonomyCanvas.html`. Hook the `[+]` button in `UI_View_SwimlaneGrid` to present this popover, populated with a `<ion-searchbar>` and a simple `<ion-list>` of target entities.
- **Files Affected**:
  - `src/CSS_TaxonomyCanvas.html`
  - `src/UI_View_SwimlaneGrid.client.js`
- **Verification**: Clicking `[+]` shows the popover with standard styling.
- **Dependencies**: None.

### Task 2: Data Orchestration & Context
- **Description**: Implement `_presentChildSelector(parentId, parentEntity)` logic. If `parentEntity === 'Unidad_Negocio'`, load `Portafolio` from `DataStore`. Implement filtering logic so it only shows items not currently attached. 
- **Files Affected**:
  - `src/UI_View_SwimlaneGrid.client.js`
- **Verification**: Popover displays actual data from the in-memory `DataStore`.
- **Dependencies**: Task 1.

### Task 3: Edge Mutation Engine
- **Description**: On confirm inside the popover, build the JSON array of new edges. Connect to `window.API_Universal.commitEdges(...)` (or standard RPC). Ensure UI blocking while saving. Once saved, artificially inject the new edge into `window.DataStore.get('Sys_Graph_Edges')` and trigger `this.refresh()`.
- **Files Affected**:
  - `src/UI_View_SwimlaneGrid.client.js`
- **Verification**: `Sys_Graph_Edges` reflects the new relation and canvas redraws correctly.
- **Dependencies**: Task 2.

### Task 4: Manual E2E Validation
- **Description**: Deploy to DEV and manually verify adding a `Portafolio` to a `Unidad_Negocio`, and a `Grupo_Productos` to a `Portafolio`. Verify that duplicate selections are handled or blocked.
- **Files Affected**: N/A
- **Verification**: Human verification passing.
- **Dependencies**: Task 3.

## Sequencing Risks
- **Risk**: Edge creation RPC might fail asynchronously. 
- **Mitigation**: Do not inject into `DataStore` until the RPC callback `google.script.run.withSuccessHandler` successfully returns. Show spinner on the popover to prevent double clicking.
