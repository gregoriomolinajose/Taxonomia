# Scope: Interactive Contextual Mutations

## In Scope
- Connect the `[+]` buttons inside `UI_View_SwimlaneGrid` nodes to a dynamically created `ion-popover`.
- Use the existing `UI_Component_TXSearchable` (or a similar multiselect) inside the popover to search entities.
- Resolve parent node context (e.g. knowing if I clicked the Business Unit or the Portfolio).
- Transform selected values into `Sys_Graph_Edges` JSON array using `tipo_arista`.
- Persist via `DataAPI.client.js` or `Schema_Engine.js` submit capabilities.
- Optimistic update or refresh of the Canvas after successful save.

## Out of Scope
- Creating new `Portafolio` or `Grupo_Productos` records from scratch inside the Canvas. This story assumes the records already exist in their respective views and are just being "linked" (Edge mutation).
- Drag and drop between swimlanes (will be explored later if needed).
- Full scale deletion mutations (only focusing on adding/linking via `[+]` for this story).

## Technical Approach
We will utilize an `<ion-popover>` dynamically appended to the DOM when the user clicks `[+]`.
Inside the popover, we will inject a searchable list of the target entity.
The selection will generate `TAXONOMIA_UNIDAD`, `UNIDAD_NEGOCIO_PORTAFOLIO`, or `PORTAFOLIO_GRUPO_PRODUCTO` edges based on the node level clicked.
