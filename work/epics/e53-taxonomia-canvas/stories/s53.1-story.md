# Story: S53.1 Schema Simplification

## User Story
**As a** system architect,
**I want** to remove the linear Portafolio and Grupo_Productos fields from the Taxonomia schema,
**so that** I can create a clean root Taxonomia entity without being blocked by linear validation rules, paving the way for the new visual canvas.

## Acceptance Criteria
- `id_portafolio` and `grupos_productos` fields are removed from the `Taxonomia` schema definition in `Schema_Engine.js`.
- The `Taxonomia` form wizard only prompts for general settings and the root `id_unidad_negocio`.
- Saving a Taxonomía through the UI works correctly with only the Unidad de Negocio.
