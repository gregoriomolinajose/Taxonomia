# Story S38.8: Ajuste Visual del Modal ETL a Mockup Carga Masiva

As a User
I want the ETL Modal to look like the provided Mockup 
So that the UX is improved and aligns with the design system

## Acceptance Criteria
- Given I open the ETL modal, When it renders, Then I should see a primary colored solid header with the upload icon.
- Given the modal body, Then I should see Radio Card Selectors for data source.
- Given the drive sync option, Then I should see a vertical stepper (1, 2, 3) delineating the steps to import data.
- Given the custom UI components needed, Then they must be abstracted properly via CSS and/or JS.
