# S38.7 Scope: UI/UX Audit & Redesign del Modal ETL

## In Scope
- Inspección del marcado HTML/CSS original de los Modales implicados en la extracción de plantillas e importación CSV.
- Emisión de un diagnóstico de usabilidad (UX) detallando oportunidades (progreso, contraste, affordance).
- Elaboración de un diseño final y estructura de CSS purificado, atado estricta pero extensiblemente al Sistema de Diseño actual.
- Recomendación de nuevos Custom Properties (`var(--...)`) que robustezcan el Layout y componentes visuales del Ecosistema de Taxonomía.

## Out of Scope
- Alteración de la algoritmia y parser JavaScript ya aprobada (`DataEngine_ETL.client.js`).
- Modificación del backend Google Apps Script. 
- Implementación Final en producción (Esta historia fungirá esencialmente como una encomienda de Arquitectura de UI o auditoría, y la codificación final se empujará o se diseñará).

## Done Criteria
- Propuesta de Re-Diseño (Design Doc o Asset) completamente documentada para el Agent / Opus 4.6.
- Propuesta formal de Tokens nuevos anexados de forma documentada al Theme Manager o variables raíces.
