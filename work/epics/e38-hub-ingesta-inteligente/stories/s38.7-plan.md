## Risks and Mitigations
| Riesgo | Probabilidad | Mitigación |
|---|---|---|
| Ionic Shadow DOM ignora clases externas | Media | Usar CSS Custom Properties que penetran Shadow DOM (`--background`, `--border-radius`) solo donde sea necesario |
| El `include('CSS_ETL_Modal')` no se resuelve en Apps Script | Baja | Patrón ya validado con `CSS_DesignSystem` y `CSS_App` — misma mecánica |
| `dragover`/`drop` events no funcionan dentro de `ion-modal` | Media | Eventos HTML5 nativos funcionan en cualquier contenedor DOM; el modal de Ionic monta sus hijos en el light DOM |
