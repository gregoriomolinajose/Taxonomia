## Risks and Mitigations
| Riesgo | Probabilidad | Mitigación |
|---|---|---|
| Ionic Shadow DOM ignora clases externas | Media | CSS Custom Properties penetran Shadow DOM |
| `@media (hover: hover)` no soportado en navegadores legacy | Baja | Fallback seguro: dropzone oculta por defecto |
| Drag events en `ion-modal` | Media | Eventos HTML5 nativos funcionan en light DOM |
