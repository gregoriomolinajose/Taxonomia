# S38.7 Rediseño UI/UX Modal ETL para Carga Masiva

## User Story
**Como** Analista de Diseño UI / Usuario Final
**Quiero** contar con un modal híbrido ETL rediseñado bajo métricas óptimas de UX y alineado a Gobernanza de Sistema de Diseño Taxonomía
**Para** interactuar con un flujo de subida documental más limpio, reduciendo fricción y aportando certidumbre visual sobre los estados del procesamiento asíncrono (Chunking) e inferencia de errores.

## Acceptance Criteria
1. **Auditoría UX Efectiva:** Se presentará una revisión crítica del DOM del modal ETL identificando deudas técnicas e inconsistencias estéticas.
2. **Propuesta Arquitecturada:** Se entregará un diseño renovado o propuesta HTML/CSS estricto basado en Tokens y tipografía vigentes del proyecto (`Config_Typography` y variables CSS genéricas).
3. **Nuevos Tokens Permitidos:** Si las limitantes actuales lo requieren, el diseño puede sugerir la inyección de nuevas variables (`--color-surface-hover`, `--spacing-fluid`, etc) adjuntándolos de forma modular para enriquecer el UI Governance sin demoler el canon.
4. **Responsive & Accesibilidad:** La propuesta debe honrar la arquitectura responsiva y las jerarquías de lectura para las animaciones y feedback visual de progreso.
